# 01 矩阵模拟

> **一句话理解**：矩阵模拟题全靠**边界控制 + 方向数组**。用 `top/bottom/left/right` 四个变量圈定还没处理的区域，处理完一条边就收缩对应边界，是螺旋类题的通用骨架。

---

## 一、螺旋矩阵（54 题）

**题目**：按顺时针螺旋顺序返回矩阵所有元素。

**核心思路**：维护四个边界 `top/bottom/left/right`，按"右→下→左→上"的顺序走，每走完一条边就收缩对应边界，直到边界交错。

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    if (matrix.length == 0) return res;
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res.add(matrix[top][j]);     // 上边：→
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);   // 右边：↓
        right--;
        if (top <= bottom)                                               // ★ 判断还有行
            for (int j = right; j >= left; j--) res.add(matrix[bottom][j]); // 下边：←
        bottom--;
        if (left <= right)                                               // ★ 判断还有列
            for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);   // 左边：↑
        left++;
    }
    return res;
}
```

**两个 `if` 判断必不可少**：走完上边和右边后，可能已经没有剩余的行或列了（比如单行/单列矩阵），不判断就会重复添加元素。**这是螺旋矩阵最高频的 bug。**

*螺旋矩阵是【四边界收缩模拟】，关键突破点是【右下左上顺序遍历、每条边走完收缩边界，走下边/左边前要判断行列是否还剩】，边界是【单行、单列矩阵】。*

## 二、螺旋矩阵 II（59 题）：反向填充

**题目**：生成 `n×n` 的螺旋矩阵（填 1 到 n²）。和 54 题结构完全一样，只是把"读"改成"写"：

```java
public int[][] generateMatrix(int n) {
    int[][] mat = new int[n][n];
    int top = 0, bottom = n - 1, left = 0, right = n - 1, num = 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) mat[top][j] = num++;
        top++;
        for (int i = top; i <= bottom; i++) mat[i][right] = num++;
        right--;
        for (int j = right; j >= left; j--) mat[bottom][j] = num++;
        bottom--;
        for (int i = bottom; i >= top; i--) mat[i][left] = num++;
        left++;
    }
    return mat;
}
```

> `n×n` 方阵不会出现"单行单列"的收缩问题，所以这里可以省掉那两个 `if`。

## 三、旋转图像（48 题）：原地顺时针转 90°

**题目**：把 `n×n` 矩阵原地顺时针旋转 90°。

**技巧：两次翻转 = 一次旋转**。先沿主对角线转置，再左右翻转每一行，就等于顺时针旋转 90°：

```java
public void rotate(int[][] matrix) {
    int n = matrix.length;
    // ① 沿主对角线转置：matrix[i][j] 与 matrix[j][i] 交换
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    // ② 每行左右翻转
    for (int i = 0; i < n; i++)
        for (int l = 0, r = n - 1; l < r; l++, r--) {
            int tmp = matrix[i][l];
            matrix[i][l] = matrix[i][r];
            matrix[i][r] = tmp;
        }
}
```

**为什么"转置 + 水平翻转"等于顺时针 90°？** 转置把 `(i,j)` 变到 `(j,i)`（沿对角线镜像），再水平翻转把列反过来，两步复合恰好是顺时针旋转。手推一个 `2×2` 矩阵就能验证。

> **逆时针 90°**：改成"转置 + 上下翻转"，或"水平翻转 + 转置"。

*旋转图像是【转置 + 翻转】，关键突破点是【顺时针 90° = 主对角线转置 + 每行左右翻转】，边界是【转置时内层 `j` 从 `i+1` 开始避免转两次】。*

## 四、矩阵置零（73 题）：用首行首列当标记

**题目**：若某元素为 0，则把它所在的行和列全置 0，要求 `O(1)` 额外空间。

**巧思**：用矩阵的**第一行和第一列**当标记位，记录"哪些行/列需要清零"，省去额外的标记数组。先单独记录第一行、第一列本身是否要清零，再处理内部。

```java
public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRow = false, firstCol = false;
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRow = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstCol = true;
    for (int i = 1; i < m; i++)                   // 用首行首列做标记
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) { matrix[i][0] = 0; matrix[0][j] = 0; }
    for (int i = 1; i < m; i++)                   // 根据标记清零内部
        for (int j = 1; j < n; j++)
            if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
    if (firstRow) for (int j = 0; j < n; j++) matrix[0][j] = 0;   // 最后处理首行首列
    if (firstCol) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
```

## 五、对角线遍历（498 题）：方向翻转

**题目**：按对角线之字形（↗↙交替）遍历矩阵。

**关键观察**：同一条对角线上 `i+j` 为定值。遍历时维护一个方向标志，走到边界就换方向、换起点。这类题的要点是**仔细处理"碰到边界时下一个起点在哪"**，容易写错，建议先画图列出每条对角线的起点规律。
