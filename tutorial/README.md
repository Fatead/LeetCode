## 怎么用这份教程（推荐流程）

```
第 1 步  读一章的「核心思想」，理解这个数据结构/算法到底解决什么问题
第 2 步  抄一遍「Java 通用模板」，做到不看书能默写
第 3 步  独立做该章的「入门题」，做不出来看题解，看懂后关掉再写一遍
第 4 步  做「进阶题」，卡住 30 分钟就看思路，不要死磕
第 5 步  过 48 小时回头重做一遍「入门题」，能秒杀才算真会
```

**铁律**：每一道做过的题，都要能一句话说出「这题属于哪个模板、关键突破点是什么」。说不出来，就等于没做。

## 教程与仓库代码的对应关系

每道例题都会以这种形式给出仓库中的参考实现：

> 参考实现：[src/array/ThreeNum.java](../src/array/ThreeNum.java)

仓库代码是**个人刷题记录**，同一个知识点往往有多个文件、多份实现（比如 `LRUCache.java`、`LRUCache2.java`、`LRUCache3.java`、`LRUCache4.java` 是同一道题的四种写法）。教程里会说明哪种写法是**面试推荐版本**，以及其余写法各自的价值（暴力 → 优化 → 最优的演进过程本身就是最好的学习材料）。
