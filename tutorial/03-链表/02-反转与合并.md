# 02 反转与合并

> **一句话理解**：反转链表 = **三指针 `pre/cur/next` 的推进**，顺序铁律是"先存下一个，再翻指针"；合并链表 = **哑结点 + 两路归并**，谁小接谁。这两个模板是链表题出现频率最高的。

---

## 一、反转整个链表（206 题）

### 1.1 迭代写法（面试首选，必须默写）

```java
public ListNode reverseList(ListNode head) {
    ListNode pre = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;   // ① 先存住下一个
        cur.next = pre;             // ② 翻转：当前指向前一个
        pre = cur;                  // ③ pre 前进到 cur
        cur = next;                 // ④ cur 前进到 next
    }
    return pre;                     // pre 停在原尾结点 = 新头
}
```

画图走一遍（`1→2→3→null`）：

```
初始   pre=null   cur=[1]
轮1    next=[2]   [1]→null      pre=[1]  cur=[2]
轮2    next=[3]   [2]→[1]→null  pre=[2]  cur=[3]
轮3    next=null  [3]→[2]→[1]→null  pre=[3]  cur=null → 退出
返回 pre=[3]，新链表 3→2→1→null  ✓
```

> 参考实现：[src/listTable/ReverseList2.java](../../src/listTable/ReverseList2.java)、[src/listTable/ReverList.java](../../src/listTable/ReverList.java)

### 1.2 递归写法（理解"后序位置"）

```java
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;   // 终止：空或单结点
    ListNode newHead = reverseList(head.next);            // 先翻转后面，拿到新头
    head.next.next = head;    // 让下一个结点反过来指向自己
    head.next = null;         // 自己断开原来的 next（否则成环）
    return newHead;           // 新头一路向上传
}
```

**理解关键**：递归到最深处返回原尾结点作为 `newHead`，然后在**回溯（后序位置）**时，逐层把 `head.next.next = head` 完成翻转。`head.next = null` 这一步最易漏——不写会形成 `2↔1` 的环。

> 参考实现：[src/listTable/ReverseList3.java](../../src/listTable/ReverseList3.java)

*反转链表是【三指针推进 / 递归后序】，关键突破点是【迭代必须先存 next 再翻指针；递归要记得 `head.next = null` 断尾】，边界是【空链表和单结点直接返回】。*

## 二、反转链表 II：区间反转（92 题）

反转第 `m` 到第 `n` 个结点（1-indexed）。**头部可能被反转，用哑结点**。

```java
public ListNode reverseBetween(ListNode head, int m, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode pre = dummy;
    for (int i = 1; i < m; i++) pre = pre.next;   // pre 停在第 m-1 个（反转段的前驱）

    ListNode cur = pre.next;                       // cur 是反转段第一个结点
    for (int i = 0; i < n - m; i++) {              // 头插法：把 cur 后面的结点逐个插到 pre 后
        ListNode next = cur.next;
        cur.next = next.next;
        next.next = pre.next;
        pre.next = next;
    }
    return dummy.next;
}
```

**头插法图解**（反转 `[2,3,4]`，`pre` 指向 1）：

```
1→2→3→4→5      把 3 摘下插到 pre 后 → 1→3→2→4→5
1→3→2→4→5      把 4 摘下插到 pre 后 → 1→4→3→2→5
```

每次把 `cur` 的下一个结点"摘下来、插到 `pre` 正后面"，循环 `n-m` 次即完成区间反转。

> 参考实现：[src/listTable/ReverseBetween.java](../../src/listTable/ReverseBetween.java)、[src/listTable/ReverseList.java](../../src/listTable/ReverseList.java)（仓库的 `ReverseList.reverseBetween` 用的是 `pre/cur/third` 整段翻转再接回的写法，也正确，但头插法更不易错）

*区间反转是【哑结点 + 头插法】，关键突破点是【固定 `pre`，把反转段后续结点逐个头插到 `pre` 后】，边界是【从哑结点出发找 `pre`，循环次数是 `n-m`】。*

## 三、K 个一组翻转（25 题，Hard）

每 `k` 个一组翻转，不足 `k` 个保持原样。这是链表 Hard 的代表题。

```java
public ListNode reverseKGroup(ListNode head, int k) {
    // ① 先检查剩余结点是否够 k 个
    ListNode tail = head;
    for (int i = 0; i < k; i++) {
        if (tail == null) return head;   // 不够 k 个，整段不翻转
        tail = tail.next;
    }
    // ② 翻转本组 [head, tail) 这 k 个
    ListNode pre = null, cur = head;
    while (cur != tail) {
        ListNode next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    // ③ 递归处理后面，并把本组尾（原 head）接上
    head.next = reverseKGroup(tail, k);
    return pre;    // pre 是本组翻转后的新头
}
```

**三步拆解**：先探路数够不够 `k` 个 → 翻转这一组（标准三指针，终止条件是 `cur != tail`）→ 递归翻转剩下的、再把原 `head`（现在成了组尾）接到后面递归的结果上。

> 参考实现：[src/listTable/ReverseKGroup.java](../../src/listTable/ReverseKGroup.java)。仓库版本用了**栈**来翻转每一组（`reverse` 方法把结点压栈再弹出），思路直观但多了 `O(k)` 空间；上面的三指针递归版是更优的 `O(1)` 额外空间（不含递归栈）写法。

*K 个一组翻转是【分组 + 组内三指针 + 递归拼接】，关键突破点是【先探路确认够 k 个再翻、翻完让原组头接上递归结果】，边界是【不足 k 个直接返回不翻转】。*

## 四、两两交换结点（24 题）

K 个一组翻转在 `k=2` 时的特例，可以单独用哑结点写：

```java
public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode pre = dummy;
    while (pre.next != null && pre.next.next != null) {
        ListNode first = pre.next, second = first.next;
        first.next = second.next;    // first 跳过 second
        second.next = first;         // second 接到 first 前
        pre.next = second;           // pre 接到 second
        pre = first;                 // pre 前进两步（first 现在是这对的后一个）
    }
    return dummy.next;
}
```

> 参考实现：[src/listTable/SwapNode.java](../../src/listTable/SwapNode.java)、[src/listTable/SwapKNode.java](../../src/listTable/SwapKNode.java)

## 五、合并两个有序链表（21 题）

**哑结点 + 两路归并**，谁小接谁，一条走完直接接上另一条的剩余段。

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode cur = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else                  { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = (l1 != null) ? l1 : l2;   // ★ 关键：接上剩余段，不要漏
    return dummy.next;
}
```

**最常见的 bug**：循环结束后忘记 `cur.next = (l1 != null) ? l1 : l2`，导致较长链表的尾巴被丢弃。因为链表是整段相连的，这里**只需接一个指针**，不用再逐个复制。

> 参考实现：[src/listTable/MergeTwoList.java](../../src/listTable/MergeTwoList.java)、[src/listTable/MergeList.java](../../src/listTable/MergeList.java)

*合并两个有序链表是【哑结点 + 双路归并】，关键突破点是【谁小接谁，循环后把剩余段一次性接上】，边界是【一条为空直接返回另一条】。*

## 六、合并 K 个有序链表（23 题，Hard）

两种主流解法：

### 6.1 分治两两合并（推荐，`O(n log k)`）

把 `k` 条链表两两合并，像归并排序一样分治：

```java
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    return merge(lists, 0, lists.length - 1);
}
private ListNode merge(ListNode[] lists, int lo, int hi) {
    if (lo == hi) return lists[lo];
    int mid = (lo + hi) >>> 1;
    ListNode l1 = merge(lists, lo, mid);
    ListNode l2 = merge(lists, mid + 1, hi);
    return mergeTwoLists(l1, l2);     // 复用 21 题
}
```

> 参考实现：[src/listTable/MergeKList.java](../../src/listTable/MergeKList.java)。仓库版本用 `Arrays.copyOfRange` 做分治，思路相同（只是用拷贝数组代替下标区间，多一点开销）。

### 6.2 优先队列（最小堆，`O(n log k)`）

把每条链表的头结点扔进小根堆，每次弹出最小的接到结果上，再把它的后继入堆：

```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) if (node != null) pq.offer(node);
    ListNode dummy = new ListNode(0), cur = dummy;
    while (!pq.isEmpty()) {
        ListNode min = pq.poll();
        cur.next = min;
        cur = cur.next;
        if (min.next != null) pq.offer(min.next);
    }
    return dummy.next;
}
```

**两种解法复杂度相同**（`n` 为总结点数，`k` 为链表数）。分治不需要额外数据结构、常数更小；优先队列代码更直观、更容易现场写对，面试任选。

> 参考实现：[src/listTable/MergeKLists.java](../../src/listTable/MergeKLists.java)

*合并 K 个链表是【分治两两合并 / 最小堆】，关键突破点是【把 K 路归并降为 `log k` 层两路归并，或用堆每次取全局最小】，边界是【空数组返回 null、堆里只放非空结点】。*
