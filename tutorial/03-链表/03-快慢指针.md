# 03 快慢指针

> **一句话理解**：快慢指针就是**两个速度不同的指针**。快 2 慢 1 → 快到头时慢在中点；在环里快慢必相遇 → 判环；快先走 k 步再同步 → 找倒数第 k 个。一个模板，三类问题。

---

## 一、找链表中点（876 题）

快指针一次走 2 步，慢指针一次走 1 步。快到末尾时，慢指针恰好在中间。

```java
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;   // 偶数长度时返回后一个中点
}
```

**偶数长度取前中点还是后中点？**

| 需求 | 初始化 | 结果 |
| --- | --- | --- |
| 后中点（876 要求） | `slow = fast = head` | `[1,2,3,4]` → 返回 `3` |
| 前中点（归并排序断链用） | `slow = head; fast = head.next` | `[1,2,3,4]` → 返回 `2` |

**归并排序链表时必须取前中点**，否则 `slow` 停在后中点会导致左半段多一个、无法正确断链，极端情况死循环。

> 参考实现：[src/listTable/MiddleNode.java](../../src/listTable/MiddleNode.java)。仓库版本用"计数器 + 每隔一次移动一次慢指针"实现，效果等价于快慢指针，但标准的快 2 慢 1 写法更简洁通用。

## 二、环形链表：判环（141 题）

### 2.1 哈希表法（仓库写法，直观）

```java
public boolean hasCycle(ListNode head) {
    Set<ListNode> seen = new HashSet<>();
    ListNode pt = head;
    while (pt != null) {
        if (!seen.add(pt)) return true;   // add 返回 false = 之前见过 = 有环
        pt = pt.next;
    }
    return false;
}
```

> 参考实现：[src/listTable/CircleInList.java](../../src/listTable/CircleInList.java)（仓库就是哈希法）。空间 `O(n)`。

### 2.2 快慢指针法（Floyd，面试首选，`O(1)` 空间）

**核心直觉**：如果有环，快指针迟早进环，然后在环里"套圈"追上慢指针——两者速度差 1，每轮距离缩短 1，必定相遇。无环则快指针会先到达 `null`。

```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;   // 相遇 = 有环
    }
    return false;                        // 快指针到头 = 无环
}
```

**为什么一定会相遇而不会"跳过"？** 因为慢指针每次走 1 步、快指针每次走 2 步，两者间距每轮**恰好减少 1**，不会出现"一步跨过去"的情况，所以间距一定会减到 0。

## 三、环形链表 II：找环入口（142 题）

### 3.1 哈希表法（仓库写法）

第一个"再次遇到"的结点就是环入口：

```java
public ListNode detectCycle(ListNode head) {
    Set<ListNode> seen = new HashSet<>();
    ListNode pt = head;
    while (pt != null) {
        if (!seen.add(pt)) return pt;   // 第一个重复出现的即入口
        pt = pt.next;
    }
    return null;
}
```

> 参考实现：[src/listTable/CircleInList2.java](../../src/listTable/CircleInList2.java)（仓库是哈希法）。

### 3.2 快慢指针法（Floyd 两阶段，必须掌握）

```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {                 // 第一阶段：相遇
            ListNode p = head;
            while (p != slow) {             // 第二阶段：头和相遇点同速前进
                p = p.next;
                slow = slow.next;
            }
            return p;                       // 相遇点即环入口
        }
    }
    return null;
}
```

**数学证明（为什么第二阶段能找到入口）**：设头到环入口距离为 `a`，入口到相遇点距离为 `b`，相遇点回到入口距离为 `c`（即环长 `= b + c`）。相遇时慢走了 `a + b`，快走了 `a + b + n(b + c)`（多绕了 `n` 圈），且快走的是慢的 2 倍：

```
2(a + b) = a + b + n(b + c)
→ a + b = n(b + c)
→ a = (n-1)(b+c) + c
```

即 `a` = `(n-1)` 整圈 + `c`。所以从头和从相遇点各派一个指针同速走，走 `a` 步后必在入口相遇。**这个推导不用背，但要能说出"a 和 c 的关系"这个结论。**

*环形链表 II 是【Floyd 两阶段 / 哈希】，关键突破点是【相遇后让一个指针回头、与慢指针同速走，交点即入口】，边界是【无环时快指针先到 null】。*

## 四、倒数第 k 个结点（剑指 22 / 面试题 02.02）

**快指针先走 k 步，然后快慢同步走，快到末尾时慢指针就在倒数第 k 个。**

```java
public ListNode getKthFromEnd(ListNode head, int k) {
    ListNode fast = head, slow = head;
    for (int i = 0; i < k; i++) fast = fast.next;   // 快指针先行 k 步
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    return slow;
}
```

**它和"删除倒数第 N 个"是同一个套路**，区别只在于删除时要从哑结点出发让慢指针停在"前一个"。

> 参考实现：[src/listTable/getKthFromEnd.java](../../src/listTable/getKthFromEnd.java)

## 五、回文链表（234 题）

**三步法**：快慢指针找中点 → 反转后半段 → 从两端向中间逐一比较。

```java
public boolean isPalindrome(ListNode head) {
    if (head == null || head.next == null) return true;
    // ① 快慢指针找中点（slow 停在后半段起点前）
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // ② 反转后半段
    ListNode second = reverse(slow);
    // ③ 双指针从两端比较
    ListNode p1 = head, p2 = second;
    boolean ok = true;
    while (ok && p2 != null) {
        if (p1.val != p2.val) ok = false;
        p1 = p1.next;
        p2 = p2.next;
    }
    return ok;
}
private ListNode reverse(ListNode head) {
    ListNode pre = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    return pre;
}
```

这个 `O(1)` 空间解法把前面学的"找中点 + 反转"组合起来。更简单的做法是把值全扔进 `ArrayList` 再双指针比较（`O(n)` 空间），面试建议先说简单版、再给出 `O(1)` 版。

> 参考实现：[src/listTable/IsPalindrome.java](../../src/listTable/IsPalindrome.java)、[src/listTable/PalindromeList.java](../../src/listTable/PalindromeList.java)

*回文链表是【找中点 + 反转后半 + 双端比较】，关键突破点是【把"反转链表"和"找中点"两个基础模板组合】，边界是【空/单结点直接 true，奇数长度中间结点不参与比较】。*

## 六、相交链表（160 题）

**双指针各走一遍对方的路**：两个指针分别从两条链表头出发，走到末尾就跳到对方链表头继续走。若相交，它们会在交点相遇（走的总长度相同 `a + c + b = b + c + a`）；若不相交，同时变成 `null`。

```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    if (headA == null || headB == null) return null;
    ListNode pA = headA, pB = headB;
    while (pA != pB) {
        pA = (pA == null) ? headB : pA.next;
        pB = (pB == null) ? headA : pB.next;
    }
    return pA;   // 相交点或同时为 null
}
```

> 参考实现：[src/listTable/IntersectionNode.java](../../src/listTable/IntersectionNode.java)、[src/listTable/IntersectList.java](../../src/listTable/IntersectList.java)

*相交链表是【双指针走对方的路消除长度差】，关键突破点是【到头就跳对方链表头，两指针走的总距离相等必在交点相遇】，边界是【不相交时同时为 null 退出】。*
