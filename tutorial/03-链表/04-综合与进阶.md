# 04 综合与进阶

> **一句话理解**：这一节的题都是**基础模板的组合**——重排链表 = 找中点 + 反转 + 合并；两数相加 = 哑结点 + 进位；复制随机指针 = 哈希映射或原地穿插。会了前三节，这一节就是"拼积木"。

---

## 一、两数相加（2 题）

两个链表逆序存储数字，逐位相加。**用哑结点 + 进位变量 `carry`**，统一处理长度不等和最后进位。

```java
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), cur = dummy;
    int carry = 0;
    while (l1 != null || l2 != null || carry != 0) {   // 三条件缺一不可
        int sum = carry;
        if (l1 != null) { sum += l1.val; l1 = l1.next; }
        if (l2 != null) { sum += l2.val; l2 = l2.next; }
        carry = sum / 10;
        cur.next = new ListNode(sum % 10);
        cur = cur.next;
    }
    return dummy.next;
}
```

**三个循环条件缺一不可**：`l1 != null || l2 != null` 处理两链表不等长，`carry != 0` 处理最高位进位（如 `5 + 5 = 10`，结果要有两位）。

> 参考实现：[src/listTable/AddTwoNum.java](../../src/listTable/AddTwoNum.java)、[src/listTable/AddTwoNums.java](../../src/listTable/AddTwoNums.java)

*两数相加是【哑结点 + 进位模拟】，关键突破点是【循环条件包含 `carry != 0` 以处理最高位进位】，边界是【两链表不等长、最终进位要补一位】。*

## 二、重排链表（143 题）

把 `L0→L1→…→Ln` 重排成 `L0→Ln→L1→Ln-1→…`。**三步法**：

1. 快慢指针找中点，断成前后两半
2. 反转后半段
3. 两半交替合并

```java
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    // ① 找中点
    ListNode slow = head, fast = head;
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    // ② 断开 + 反转后半
    ListNode second = slow.next;
    slow.next = null;
    ListNode pre = null;
    while (second != null) {
        ListNode next = second.next;
        second.next = pre;
        pre = second;
        second = next;
    }
    // ③ 交替合并（pre 是后半段的头）
    ListNode p1 = head, p2 = pre;
    while (p2 != null) {
        ListNode n1 = p1.next, n2 = p2.next;
        p1.next = p2;
        p2.next = n1;
        p1 = n1;
        p2 = n2;
    }
}
```

> 参考实现：[src/listTable/Reorder.java](../../src/listTable/Reorder.java)。仓库版本把这三步揉在一个方法里写（找中点用计数器、反转和合并手工交织），逻辑正确但较难读；上面"**找中点 → 反转 → 合并**"三段式结构清晰、更易默写，是推荐版本。

*重排链表是【找中点 + 反转后半 + 交替合并】，关键突破点是【把问题拆成三个独立的基础模板】，边界是【找中点后要 `slow.next = null` 断开两半，否则合并时成环】。*

## 三、分隔链表（86 题）

把小于 `x` 的结点都排在大于等于 `x` 的结点前面，保持相对顺序。**用两个哑结点各建一条链，最后拼接**：

```java
public ListNode partition(ListNode head, int x) {
    ListNode smallHead = new ListNode(0), small = smallHead;
    ListNode bigHead = new ListNode(0), big = bigHead;
    while (head != null) {
        if (head.val < x) { small.next = head; small = small.next; }
        else              { big.next = head;   big = big.next; }
        head = head.next;
    }
    big.next = null;              // ★ 必须断尾，否则可能成环
    small.next = bigHead.next;    // 小链尾接大链头
    return smallHead.next;
}
```

**最关键的 `big.next = null`**：大链的最后一个结点可能还指着原链表后面的结点，不断尾就会形成环。

> 参考实现：[src/listTable/PartitionList.java](../../src/listTable/PartitionList.java)、[src/listTable/SplitList.java](../../src/listTable/SplitList.java)

*分隔链表是【双哑结点分流 + 拼接】，关键突破点是【建两条链分别收集，大链尾必须断开】，边界是【`big.next = null` 防止成环】。*

## 四、奇偶链表（328 题）

把奇数位置的结点排前面，偶数位置的排后面。**双指针原地穿针**：

```java
public ListNode oddEvenList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode odd = head, even = head.next, evenHead = even;
    while (even != null && even.next != null) {
        odd.next = even.next;    // 奇指针跳过偶结点
        odd = odd.next;
        even.next = odd.next;    // 偶指针跳过奇结点
        even = even.next;
    }
    odd.next = evenHead;         // 奇链尾接偶链头
    return head;
}
```

> 参考实现：[src/listTable/OddEvenList.java](../../src/listTable/OddEvenList.java)

## 五、复制带随机指针的链表（138 题）

每个结点除 `next` 外还有一个 `random` 指针。难点是：复制时 `random` 指向的结点可能还没被创建。

### 5.1 哈希映射法（仓库写法，直观）

**两趟遍历**：第一趟建所有新结点并建立"原结点 → 新结点"的映射；第二趟照着映射把 `next` 和 `random` 接好。

```java
public Node copyRandomList(Node head) {
    if (head == null) return null;
    Map<Node, Node> map = new HashMap<>();
    for (Node p = head; p != null; p = p.next)       // 第一趟：建新结点
        map.put(p, new Node(p.val));
    for (Node p = head; p != null; p = p.next) {     // 第二趟：接指针
        map.get(p).next = map.get(p.next);
        map.get(p).random = map.get(p.random);       // map.get(null) 返回 null，天然正确
    }
    return map.get(head);
}
```

> 参考实现：[src/listTable/CopyRandomList.java](../../src/listTable/CopyRandomList.java)、[src/listTable/CopyListTable.java](../../src/listTable/CopyListTable.java)。仓库用的就是哈希映射法（三趟写法，可合并为两趟）。空间 `O(n)`。

### 5.2 原地穿插法（`O(1)` 空间，进阶）

把每个新结点插到原结点后面（`A → A' → B → B' → …`），然后 `A'.random = A.random.next`，最后把两条链拆开。思路巧妙但易错，面试能说出思路即可。

*复制随机指针是【哈希映射 / 原地穿插】，关键突破点是【先建所有结点再接指针，解决"random 指向尚未创建的结点"的问题】，边界是【`map.get(null)` 返回 null，不用特判 random 为空】。*

## 六、链表排序（148 题）

要求 `O(n log n)` 时间、`O(1)` 空间——**首选归并排序**（自顶向下递归版最易写）：

```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    // ① 找前中点断链（注意 fast 从 head.next 出发取前中点）
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode mid = slow.next;
    slow.next = null;
    // ② 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(mid);
    // ③ 合并两条有序链表
    return merge(left, right);
}
private ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), cur = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else                  { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
```

**为什么链表排序偏爱归并而不是快排？** 链表不能 `O(1)` 随机访问，快排选 pivot 和分区都不方便；归并只需要"找中点 + 合并"，这两个操作链表都很擅长。**注意找中点必须取前中点**（`fast = head.next`），否则两个结点时会死循环。

> 参考实现：[src/listTable/SortList.java](../../src/listTable/SortList.java)、[src/listTable/InsertSortList.java](../../src/listTable/InsertSortList.java)（插入排序版，`O(n^2)`）

*链表排序是【自顶向下归并】，关键突破点是【链表擅长"找中点 + 合并"，所以用归并而非快排】，边界是【找中点取前中点，否则两结点死循环】。*

## 七、旋转链表（61 题）

把链表每个结点向右移 `k` 个位置。**技巧：先成环，再在正确位置断开**。

```java
public ListNode rotateRight(ListNode head, int k) {
    if (head == null || head.next == null || k == 0) return head;
    // ① 求长度并找到尾结点
    int len = 1;
    ListNode tail = head;
    while (tail.next != null) { tail = tail.next; len++; }
    // ② 成环
    tail.next = head;
    // ③ 新尾在 len - k%len - 1 处，它的 next 是新头
    k %= len;
    ListNode newTail = head;
    for (int i = 0; i < len - k - 1; i++) newTail = newTail.next;
    ListNode newHead = newTail.next;
    newTail.next = null;   // 断环
    return newHead;
}
```

**关键是 `k %= len`**：`k` 可能远大于链表长度，取模后才是实际要移动的步数。

> 参考实现：[src/listTable/RotateList.java](../../src/listTable/RotateList.java)、[src/listTable/RotateRight.java](../../src/listTable/RotateRight.java)
