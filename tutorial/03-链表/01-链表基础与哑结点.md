# 01 链表基础与哑结点

> **一句话理解**：链表题 80% 的 bug 都在"头结点要不要特判"。**哑结点（dummy node）就是用一个假的头，把"删头/改头"变成"删中间/改中间"，从而彻底消灭特判。**

---

## 一、链表的物理结构

数组在内存里是**连续**的一整块，链表是**散落**在各处、用指针串起来的：

```
数组：  [a][b][c][d]        ← 地址连续，下标直达
链表：  [a|·]→[b|·]→[c|·]→[d|null]   ← 每个节点存"值 + 下一个节点的地址"
```

正因为如此：
- **数组**随机访问快（`O(1)`），插入删除慢（要搬移，`O(n)`）
- **链表**随机访问慢（`O(n)`，要一个个走），插入删除快（`O(1)`，改指针即可）

---

## 二、遍历链表：最基础的循环

```java
ListNode pt = head;
while (pt != null) {
    // 处理 pt.val
    pt = pt.next;      // 前进一步
}
```

**铁律**：循环条件永远先判 `pt != null`，再访问 `pt.val` / `pt.next`。先访问后判空 = 空指针异常。

统计长度：

```java
int len = 0;
for (ListNode pt = head; pt != null; pt = pt.next) len++;
```

## 三、哑结点：链表题的头号武器

### 3.1 为什么需要哑结点

考虑"删除链表中所有值为 `val` 的结点"。如果头结点就是要删的：

```java
// ❌ 没有哑结点，要为"删头"单独写一段
while (head != null && head.val == val) head = head.next;  // 先处理开头的
ListNode pt = head;
while (pt != null && pt.next != null) {                    // 再处理中间的
    if (pt.next.val == val) pt.next = pt.next.next;
    else pt = pt.next;
}
return head;
```

用哑结点后，**头结点和中间结点用完全相同的逻辑**：

```java
// ✅ 哑结点统一逻辑，没有任何特判
public ListNode removeElements(ListNode head, int val) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode pt = dummy;              // 从哑结点开始
    while (pt.next != null) {
        if (pt.next.val == val) pt.next = pt.next.next;   // 删 = 跳过
        else pt = pt.next;
    }
    return dummy.next;                // 真正的头结点
}
```

> 参考实现：[src/listTable/RemoveElement.java](../../src/listTable/RemoveElement.java)

### 3.2 哑结点的三步固定套路

```java
ListNode dummy = new ListNode(0);   // ① 建一个假头，值随便
dummy.next = head;                  // ② 指向真头
// ... 用 pt 从 dummy 开始操作 ...
return dummy.next;                  // ③ 返回真头（可能已经变了）
```

**判断标准：只要你的操作"可能改变或删除头结点"，就无脑加哑结点。** 这是经验丰富者和新手的分水岭。

## 四、删除结点的几种情形

### 4.1 删除倒数第 N 个结点（哑结点 + 快慢指针）

**核心技巧**：让快指针先走 N 步，然后快慢一起走，快指针到末尾时，慢指针恰好停在"待删结点的前一个"。

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next;   // 快指针先走 n 步
    while (fast.next != null) {                     // 一起走到末尾
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;                     // slow 停在待删结点前一个
    return dummy.next;
}
```

> 参考实现：[src/listTable/RemoveNthFromEnd.java](../../src/listTable/RemoveNthFromEnd.java)。该文件保留了**三种写法**：`removeNthFromEnd`（双指针，最优）、`removeNthFromEnd2`（栈，直观但费空间）、`removeNthFromEnd3`（先求长度再定位，两次遍历）。**面试首选双指针版——一次遍历、`O(1)` 空间。**

**为什么从 `dummy` 出发而不是 `head`？** 当要删的恰好是头结点时，`slow` 要停在 `dummy`，才能用 `slow.next = slow.next.next` 把头删掉。从 `head` 出发就处理不了这种情况。

### 4.2 删除排序链表中的重复元素

**保留一个**（83 题）：

```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode pt = head;
    while (pt != null && pt.next != null) {
        if (pt.val == pt.next.val) pt.next = pt.next.next;  // 跳过重复
        else pt = pt.next;
    }
    return head;   // 头结点一定保留，不需要哑结点
}
```

**一个都不留**（82 题，重复的全删）：这时头结点可能被删，**必须用哑结点**。

```java
public ListNode deleteDuplicates(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode pre = dummy, cur = head;
    while (cur != null) {
        while (cur.next != null && cur.val == cur.next.val) cur = cur.next;  // 跳到重复段的最后一个
        if (pre.next == cur) pre = pre.next;        // 没有重复，pre 正常前进
        else pre.next = cur.next;                   // 有重复，整段跳过
        cur = cur.next;
    }
    return dummy.next;
}
```

> 参考实现：[src/listTable/DeleteDuplicates.java](../../src/listTable/DeleteDuplicates.java)、[src/listTable/DeleteDuplicates2.java](../../src/listTable/DeleteDuplicates2.java)、[src/listTable/DeleteDuplicates3.java](../../src/listTable/DeleteDuplicates3.java)

### 4.3 "只给待删结点"的脑筋急转弯（237 题）

题目**不给头结点**，只给你要删的那个结点（且保证不是尾结点）。既然走不到前一个，就**把下一个结点的值复制过来，然后删掉下一个**：

```java
public void deleteNode(ListNode node) {
    node.val = node.next.val;       // 偷梁换柱：把下家的值搬过来
    node.next = node.next.next;     // 再把下家删掉
}
```

> 参考实现：[src/listTable/DeleteNode.java](../../src/listTable/DeleteNode.java)

*这题是【值覆盖替代删除】，关键突破点是【删不了自己就删下家、把下家的值搬过来】，边界是【题目保证待删结点不是尾结点，否则此法失效】。*

## 五、设计链表（707 题）：双链表 + 双哨兵

设计题要实现 `get`/`addAtHead`/`addAtTail`/`addAtIndex`/`deleteAtIndex`。用**双向链表 + 头尾两个哨兵节点**最省心：任何插入/删除都不用判断"是不是在边界"，因为哨兵保证了每个真实节点两侧都有节点。

```java
class MyLinkedList {
    static class Node {
        int val; Node prev, next;
        Node(int val) { this.val = val; }
    }
    private int size;
    private Node head, tail;   // 两个哨兵

    public MyLinkedList() {
        head = new Node(-1);
        tail = new Node(-1);
        head.next = tail;      // 初始：head <-> tail
        tail.prev = head;
    }

    public int get(int index) {
        if (index < 0 || index >= size) return -1;
        Node p = head.next;
        while (index-- > 0) p = p.next;
        return p.val;
    }

    public void addAtHead(int val) { addBefore(head.next, val); }
    public void addAtTail(int val) { addBefore(tail, val); }

    public void addAtIndex(int index, int val) {
        if (index > size) return;
        if (index < 0) index = 0;
        Node p = head.next;
        while (index-- > 0) p = p.next;
        addBefore(p, val);
    }

    public void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;
        Node p = head.next;
        while (index-- > 0) p = p.next;
        p.prev.next = p.next;
        p.next.prev = p.prev;
        size--;
    }

    private void addBefore(Node cur, int val) {   // 在 cur 之前插入
        Node node = new Node(val);
        node.prev = cur.prev;
        node.next = cur;
        cur.prev.next = node;
        cur.prev = node;
        size++;
    }
}
```

> 参考实现：[src/listTable/MyLinkedList.java](../../src/listTable/MyLinkedList.java)。仓库版本就是这个思路（`head`/`tail` 双哨兵），**双哨兵是双链表设计题的标准答案**——它让插入删除永远不碰边界。

*设计链表是【双链表 + 双哨兵】，关键突破点是【头尾哨兵让所有操作无需判断边界】，边界是【`addAtIndex` 的 `index == size` 要允许（追加到末尾），`index > size` 要拒绝】。*
