# 01 DP 五步法与入门

> **一句话理解**：DP 入门题的核心是**学会定义 `dp[i]`**。只要能用一句话说清"`dp[i]` 代表什么"，转移方程往往就自己浮现了。本节用爬楼梯和打家劫舍把五步法走通。

---

## 一、从暴力到 DP：爬楼梯的三重境界

**题目（70 题）**：爬 `n` 阶楼梯，每次爬 1 或 2 阶，有多少种方法？

### 境界一：暴力递归（会超时）

要到第 `n` 阶，最后一步要么从 `n-1` 阶跨 1 步、要么从 `n-2` 阶跨 2 步，所以：

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    return climbStairs(n - 1) + climbStairs(n - 2);   // O(2^n)，爆炸
}
```

画出递归树会发现 `climbStairs(n-2)` 被反复计算——**这正是 DP 的信号**。

### 境界二：记忆化递归（自顶向下）

把算过的结果存进 `memo`，重复调用直接查表：

```java
int[] memo;
int climbStairs(int n) {
    memo = new int[n + 1];
    return dfs(n);
}
int dfs(int n) {
    if (n <= 2) return n;
    if (memo[n] != 0) return memo[n];          // 查表命中
    return memo[n] = dfs(n - 1) + dfs(n - 2);  // 算一次就存
}
```

### 境界三：递推填表（自底向上，面试首选）

```java
int climbStairs(int n) {
    if (n <= 2) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1;
    dp[2] = 2;
    for (int i = 3; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

> 参考实现：[src/dp/ClimbStair.java](../../src/dp/ClimbStair.java)（递推版）、[src/dp/ClimbStairs.java](../../src/dp/ClimbStairs.java)

**三重境界的本质是同一个转移方程 `dp[i] = dp[i-1] + dp[i-2]`，只是实现方式不同。** 面试时直接写境界三。

## 二、用五步法完整解一道题

还是爬楼梯，走一遍五步法：

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i]` = 爬到第 `i` 阶的方法数 |
| **2. 转移方程** | `dp[i] = dp[i-1] + dp[i-2]`（最后一步跨 1 或 2） |
| **3. 初始化** | `dp[1] = 1`（一种：跨 1）；`dp[2] = 2`（两种：1+1 或 2） |
| **4. 遍历顺序** | `i` 从 3 到 `n`，正序（因为 `dp[i]` 依赖更小的下标） |
| **5. 手推验证** | `dp = [_,1,2,3,5,8,...]`，正是斐波那契，✓ |

**第 1 步最关键**：如果你把 `dp[i]` 定义成"从第 `i` 阶往上爬的方法数"，转移方程就完全不同了。**定义决定一切。**

## 三、使用最小花费爬楼梯（746 题）

**题目**：每阶有花费 `cost[i]`，踏上该阶要付费，可从 0 或 1 阶起步，求到达楼顶的最小花费。

```java
int minCostClimbingStairs(int[] cost) {
    int n = cost.length;
    int[] dp = new int[n + 1];   // dp[i] = 到达第 i 阶的最小花费
    dp[0] = 0;                   // 可从 0 阶起步，不花钱
    dp[1] = 0;                   // 也可从 1 阶起步，不花钱
    for (int i = 2; i <= n; i++)
        dp[i] = Math.min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
    return dp[n];                // 楼顶是第 n 阶（在最后一级之上）
}
```

**和爬楼梯的区别**：这里 `dp[i]` 从"方法数"变成了"最小花费"，转移里的 `+` 变成了 `Math.min`。**求最值类 DP 的转移方程通常是 `min`/`max`，求方案数类通常是 `+`——这是一条重要的直觉规律。**

> 参考实现：[src/dp/MinCostClimbingStairs.java](../../src/dp/MinCostClimbingStairs.java)

## 四、打家劫舍 I（198 题）：DP 入门的"必刷题"

**题目**：沿街房屋各有金额 `nums[i]`，**不能偷相邻两家**，求最多能偷多少。

**五步法**：

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i]` = 偷到第 `i` 家为止能获得的最大金额 |
| **2. 转移方程** | `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` |
| **3. 初始化** | `dp[0] = nums[0]`；`dp[1] = max(nums[0], nums[1])` |
| **4. 遍历顺序** | 正序，`i` 从 2 到 `n-1` |
| **5. 手推** | `nums=[2,7,9,3,1]` → `dp=[2,7,11,11,12]` → 答案 12 ✓ |

**转移方程的直觉**：到第 `i` 家时只有两个选择——
- **不偷**第 `i` 家：收益就是 `dp[i-1]`
- **偷**第 `i` 家：那第 `i-1` 家不能偷，收益是 `dp[i-2] + nums[i]`

取两者较大值即可。

```java
int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;
    if (n == 1) return nums[0];
    int[] dp = new int[n];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);
    for (int i = 2; i < n; i++)
        dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
    return dp[n - 1];
}
```

> 参考实现：[src/dp/Rob1.java](../../src/dp/Rob1.java)。仓库版本用 `dp[len+1]`、`dp[1] = nums[0]` 的"偏移一位"写法（`dp[i]` 对应前 `i` 家），也完全正确——**偏移下标是 DP 的常见技巧，用来避免 `dp[-1]` 这种越界，关键是全程保持一致。**

### 滚动数组优化到 O(1) 空间

`dp[i]` 只依赖前两个值，用两个变量滚动即可：

```java
int rob(int[] nums) {
    int prev = 0, curr = 0;    // prev = dp[i-2], curr = dp[i-1]
    for (int num : nums) {
        int next = Math.max(curr, prev + num);
        prev = curr;
        curr = next;
    }
    return curr;
}
```

> 参考实现：[src/dp/Rob4.java](../../src/dp/Rob4.java)（空间优化版）

*打家劫舍是【选 / 不选的线性 DP】，关键突破点是【`dp[i]` 定义为"前 i 家的最大收益"，转移是"偷不偷第 i 家"二选一取 max】，边界是【n=0 返回 0，n=1 返回 nums[0]】。*

## 五、不同路径（62 / 63 题）：二维 DP 入门

**题目**：`m×n` 网格，机器人从左上走到右下，只能向右或向下，有多少条路径？

```java
int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    for (int i = 0; i < m; i++) dp[i][0] = 1;   // 第一列只有一条路（一直向下）
    for (int j = 0; j < n; j++) dp[0][j] = 1;   // 第一行只有一条路（一直向右）
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];   // 从上面来 + 从左面来
    return dp[m - 1][n - 1];
}
```

**二维 DP 的套路和一维一样**，只是 `dp[i][j]` 的定义变成了"走到格子 `(i,j)` 的方法数"，转移方程体现"当前格子只能从上方或左方到达"。63 题"有障碍"版只需在障碍格把 `dp[i][j] = 0` 即可。

> 参考实现：[src/dp/PathNum.java](../../src/dp/PathNum.java)、[src/dp/PathNum2.java](../../src/dp/PathNum2.java)、[src/dp/UniquePathObstacles.java](../../src/dp/UniquePathObstacles.java)（含障碍版）

## 六、解码方法（91 题）：带约束的计数 DP

**题目**：数字串按 `A=1...Z=26` 解码，求解码方法数。类似爬楼梯，但**每一步有合法性约束**。

```java
int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1];
    dp[0] = 1;                                     // 空串算一种
    dp[1] = s.charAt(0) == '0' ? 0 : 1;
    for (int i = 2; i <= n; i++) {
        int one = s.charAt(i - 1) - '0';           // 当前 1 位
        int two = (s.charAt(i - 2) - '0') * 10 + one;  // 当前 2 位
        if (one >= 1 && one <= 9) dp[i] += dp[i - 1];   // 单独解码
        if (two >= 10 && two <= 26) dp[i] += dp[i - 2]; // 两位一起解码
    }
    return dp[n];
}
```

**比爬楼梯多的只是"合法性判断"**：单字符不能是 `0`，两字符要在 `10~26` 之间。这是"爬楼梯模型 + 约束条件"的典型变体。

> 参考实现：[src/dp/Decoding.java](../../src/dp/Decoding.java)

*解码方法是【带约束的计数 DP（爬楼梯变体）】，关键突破点是【转移时判断当前 1 位和 2 位是否合法，合法才累加】，边界是【前导 0 不能单独解码，`00` 这类无解】。*
