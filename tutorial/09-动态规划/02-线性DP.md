# 02 线性 DP

> **一句话理解**：线性 DP 是 `dp` 按一维/二维"线性推进"的问题。一维看 `dp[i]`（最大子数组、LIS），二维看 `dp[i][j]`（两个序列的 LCS、编辑距离）。**二维 DP 的本质就是"两个指针各走一个序列"。**

---

## 一、最大子数组和（53 题）：一维 DP 的典范

**题目**：求连续子数组的最大和。

**五步法**：

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i]` = **以 `nums[i]` 结尾**的最大子数组和（注意：必须以 `i` 结尾！） |
| **2. 转移方程** | `dp[i] = max(dp[i-1] + nums[i], nums[i])` |
| **3. 初始化** | `dp[0] = nums[0]` |
| **4. 遍历顺序** | 正序 |
| **5. 答案** | 不是 `dp[n-1]`，而是 `max(dp)`——最大子数组可以在任何位置结尾 |

**定义的精妙之处**：为什么是"以 `i` 结尾"而不是"前 `i` 个的最大和"？因为"以 `i` 结尾"才能写出转移方程——要么把前面的接上（`dp[i-1] + nums[i]`），要么前面是负贡献、自己另起炉灶（`nums[i]`）。

```java
int maxSubArray(int[] nums) {
    int sum = 0, res = nums[0];
    for (int num : nums) {
        sum = sum > 0 ? sum + num : num;   // 等价于 max(sum+num, num)
        res = Math.max(res, sum);
    }
    return res;
}
```

> 参考实现：[src/dp/MaxSubArray.java](../../src/dp/MaxSubArray.java)。仓库里 `maxSubArray` 是上面的 `O(n)` 滚动版（最优），`maxSubArray2` 是 `O(n²)` 区间 DP 版——**保留两个版本对比，正是好的学习习惯**：后者直观但慢，前者是贪心式的 DP 优化。

*最大子数组和是【以 i 结尾的一维 DP】，关键突破点是【`dp[i]` 定义为"以 i 结尾"才能写出转移，答案取 `max(dp)` 而非 `dp[n-1]`】，边界是【全负数组答案是最大的那个负数】。*

**变体：乘积最大子数组（152 题）**。因为负负得正，必须**同时维护最大和最小两个 `dp`**（最小的乘上负数可能变最大）。见 [src/dp/MaxMulSubArray.java](../../src/dp/MaxMulSubArray.java)。

## 二、最长递增子序列 LIS（300 题）

**题目**：求最长**严格递增子序列**的长度（子序列可不连续）。

### 2.1 O(n²) 动态规划（必须掌握）

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长度 |
| **2. 转移方程** | `dp[i] = max(dp[j] + 1)`，其中 `j < i` 且 `nums[j] < nums[i]` |
| **3. 初始化** | 全部 `dp[i] = 1`（每个元素自成长度 1） |
| **4. 遍历顺序** | 外层 `i` 正序，内层 `j` 从 0 到 `i-1` |
| **5. 答案** | `max(dp)` |

```java
int lengthOfLIS(int[] nums) {
    int n = nums.length, res = 1;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        res = Math.max(res, dp[i]);
    }
    return res;
}
```

> 参考实现：[src/dp/LongestIncreaseSequence.java](../../src/dp/LongestIncreaseSequence.java)

### 2.2 O(n log n) 贪心 + 二分（进阶）

维护一个 `tails` 数组，`tails[k]` 表示长度为 `k+1` 的递增子序列的最小结尾。对每个数二分查找它该放的位置：

```java
int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int num : nums) {
        int lo = 0, hi = size;
        while (lo < hi) {                    // 二分找第一个 >= num 的位置
            int mid = (lo + hi) >>> 1;
            if (tails[mid] < num) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = num;                     // 替换或追加
        if (lo == size) size++;
    }
    return size;
}
```

**面试策略**：先讲 `O(n²)` DP（人人都该会），再提"可以用贪心 + 二分优化到 `O(n log n)`"作为加分。

*LIS 是【以 i 结尾的 DP / 贪心+二分】，关键突破点是【`dp[i]` 依赖所有满足 `nums[j]<nums[i]` 的 `dp[j]`；进阶用 tails 数组保持"同长度最小结尾"】，边界是【空数组返回 0，每个 dp 初始为 1】。*

**相关题**：[最长连续递增序列 674](../../src/dp/MaxContinueSeq.java)（连续，`O(n)`）、[最长数对链 646](../../src/dp/LongestChain.java)、[最长字符串链 1048](../../src/dp/LongestStrChain.java)、[最长斐波那契子序列 873](../../src/dp/LongestFib.java)。

## 三、最长公共子序列 LCS（1143 题）：二维 DP 的模板

**题目**：求两个字符串的最长公共子序列长度。

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i][j]` = `text1` 前 `i` 个字符和 `text2` 前 `j` 个字符的 LCS 长度 |
| **2. 转移方程** | 若 `text1[i-1]==text2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`；否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` |
| **3. 初始化** | `dp[0][*] = dp[*][0] = 0`（空串与任何串的 LCS 为 0） |
| **4. 遍历顺序** | 两层正序 |
| **5. 答案** | `dp[m][n]` |

```java
int longestCommonSubsequence(String t1, String t2) {
    int m = t1.length(), n = t2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (t1.charAt(i - 1) == t2.charAt(j - 1))
                dp[i][j] = dp[i - 1][j - 1] + 1;         // 当前字符匹配，LCS 加 1
            else
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]); // 不匹配，取较优
        }
    return dp[m][n];
}
```

**二维 DP 的通用直觉**：`dp[i][j]` 表示"两个序列各取前缀"的答案，转移时讨论"当前两个字符相不相等"。**这个模板是编辑距离、不同子序列、删除操作等一大类题的母版。**

> 参考实现：[src/dp/CommonLength.java](../../src/dp/CommonLength.java)（最长公共**子数组**，要求连续，转移略有不同）、[src/dp/MaxUncrossedLines.java](../../src/dp/MaxUncrossedLines.java)（不相交的线，本质就是 LCS）

> ⚠️ **区分子序列和子数组**：LCS（子序列，可不连续）不匹配时取 `max(dp[i-1][j], dp[i][j-1])`；最长公共子数组（必须连续，见 `CommonLength`）不匹配时直接 `dp[i][j] = 0`，答案取全表最大值。

*LCS 是【二维 DP 母版】，关键突破点是【`dp[i][j]` 用两个前缀定义，转移讨论当前字符是否相等】，边界是【第 0 行第 0 列为 0，下标 `i` 对应字符 `i-1`】。*

## 四、编辑距离（72 题，Hard）：二维 DP 的巅峰

**题目**：把 `word1` 变成 `word2`，可插入/删除/替换一个字符，求最少操作数。

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i][j]` = `word1` 前 `i` 个变成 `word2` 前 `j` 个的最少操作数 |
| **2. 转移方程** | 字符相等：`dp[i][j]=dp[i-1][j-1]`；不等：`dp[i][j]=1+min(删, 增, 替)` |
| **3. 初始化** | `dp[i][0]=i`（删 i 次）；`dp[0][j]=j`（增 j 次） |
| **4. 遍历顺序** | 两层正序 |
| **5. 答案** | `dp[m][n]` |

```java
int minDistance(String w1, String w2) {
    int m = w1.length(), n = w2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;   // w1 删到空
    for (int j = 0; j <= n; j++) dp[0][j] = j;   // 空补成 w2
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (w1.charAt(i - 1) == w2.charAt(j - 1))
                dp[i][j] = dp[i - 1][j - 1];     // 相等，无需操作
            else
                dp[i][j] = 1 + Math.min(dp[i - 1][j - 1],              // 替换
                                Math.min(dp[i - 1][j], dp[i][j - 1])); // 删除 / 插入
        }
    return dp[m][n];
}
```

**三个来源对应三种操作**（这是编辑距离最难理解、也最重要的点）：

| 来源 | 操作 | 含义 |
| --- | --- | --- |
| `dp[i-1][j-1]` | 替换 | 把 `word1[i-1]` 换成 `word2[j-1]` |
| `dp[i-1][j]` | 删除 | 删掉 `word1[i-1]`，剩下 `i-1` 个去匹配 `j` 个 |
| `dp[i][j-1]` | 插入 | 在 `word1` 后插入 `word2[j-1]`，剩 `i` 个匹配 `j-1` 个 |

> 参考实现：[src/dp/EditDistance.java](../../src/dp/EditDistance.java)。该文件同时保留了 `editDistance`（二维 DP）和 `editDistance_recursive`（纯递归，会超时）——**暴力递归和 DP 放一起对比，能清楚看到"记忆化"消除了多少重复子问题。**

*编辑距离是【二维 DP 的三操作合并】，关键突破点是【字符不等时取"删/增/替"三个来源的最小值 +1】，边界是【第 0 行第 0 列分别初始化为 j 和 i（空串变换代价）】。*

**同类题**：[两个字符串的删除操作 583](../../src/dp/DeleteWords.java)（只能删，答案 = `m+n-2*LCS`）、[不同的子序列 115](../../src/dp/DistinctSubStr.java)、[两个字符串的最小 ASCII 删除和 712](../../src/dp/MinSteps.java)。
