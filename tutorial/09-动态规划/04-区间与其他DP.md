# 04 区间与其他 DP

> **一句话理解**：这一节是 DP 的"进阶形态"——**区间 DP**（`dp[i][j]` 表示区间 `[i,j]` 的解，从小区间推大区间）、**状态机 DP**（股票买卖，用"持有/不持有"做状态）、**树形 DP**（在树上做 DP，后序位置返回多个状态）。

---

## 一、区间 DP：从小区间推大区间

**特征**：`dp[i][j]` 表示区间 `[i, j]` 的解，大区间的答案由小区间组合而来。**遍历顺序特殊——必须保证算 `dp[i][j]` 时，更小的区间已经算好**，所以通常 `i` 逆序、`j` 正序，或按区间长度从小到大枚举。

### 1.1 最长回文子序列（516 题）

**题目**：求字符串最长回文**子序列**（可不连续）的长度。

| 步骤 | 内容 |
| --- | --- |
| **1. dp 含义** | `dp[i][j]` = 子串 `s[i..j]` 的最长回文子序列长度 |
| **2. 转移方程** | `s[i]==s[j]`：`dp[i][j]=dp[i+1][j-1]+2`；否则 `dp[i][j]=max(dp[i+1][j], dp[i][j-1])` |
| **3. 初始化** | `dp[i][i]=1`（单字符自成回文） |
| **4. 遍历顺序** | **`i` 从大到小、`j` 从小到大**（因为依赖 `i+1` 和 `j-1`） |
| **5. 答案** | `dp[0][n-1]` |

```java
int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int i = n - 1; i >= 0; i--)          // ★ i 必须逆序
        for (int j = i + 1; j < n; j++) {     // j 正序
            if (s.charAt(i) == s.charAt(j)) dp[i][j] = dp[i + 1][j - 1] + 2;
            else dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
        }
    return dp[0][n - 1];
}
```

> 参考实现：[src/dp/LongestSubPalindrome.java](../../src/dp/LongestSubPalindrome.java)（仓库实现与此完全一致）

**为什么 `i` 要逆序？** 转移用到 `dp[i+1][...]`——`i+1` 比 `i` 大，必须先算好。所以外层 `i` 从 `n-1` 往 0 走，才能保证"更小区间先于更大区间计算"。**这是区间 DP 的通用注意点。**

*最长回文子序列是【区间 DP】，关键突破点是【`dp[i][j]` 定义为区间 `[i,j]` 的解，依赖 `dp[i+1][j-1]`，所以 i 逆序 j 正序】，边界是【单字符 dp[i][i]=1】。*

### 1.2 最长回文子串（5 题）

**子串要求连续**，和子序列的转移不同。`dp[i][j]` 表示 `s[i..j]` **是否**是回文：`dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1]`。另一种更直观的解法是**中心扩展**（枚举每个中心向两边扩）。

> 参考实现：[src/dp/LongestPalindrome.java](../../src/dp/LongestPalindrome.java)、[src/dp/LongestSubString.java](../../src/dp/LongestSubString.java)

## 二、股票买卖系列：状态机 DP

股票系列是 DP 的一个独立"宇宙"，但万变不离其宗——**用"每天是否持有股票"作为状态**。

### 2.1 通用状态定义

```
dp[i][0] = 第 i 天结束时【不持有】股票的最大利润
dp[i][1] = 第 i 天结束时【持有】股票的最大利润
```

**转移方程**（含手续费 fee 版，714 题）：

```
dp[i][0] = max(dp[i-1][0],              // 昨天就不持有，今天啥也不干
               dp[i-1][1] + prices[i] - fee)   // 昨天持有，今天卖出（扣手续费）
dp[i][1] = max(dp[i-1][1],              // 昨天就持有，今天继续持有
               dp[i-1][0] - prices[i])  // 昨天不持有，今天买入
```

```java
int maxProfit(int[] prices, int fee) {
    int n = prices.length;
    int[][] dp = new int[n][2];
    dp[0][1] = -prices[0];               // 第 0 天买入
    for (int i = 1; i < n; i++) {
        dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i] - fee);
        dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
    }
    return dp[n - 1][0];                  // 最后一天手里没股票利润最大
}
```

> 参考实现：[src/dp/MaxProfit.java](../../src/dp/MaxProfit.java)。该文件同时给了 `maxProfit`（贪心）和 `maxProfit2`（状态机 DP），并在注释里写清了每个状态的转移含义——**是学习状态机 DP 的绝佳范例**。

### 2.2 整个股票系列的套路

| 题号 | 变化 | 状态怎么改 |
| --- | --- | --- |
| 121 买卖一次 | 只能买卖 1 次 | 买入时利润直接是 `-prices[i]`（不叠加之前利润） |
| 122 买卖多次 | 无限次 | 本节模板去掉 fee |
| 714 含手续费 | 卖出扣 fee | 本节模板 |
| 309 含冷冻期 | 卖出后 1 天不能买 | 加一个"冷冻"状态，或买入时用 `dp[i-2][0]` |
| 123 / 188 限 k 次 | 最多 k 次交易 | 状态加一维 `dp[i][k][0/1]` |

**面试策略**：掌握"持有/不持有"二状态模板，其余都是在它上面加状态维度。

*股票买卖是【状态机 DP】，关键突破点是【用"当天是否持有"做状态，转移枚举买/卖/不动】，边界是【第 0 天持有状态初始化为 `-prices[0]`，最后返回不持有状态】。*

## 三、矩阵路径类 DP

### 3.1 最小路径和（64 题）

```java
int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    dp[0][0] = grid[0][0];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i - 1][0] + grid[i][0];  // 第一列
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j - 1] + grid[0][j];  // 第一行
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
    return dp[m - 1][n - 1];
}
```

> 参考实现：[src/dp/MinPathSum.java](../../src/dp/MinPathSum.java)

### 3.2 三角形最小路径和（120 题）

从顶到底，每步只能走到下一行相邻的两个数之一。`dp[i][j] = min(dp[i-1][j-1], dp[i-1][j]) + triangle[i][j]`。

> 参考实现：[src/dp/MinTotal.java](../../src/dp/MinTotal.java)、[src/dp/MinFallingPathSum.java](../../src/dp/MinFallingPathSum.java)（下降路径最小和 931 题）

### 3.3 最大正方形（221 题）

`dp[i][j]` 表示以 `(i,j)` 为右下角的最大正方形边长：`dp[i][j] = min(左, 上, 左上) + 1`（当前格为 1 时）。**"三个方向取最小 +1"是正方形类问题的经典转移。**

> 参考实现：[src/dp/MaxSquare.java](../../src/dp/MaxSquare.java)

## 四、树形 DP：在树上做动态规划

**特征**：DP 发生在树上，`dp` 状态挂在节点上，用**后序遍历**（见 [10 树](../10-树/01-树的遍历与递归思维.md) 的后序位置）自底向上收集子树信息。

### 打家劫舍 III（337 题）

**题目**：二叉树上的房屋，不能偷相邻父子，求最大金额。

**每个节点返回两个状态**：偷它、不偷它。

```java
public int rob(TreeNode root) {
    int[] res = dfs(root);
    return Math.max(res[0], res[1]);
}
// 返回 [不偷当前节点的最大值, 偷当前节点的最大值]
private int[] dfs(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] left = dfs(node.left);
    int[] right = dfs(node.right);
    // 偷当前节点：当前值 + 左右孩子都不偷
    int rob = node.val + left[0] + right[0];
    // 不偷当前节点：左右孩子各取"偷或不偷"的较大值
    int notRob = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
    return new int[]{notRob, rob};
}
```

**树形 DP 的精髓**：在**后序位置**（左右子树都算完）才能综合子树的状态推出当前节点的状态。返回值用数组/对象携带多个状态，是树形 DP 的标志性写法。

> 参考实现：[src/dp/Rob3.java](../../src/dp/Rob3.java)。仓库版本用两个 `HashMap`（`fMap` 偷、`gMap` 不偷）存状态，思路相同；上面的"返回 `int[]` 数组"写法省去哈希表、更简洁高效，是推荐版本。

*打家劫舍 III 是【树形 DP】，关键突破点是【每个节点在后序位置返回"偷/不偷"两个状态，父节点据此决策】，边界是【空节点返回 {0,0}】。*
