## 零、面试手写和刷题的区别

### 0.1 面试官在看什么

| 维度 | 权重 | 表现 |
| --- | --- | --- |
| **思路是否清晰** | 30% | 先说方案再写，不是边写边想 |
| **代码是否正确** | 30% | 边界、空值、溢出、并发 |
| **可读性** | 20% | 命名、分层、注释 |
| **沟通** | 20% | 边写边解释，卡住会求助 |

**残酷事实**：**写不出来 = 直接挂；写得出来但讲不清 = 降级。** 两者都要练。

### 0.2 和刷题的三点差异

| 刷题 | 面试手写 |
| --- | --- |
| 有 IDE 补全和报错 | 纯文本，语法错误自己发现 |
| 可以反复提交 | 一次成型 |
| 只看结果 | 看过程、看边界、看沟通 |

**所以练习方式要改**：用纸/纯文本编辑器写，不运行，写完自己"人肉编译"。

### 0.3 高频手写题型分布（国内后端）

```
算法类   40%   排序、二分、链表、二叉树、字符串、TopK
并发类   30%   单例、生产者消费者、交替打印、阻塞队列、限流器
设计类   20%   LRU、循环队列、最小栈、Trie、栈实现队列
其他     10%   大数相加、区间合并、矩阵
```

**并发类是最大盲区**——很多人算法刷了几百题，却写不出一个正确的生产者消费者。

## 一、白板流程：六步法

### 第 1 步：确认题意（30 秒）

```
"我理解是……，输入范围是……，需要处理空数组吗？"
```

**必须问的**：输入规模、是否有序、有无重复、返回值形式、是否允许修改原数组。

### 第 2 步：举例（30 秒）

写一个**小但有代表性**的样例，手动走一遍。**这一步能暴露 80% 的边界问题。**

### 第 3 步：说思路（1 分钟）

```
"最直接是 O(n^2) 的暴力；但这题可以用哈希降到 O(n)，空间换时间。我写这个版本。"
```

**先说暴力再说优化**，既展示思维过程，也给自己留后路。

### 第 4 步：写代码（5~8 分钟）

**边写边解释**，每一段说一句"这里是为了……"。

### 第 5 步：手动跑样例（1 分钟）

**逐行代入**，说出变量的值。这一步能抓出 90% 的低级错误。

### 第 6 步：复杂度与边界（30 秒）

```
"时间 O(n)，空间 O(n)。边界我处理了空数组、单元素、以及 target 不存在的情况。"
```

### 常见扣分点

| 扣分 | 怎么避免 |
| --- | --- |
| 一上来就写 | 先问 + 举例 |
| 变量名 a/b/c | 用 `left/right/slow/fast/prev/cur` |
| 不处理空输入 | 第一行写 `if (arr == null \|\| arr.length == 0)` |
| 越界 | 写完检查所有 `+1/-1` |
| 死循环 | 检查 `while` 的推进条件 |
| 不解释 | 每段加一句注释或口头说明 |

## 二、算法类手写（12 题）

### 2.1 二分查找（左边界）

**考察**：边界处理、死循环。

```java
/** 返回第一个 >= target 的下标；不存在返回 arr.length */
public int lowerBound(int[] arr, int target) {
    int left = 0, right = arr.length;          // 左闭右开
    while (left < right) {
        int mid = left + (right - left) / 2;   // 防溢出
        if (arr[mid] >= target) {
            right = mid;                       // 满足，尝试更左
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```

**追问**：

- 找最后一个 `<= target`？→ 反向收缩 + `mid` 向上取整。
- 有重复元素？→ 左边界模板天然去重。
- 为什么 `left + (right - left)/2`？→ 防 `left + right` 溢出。

**易错**：`while (left <= right)` 配 `right = mid` 会死循环；模板要整套换，不能混。

### 2.2 快速排序

**考察**：分治、递归、随机化。

```java
public void quickSort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = arr[lo + (int) (Math.random() * (hi - lo + 1))];
    int lt = lo, i = lo, gt = hi;              // 三路划分
    while (i <= gt) {
        if (arr[i] < pivot) swap(arr, lt++, i++);
        else if (arr[i] > pivot) swap(arr, i, gt--);
        else i++;
    }
    quickSort(arr, lo, lt - 1);
    quickSort(arr, gt + 1, hi);
}
```

**追问**：

- 为什么随机 pivot？→ 避免有序数组退化为 `O(n^2)`。
- 三路划分的好处？→ 大量重复元素时不退化。
- 稳定性？→ 不稳定；要稳定用归并。

### 2.3 归并排序 + 求逆序对

**考察**：分治、辅助数组、统计。

```java
private int count = 0;
private int[] temp;

public int reversePairs(int[] arr) {
    temp = new int[arr.length];
    sort(arr, 0, arr.length - 1);
    return count;
}

private void sort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    sort(arr, lo, mid);
    sort(arr, mid + 1, hi);
    merge(arr, lo, mid, hi);
}

private void merge(int[] arr, int lo, int mid, int hi) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            count += mid - i + 1;              // 关键：右边小，左边剩余都构成逆序
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= hi) temp[k++] = arr[j++];
    System.arraycopy(temp, lo, arr, lo, hi - lo + 1);
}
```

**追问**：为什么 `count += mid - i + 1`？→ 右边元素比左边剩余所有元素都小。

**易错**：忘记写回原数组；`<=` 写成 `<` 会丢稳定性。

### 2.4 TopK（小顶堆）

**考察**：堆、复杂度取舍。

```java
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();   // 小顶堆
    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) minHeap.poll();               // 只留最大的 k 个
    }
    return minHeap.peek();
}
```

**追问**：

- 复杂度？→ `O(n log k)`，空间 `O(k)`。
- 更快？→ 快速选择平均 `O(n)`，但会打乱数组。
- 数据流？→ 必须用堆。

### 2.5 反转链表（迭代 + 递归）

```java
// 迭代：三指针
public ListNode reverse(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

// 递归
public ListNode reverseRec(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseRec(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}
```

**追问**：

- 反转区间 `[m,n]`？→ 定位 + 断链 + 接回。
- K 个一组？→ 先数够不够 K 个，再反转。
- 递归的空间？→ `O(n)` 栈。

### 2.6 二叉树非递归遍历

```java
// 前序
public List<Integer> preorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);
        if (node.right != null) stack.push(node.right);   // 先右后左
        if (node.left != null) stack.push(node.left);
    }
    return res;
}

// 中序
public List<Integer> inorder(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}

// 后序：前序变体（根右左）再反转
public List<Integer> postorder(TreeNode root) {
    LinkedList<Integer> res = new LinkedList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    if (root != null) stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.addFirst(node.val);                            // 头插
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    return res;
}
```

**追问**：中序为什么不能像前序那样简单？→ 要先走到最左，需要"访问后再转向右子树"。

### 2.7 层序遍历（按层分组）

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();                               // 关键：固定本层数量
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 2.8 大数相加（字符串）

```java
public String addStrings(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry > 0) {
        int x = i >= 0 ? a.charAt(i--) - '0' : 0;
        int y = j >= 0 ? b.charAt(j--) - '0' : 0;
        int sum = x + y + carry;
        sb.append(sum % 10);
        carry = sum / 10;
    }
    return sb.reverse().toString();
}
```

**追问**：相乘？→ 双重循环 + 结果数组 `num1[i] * num2[j]` 累加到 `i+j+1`，再统一处理进位。

### 2.9 合并区间

```java
public int[][] merge(int[][] intervals) {
    if (intervals.length == 0) return new int[0][];
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> res = new ArrayList<>();
    int[] cur = intervals[0];
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] <= cur[1]) {
            cur[1] = Math.max(cur[1], intervals[i][1]);    // 注意取 max
        } else {
            res.add(cur);
            cur = intervals[i];
        }
    }
    res.add(cur);
    return res.toArray(new int[0][]);
}
```

**易错**：合并时 `cur[1]` 要取 `max`（存在被完全包含的区间）。

### 2.10 螺旋矩阵

```java
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    if (matrix.length == 0) return res;
    int top = 0, bottom = matrix.length - 1;
    int left = 0, right = matrix[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) res.add(matrix[top][j]);
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--) res.add(matrix[bottom][j]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
            left++;
        }
    }
    return res;
}
```

**易错**：后两个方向要判断边界，否则单行/单列会重复。

### 2.11 最长无重复子串（滑动窗口）

```java
public int lengthOfLongestSubstring(String s) {
    int[] last = new int[128];
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        left = Math.max(left, last[c]);          // last 存"上次位置+1"
        max = Math.max(max, right - left + 1);
        last[c] = right + 1;
    }
    return max;
}
```

**易错**：`left` 必须取 `max`，否则 `"abba"` 会让窗口回退。

### 2.12 岛屿数量（DFS）

```java
public int numIslands(char[][] grid) {
    int count = 0;
    for (int i = 0; i < grid.length; i++)
        for (int j = 0; j < grid[0].length; j++)
            if (grid[i][j] == '1') {
                count++;
                dfs(grid, i, j);
            }
    return count;
}

private void dfs(char[][] g, int i, int j) {
    if (i < 0 || i >= g.length || j < 0 || j >= g[0].length || g[i][j] != '1') return;
    g[i][j] = '0';                               // 原地标记，省 visited
    dfs(g, i + 1, j);
    dfs(g, i - 1, j);
    dfs(g, i, j + 1);
    dfs(g, i, j - 1);
}
```

## 三、并发类手写（12 题）

> 这一节是最大盲区。面试官要看的是**你对可见性、原子性、等待通知的理解**，不是背 API。

### 3.1 单例：六种写法

```java
// ① 饿汉：类加载即创建，线程安全，但不能懒加载
public class Eager {
    private static final Eager INSTANCE = new Eager();
    private Eager() {}
    public static Eager getInstance() { return INSTANCE; }
}

// ② 懒汉 + synchronized：安全但每次加锁
public class LazySync {
    private static LazySync instance;
    private LazySync() {}
    public static synchronized LazySync getInstance() {
        if (instance == null) instance = new LazySync();
        return instance;
    }
}

// ③ DCL：必须 volatile
public class Dcl {
    private static volatile Dcl instance;
    private Dcl() {}
    public static Dcl getInstance() {
        if (instance == null) {
            synchronized (Dcl.class) {
                if (instance == null) instance = new Dcl();
            }
        }
        return instance;
    }
}

// ④ 静态内部类：懒加载 + 线程安全（推荐）
public class Holder {
    private Holder() {}
    private static class H { static final Holder INSTANCE = new Holder(); }
    public static Holder getInstance() { return H.INSTANCE; }
}

// ⑤ 枚举：最安全（防反射、防序列化）
public enum EnumSingleton {
    INSTANCE;
    public void doSomething() {}
}

// ⑥ 容器：适合多种单例统一管理
public class Registry {
    private static final Map<String, Object> MAP = new ConcurrentHashMap<>();
    public static Object get(String key) {
        return MAP.computeIfAbsent(key, k -> new Object());
    }
}
```

**追问**：

- DCL 为什么 volatile？→ 禁止 `new` 的三步重排（分配→初始化→赋值）。
- 怎么破坏单例？→ 反射（`setAccessible`）、序列化（`readResolve` 可防）、`Unsafe`。
- 枚举为什么安全？→ JVM 保证枚举实例唯一，反射创建会抛异常。
- 静态内部类为什么线程安全？→ 类加载机制保证 `<clinit>` 只执行一次。

### 3.2 生产者消费者：三种写法

```java
// ① wait/notify + 自己维护队列
public class ProducerConsumer1 {
    private final Queue<Integer> queue = new LinkedList<>();
    private final int capacity = 10;

    public void produce(int x) throws InterruptedException {
        synchronized (queue) {
            while (queue.size() == capacity) queue.wait();   // 必须 while
            queue.offer(x);
            queue.notifyAll();
        }
    }

    public int consume() throws InterruptedException {
        synchronized (queue) {
            while (queue.isEmpty()) queue.wait();
            int x = queue.poll();
            queue.notifyAll();
            return x;
        }
    }
}

// ② BlockingQueue（生产环境首选）
public class ProducerConsumer2 {
    private final BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(10);
    public void produce(int x) throws InterruptedException { queue.put(x); }
    public int consume() throws InterruptedException { return queue.take(); }
}

// ③ Lock + Condition（可以精确唤醒）
public class ProducerConsumer3 {
    private final Queue<Integer> queue = new LinkedList<>();
    private final int capacity = 10;
    private final Lock lock = new ReentrantLock();
    private final Condition notFull = lock.newCondition();
    private final Condition notEmpty = lock.newCondition();

    public void produce(int x) throws InterruptedException {
        lock.lock();
        try {
            while (queue.size() == capacity) notFull.await();
            queue.offer(x);
            notEmpty.signal();
        } finally {
            lock.unlock();
        }
    }

    public int consume() throws InterruptedException {
        lock.lock();
        try {
            while (queue.isEmpty()) notEmpty.await();
            int x = queue.poll();
            notFull.signal();
            return x;
        } finally {
            lock.unlock();
        }
    }
}
```

**必答追问**：

- 为什么用 `while` 不用 `if`？→ **虚假唤醒**（spurious wakeup），醒来后条件可能仍不满足。
- `notify` 和 `notifyAll` 区别？→ 前者可能唤醒同类线程导致死锁，**优先 `notifyAll`**。
- 为什么 `wait` 必须在 `synchronized` 里？→ 要检查条件与等待是原子的，否则会丢信号。

### 3.3 三线程交替打印 ABC（循环 10 次）

```java
public class PrintABC {
    private final Object lock = new Object();
    private int state = 0;                       // 0=A, 1=B, 2=C
    private static final int TIMES = 10;

    public void print(int target, String s, int next) throws InterruptedException {
        for (int i = 0; i < TIMES; i++) {
            synchronized (lock) {
                while (state != target) lock.wait();
                System.out.print(s);
                state = next;
                lock.notifyAll();
            }
        }
    }

    public static void main(String[] args) {
        PrintABC p = new PrintABC();
        new Thread(() -> run(p, 0, "A", 1)).start();
        new Thread(() -> run(p, 1, "B", 2)).start();
        new Thread(() -> run(p, 2, "C", 0)).start();
    }

    private static void run(PrintABC p, int target, String s, int next) {
        try { p.print(target, s, next); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}
```

**追问**：

- 用 Semaphore 怎么写？→ 三个信号量，`A` 打印后 release `B`，初始 `A=1`、`B=0`、`C=0`。
- `ReentrantLock + Condition`？→ 三个 Condition，精确唤醒下一个。

### 3.4 两个线程交替打印奇偶数

```java
public class PrintOddEven {
    private int n = 1;
    private final int max = 100;

    public static void main(String[] args) {
        PrintOddEven p = new PrintOddEven();
        new Thread(() -> p.print(true)).start();
        new Thread(() -> p.print(false)).start();
    }

    private synchronized void print(boolean odd) {
        while (n <= max) {
            while (n <= max && (n % 2 == 1) != odd) {
                try { wait(); } catch (InterruptedException e) { Thread.currentThread().interrupt(); return; }
            }
            if (n > max) { notifyAll(); return; }
            System.out.println(Thread.currentThread().getName() + ":" + n++);
            notifyAll();
        }
    }
}
```

**易错**：退出时也要 `notifyAll`，否则另一个线程永久等待。

### 3.5 简易阻塞队列

```java
public class MyBlockingQueue<E> {
    private final Object[] items;
    private int head, tail, count;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notEmpty = lock.newCondition();
    private final Condition notFull = lock.newCondition();

    public MyBlockingQueue(int capacity) {
        items = new Object[capacity];
    }

    public void put(E e) throws InterruptedException {
        lock.lock();
        try {
            while (count == items.length) notFull.await();
            items[tail] = e;
            tail = (tail + 1) % items.length;
            count++;
            notEmpty.signal();
        } finally {
            lock.unlock();
        }
    }

    @SuppressWarnings("unchecked")
    public E take() throws InterruptedException {
        lock.lock();
        try {
            while (count == 0) notEmpty.await();
            E e = (E) items[head];
            head = (head + 1) % items.length;
            count--;
            notFull.signal();
            return e;
        } finally {
            lock.unlock();
        }
    }
}
```

### 3.6 简易线程池

```java
public class SimplePool {
    private final BlockingQueue<Runnable> queue;
    private final List<Thread> workers = new ArrayList<>();
    private volatile boolean running = true;

    public SimplePool(int nThreads, int queueSize) {
        queue = new ArrayBlockingQueue<>(queueSize);
        for (int i = 0; i < nThreads; i++) {
            Thread t = new Thread(this::work, "worker-" + i);
            workers.add(t);
            t.start();
        }
    }

    private void work() {
        while (running || !queue.isEmpty()) {
            try {
                Runnable task = queue.poll(100, TimeUnit.MILLISECONDS);
                if (task != null) task.run();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
        }
    }

    public boolean submit(Runnable task) {
        return queue.offer(task);                 // 有界队列 + 返回值表示是否接受
    }

    public void shutdown() {
        running = false;
    }
}
```

**追问**：和 `ThreadPoolExecutor` 差什么？→ 核心/最大线程数、拒绝策略、空闲回收、状态机、优雅关闭。

### 3.7 令牌桶限流器

```java
public class TokenBucket {
    private final long capacity;
    private final double ratePerSecond;          // 每秒补充令牌数
    private double tokens;
    private long lastRefillNanos;

    public TokenBucket(long capacity, double ratePerSecond) {
        this.capacity = capacity;
        this.ratePerSecond = ratePerSecond;
        this.tokens = capacity;
        this.lastRefillNanos = System.nanoTime();
    }

    public synchronized boolean tryAcquire() {
        refill();
        if (tokens >= 1) {
            tokens -= 1;
            return true;
        }
        return false;
    }

    private void refill() {
        long now = System.nanoTime();
        double add = (now - lastRefillNanos) / 1e9 * ratePerSecond;
        if (add > 0) {
            tokens = Math.min(capacity, tokens + add);
            lastRefillNanos = now;
        }
    }
}
```

**追问**：

- 为什么懒补充？→ 避免定时器线程。
- 分布式限流？→ Redis + Lua（ZSet 滑动窗口或令牌桶脚本）。
- 和漏桶的区别？→ 令牌桶允许突发（可攒令牌），漏桶恒定速率。

### 3.8 滑动窗口限流

```java
public class SlidingWindowLimiter {
    private final long windowMillis;
    private final int limit;
    private final Deque<Long> timestamps = new ArrayDeque<>();

    public SlidingWindowLimiter(long windowMillis, int limit) {
        this.windowMillis = windowMillis;
        this.limit = limit;
    }

    public synchronized boolean tryAcquire() {
        long now = System.currentTimeMillis();
        while (!timestamps.isEmpty() && now - timestamps.peekFirst() >= windowMillis) {
            timestamps.pollFirst();
        }
        if (timestamps.size() < limit) {
            timestamps.offerLast(now);
            return true;
        }
        return false;
    }
}
```

**追问**：内存占用？→ 每个请求一个时间戳，高 QPS 下用环形数组/分桶（Sentinel 的 LeapArray）。

### 4.1 LRU 缓存

**考察**：哈希 + 双向链表，`O(1)` 读写。

```java
public class LRUCache {
    private static class Node {
        int key, value;
        Node prev, next;
        Node(int k, int v) { key = k; value = v; }
    }

    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0);     // 哨兵
    private final Node tail = new Node(0, 0);     // 哨兵

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }
        if (map.size() == capacity) {
            Node last = tail.prev;
            remove(last);
            map.remove(last.key);
        }
        Node newNode = new Node(key, value);
        map.put(key, newNode);
        addToHead(newNode);
    }

    private void moveToHead(Node node) { remove(node); addToHead(node); }

    private void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private void addToHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }
}
```

**追问**：为什么用哨兵？→ 省去头尾特判。LFU 怎么做？→ 频次桶 + 双向链表。

### 4.3 用两个栈实现队列

```java
public class MyQueue {
    private final Deque<Integer> in = new ArrayDeque<>();
    private final Deque<Integer> out = new ArrayDeque<>();

    public void push(int x) { in.push(x); }

    public int pop() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) out.push(in.pop());
        }
        return out.pop();
    }

    public int peek() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) out.push(in.pop());
        }
        return out.peek();
    }

    public boolean empty() { return in.isEmpty() && out.isEmpty(); }
}
```

**追问**：摊还复杂度？→ 每个元素最多两次进出，`O(1)` 摊还。

### 4.4 循环队列

```java
public class MyCircularQueue {
    private final int[] data;
    private int head, size;

    public MyCircularQueue(int k) { data = new int[k]; }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        data[(head + size) % data.length] = value;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % data.length;
        size--;
        return true;
    }

    public int Front() { return isEmpty() ? -1 : data[head]; }
    public int Rear() { return isEmpty() ? -1 : data[(head + size - 1) % data.length]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == data.length; }
}
```

### 4.5 Trie 前缀树

```java
public class Trie {
    private static class Node {
        Node[] next = new Node[26];
        boolean end;
    }

    private final Node root = new Node();

    public void insert(String word) {
        Node cur = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (cur.next[i] == null) cur.next[i] = new Node();
            cur = cur.next[i];
        }
        cur.end = true;
    }

    public boolean search(String word) { return find(word, true); }
    public boolean startsWith(String prefix) { return find(prefix, false); }

    private boolean find(String s, boolean exact) {
        Node cur = root;
        for (char c : s.toCharArray()) {
            int i = c - 'a';
            if (cur.next[i] == null) return false;
            cur = cur.next[i];
        }
        return exact ? cur.end : true;
    }
}
```

### 4.6 两个线程池隔离的提交器

```java
public class IsolatedExecutor {
    private final ExecutorService core = Executors.newFixedThreadPool(8);
    private final ExecutorService nonCore = Executors.newFixedThreadPool(4);

    public void submitCore(Runnable task) {
        try {
            core.execute(task);
        } catch (RejectedExecutionException e) {
            // 核心链路：阻塞提交或降级，不能丢
            log.warn("core pool full, run in caller thread");
            task.run();
        }
    }

    public void submitNonCore(Runnable task) {
        try {
            nonCore.execute(task);
        } catch (RejectedExecutionException e) {
            log.warn("non-core pool full, drop task");
        }
    }
}
```

## 五、边界自检清单

写完代码，**逐条过一遍**（面试时说出来，直接加分）：

| 类别 | 检查项 |
| --- | --- |
| **空** | `null`、空数组、空字符串、空树 |
| **单元素** | 长度为 1 时循环是否执行 |
| **两端** | 第一个/最后一个元素是否漏处理 |

| **越界** | 二维数组的 `matrix[0]` 可能为空 |
| **溢出** | `mid` 计算、`int` 乘法、金额 |
| **死循环** | `while` 内是否推进；`left = mid` 是否向上取整 |
| **并发** | 可见性（volatile）、原子性（CAS/锁）、等待条件（while） |
| **资源** | 锁是否 `finally` 释放、流是否关闭 |
| **返回** | 返回长度还是下标、返回 null 还是空集合 |
