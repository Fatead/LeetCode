# 06 排序与快速选择

> **一句话理解**：
> 排序本身很简单（Java 一行 `Arrays.sort`），**难的是"排序之后能做什么"**。
> 这一类题的核心考点是：**归并排序求逆序对 / 快速选择求 TopK / 自定义排序规则**。

---

## 一、先明确：什么时候需要自己写排序？

| 场景 | 做法 |
| --- | --- |
| 只需要排序结果 | `Arrays.sort(nums)` —— **永远优先用这个** |
| 需要按自定义规则排序 | `Arrays.sort(nums, comparator)` |
| 需要在排序过程中**统计信息**（逆序对、右边更小的数） | 自己写归并排序 |
| 需要 `O(n)` 求第 K 大 | 自己写快速选择 |
| 面试官明确要求"手写快排" | 自己写快排 |

**结论**：Java 内置排序是双轴快排（基本类型）+ 归并排序（对象类型），工程上够用。**只有上面后三种场景才需要手写。**

## 二、手写快速排序

### 2.1 核心思想

```
1. 选一个基准值 pivot
2. 把数组分成三部分：小于 pivot | 等于 pivot | 大于 pivot（或两部分）
3. 递归处理左右两部分
```

**平均 `O(n log n)`，最坏 `O(n^2)`（数组已有序且每次取首元素为 pivot），空间 `O(log n)`。**

### 2.2 模板：三路划分（推荐，能处理大量重复元素）

```java
/**
 * 三路快排
 * 把数组分成 < pivot、== pivot、> pivot 三段
 * 优势：遇到大量重复元素时不会退化
 */
public void quickSort(int[] nums, int lo, int hi) {
    if (lo >= hi) return;                        // ① 递归出口

    int pivot = nums[lo + (int) (Math.random() * (hi - lo + 1))];  // ② 随机选 pivot，避免退化
    int lt = lo;                                 // [lo, lt) 是 < pivot
    int gt = hi;                                 // (gt, hi] 是 > pivot
    int i = lo;                                  // [lt, i) 是 == pivot

    while (i <= gt) {
        if (nums[i] < pivot) {
            swap(nums, lt++, i++);
        } else if (nums[i] > pivot) {
            swap(nums, i, gt--);                 // 注意：i 不自增
        } else {
            i++;
        }
    }
    // 此时 [lo, lt-1] < pivot，[lt, gt] == pivot，[gt+1, hi] > pivot
    quickSort(nums, lo, lt - 1);
    quickSort(nums, gt + 1, hi);
}
```

> 参考实现：[src/sort/QuickSort.java](../src/sort/QuickSort.java)、[src/sort/QuickSort2.java](../src/sort/QuickSort2.java)

### 2.3 为什么必须**随机选 pivot**？

如果每次固定选 `nums[lo]`，遇到**已经有序的数组**会退化：

```
[1, 2, 3, 4, 5]  选 pivot = 1
→ 左边空，右边 [2,3,4,5]  → 递归深度 n → O(n^2) 时间、O(n) 栈空间
```

**随机化后，期望复杂度是 `O(n log n)`。** 这是快排最重要的工程实践。

### 2.4 时间复杂度的直观理解

- **递归树的高度**：期望 `O(log n)`
- **每层的总工作量**：`O(n)`（每个元素只被比较常数次）
- **总计**：`O(n log n)`

### 2.5 快排的稳定性

**快排不稳定**（交换会打乱相等元素的相对顺序）。如果题目要求"相等元素保持原顺序"，用**归并排序**。

## 三、手写归并排序（重点：分治思想的载体）

### 3.1 模板

```java
public void mergeSort(int[] nums, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(nums, lo, mid);                    // ① 分
    mergeSort(nums, mid + 1, hi);
    merge(nums, lo, mid, hi);                    // ② 治（合并）
}

private void merge(int[] nums, int lo, int mid, int hi) {
    int[] temp = new int[hi - lo + 1];           // 辅助数组
    int i = lo, j = mid + 1, k = 0;

    while (i <= mid && j <= hi) {
        // 注意 <= ：取左边时优先，保证稳定性
        if (nums[i] <= nums[j]) temp[k++] = nums[i++];
        else temp[k++] = nums[j++];
    }
    while (i <= mid) temp[k++] = nums[i++];
    while (j <= hi) temp[k++] = nums[j++];

    // 写回原数组
    System.arraycopy(temp, 0, nums, lo, temp.length);
}
```

> 参考实现：[src/sort/SortArray.java](../src/sort/SortArray.java)、[src/listTable/SortList.java](../src/listTable/SortList.java)、[src/listTable/MergeKLists.java](../src/listTable/MergeKLists.java)

**归并排序的三大特性**：

1. **稳定**（`nums[i] <= nums[j]` 时优先取左边）
2. **`O(n log n)` 稳定不变**（不受输入数据分布影响）
3. **空间 `O(n)`**（需要辅助数组）

### 3.2 归并排序的两大杀器用途

**归并排序真正的价值不在"排序"，而在"分治过程中顺便统计信息"。** 这是很多人忽略的考点。

#### 用途 1：统计逆序对（剑指 Offer 51 / LeetCode 493）

**题意**：统计 `i < j` 且 `nums[i] > nums[j]` 的数对个数。

**关键洞察**：在 `merge` 过程中，当从**右半部分**取元素时，说明它比左半部分剩余的所有元素都小 → 一次性产生"剩余左半部分元素个数"个逆序对。

```java
class Solution {
    private int count = 0;
    private int[] temp;

    public int reversePairs(int[] nums) {
        temp = new int[nums.length];
        mergeSort(nums, 0, nums.length - 1);
        return count;
    }

    private void mergeSort(int[] nums, int lo, int hi) {
        if (lo >= hi) return;
        int mid = lo + (hi - lo) / 2;
        mergeSort(nums, lo, mid);
        mergeSort(nums, mid + 1, hi);
        merge(nums, lo, mid, hi);
    }

    private void merge(int[] nums, int lo, int mid, int hi) {
        int i = lo, j = mid + 1, k = lo;
        while (i <= mid && j <= hi) {
            if (nums[i] <= nums[j]) {
                temp[k++] = nums[i++];
            } else {
                // 关键：nums[j] 比左半部分剩下的 (mid - i + 1) 个元素都小
                count += mid - i + 1;
                temp[k++] = nums[j++];
            }
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= hi) temp[k++] = nums[j++];
        System.arraycopy(temp, lo, nums, lo, hi - lo + 1);
    }
}
```

> 参考实现：[src/array/ReversePairs.java](../src/array/ReversePairs.java)、[src/array/CountSmaller.java](../src/array/CountSmaller.java)

**`count += mid - i + 1` 这一行就是全部的精髓。** 面试时被问"为什么这样统计不会重复不会遗漏"，答：*每次从右边取元素时，左边剩余的所有元素都和它构成逆序对，且这些逆序对都以右边这个元素为"后面的元素"，恰好被枚举一次。*

#### 用途 2：链表排序（LeetCode 148）

链表不能随机访问，所以**快排不好用**（无法 `O(1)` 取中间元素），而**归并排序天然适合链表**。

```java
public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    // ① 快慢指针找中点
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode mid = slow.next;
    slow.next = null;                        // 断开
    // ② 递归排序两半
    ListNode left = sortList(head);
    ListNode right = sortList(mid);
    // ③ 合并两个有序链表
    return mergeTwoLists(left, right);
}
```

## 四、快速选择：`O(n)` 求第 K 大

### 4.1 核心思想

快排的 `partition` 操作会把数组分成"小于 pivot"和"大于 pivot"两部分。**如果 pivot 的位置恰好是我们要找的 K，就找到了；否则只需要递归一边。**

```
快排：    两边都要递归 → O(n log n)
快速选择：只递归一边 → 平均 O(n)，最坏 O(n^2)
```

### 4.2 模板

```java
/**
 * 求数组中第 k 大的元素（k 从 1 开始）
 * 思路：转化为"第 (n-k) 小的元素"，用快速选择找下标为 n-k 的位置
 */
public int findKthLargest(int[] nums, int k) {
    int target = nums.length - k;            // 升序排列后，第 k 大在 target 位置
    int lo = 0, hi = nums.length - 1;
    while (lo <= hi) {
        int p = partition(nums, lo, hi);
        if (p == target) return nums[p];
        else if (p < target) lo = p + 1;
        else hi = p - 1;
    }
    return -1;
}

/** 以 nums[lo] 为 pivot 分区，返回 pivot 最终所在下标（左边都比它小） */
private int partition(int[] nums, int lo, int hi) {
    int pivot = nums[lo];
    int i = lo, j = hi;
    while (i < j) {
        while (i < j && nums[j] >= pivot) j--;   // 从右往左找比 pivot 小的
        while (i < j && nums[i] <= pivot) i++;   // 从左往右找比 pivot 大的
        swap(nums, i, j);
    }
    swap(nums, lo, i);                           // pivot 归位
    return i;
}

private void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
```

> 参考实现：[src/array/FindKthLargest.java](../src/array/FindKthLargest.java)、[src/array/KthLargest.java](../src/array/KthLargest.java)、[src/array/KthLargest2.java](../src/array/KthLargest2.java)、[src/array/KthElement.java](../src/array/KthElement.java)、[src/array/LeastNumbers.java](../src/array/LeastNumbers.java)

**注意 `partition` 的细节**：
- 外层 `while (i < j)`，内层两个 `while` 也要带 `i < j`
- 两个内层 while 的顺序**先从右往左**（因为 pivot 在左边 `nums[lo]`），否则会出错
- 最后 `swap(nums, lo, i)` 把 pivot 放到最终位置

### 4.3 三路 partition 版本（能处理大量重复元素）

当数组有大量重复元素时，两路 partition 会退化成 `O(n^2)`（比如全是一样的元素）。用三路划分可以保证重复元素被一次性归位。

> 参考实现：[src/array/KthLargest2.java](../src/array/KthLargest2.java)

### 4.4 快速选择 vs 小顶堆

| 方案 | 时间 | 空间 | 适用场景 |
| --- | --- | --- | --- |
| 快速选择 | 平均 `O(n)`，最坏 `O(n^2)` | `O(1)` | 只要能拿到答案即可，允许打乱数组 |
| 小顶堆（size = k） | `O(n log k)` | `O(k)` | **数据流**场景（元素一个一个来） |
| 大顶堆（全部入堆） | `O(n log n)` | `O(n)` | 简单但不优 |
| 全排序 | `O(n log n)` | `O(log n)` | 代码最短，面试可以先说这个 |

**决策口诀**：

- **数据是静态的** → 快速选择（`O(n)` 更快）
- **数据是流式的 / 内存放不下全部** → 小顶堆（`O(n log k)`）
- **`k` 接近 `n`** → 直接排序更简单

**Java 小顶堆写法**：

```java
public int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>();   // 默认小顶堆
    for (int x : nums) {
        minHeap.offer(x);
        if (minHeap.size() > k) {
            minHeap.poll();               // 弹出最小的，堆里始终保持最大的 k 个
        }
    }
    return minHeap.peek();                // 堆顶就是第 k 大
}
```

> 参考实现：[src/array/TopKFrequent.java](../src/array/TopKFrequent.java)、[src/queue/MyPriorityQueue.java](../src/queue/MyPriorityQueue.java)、[src/tree/BinaryHeap.java](../src/tree/BinaryHeap.java)

### 4.5 例题：347. 前 K 个高频元素

**两步走**：① 哈希统计频次 → ② 用小顶堆按频次取前 K。

```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);

    // 小顶堆，按频次排序
    PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
        heap.offer(new int[]{e.getKey(), e.getValue()});
        if (heap.size() > k) heap.poll();
    }

    int[] res = new int[k];
    for (int i = k - 1; i >= 0; i--) res[i] = heap.poll()[0];
    return res;
}
```

> 参考实现：[src/array/TopKFrequent.java](../src/array/TopKFrequent.java)、[src/hashTable/TopKWords.java](../src/hashTable/TopKWords.java)、[src/hashTable/FrequencySort.java](../src/hashTable/FrequencySort.java)

**进阶**：这道题有 `O(n)` 的**桶排序**解法——按频次建桶，频次范围是 `[1, n]`，所以桶的数量是 `O(n)`。

```java
// 桶排序 O(n)：下标 = 频次，值 = 该频次的所有元素
List<Integer>[] buckets = new List[nums.length + 1];
// ... 填充 buckets ...
// 从后往前取，凑够 k 个
```

**"频次作为下标"是桶排序的经典套路**，因为频次的范围一定在 `[1, n]` 内。

## 五、自定义排序规则

这是**最容易在面试中吃亏的地方**——排序规则写错，尤其是**溢出**。

### 5.1 三种写法对比

```java
int[][] points = {{1,2},{3,4}};

// ❌ 有溢出风险：相减可能超出 int 范围
Arrays.sort(points, (a, b) -> a[0] - b[0]);

// ✅ 安全：用 Integer.compare
Arrays.sort(points, (a, b) -> Integer.compare(a[0], b[0]));

// ✅ 安全：Java 8+ 的 Comparator 链式写法
Arrays.sort(points, Comparator.comparingInt((int[] a) -> a[0])
                              .thenComparingInt(a -> a[1]));
```

**为什么相减会溢出？** 如果 `a[0] = Integer.MAX_VALUE`，`b[0] = -1`，相减结果溢出成负数，排序就错了。**面试时主动提这一点是加分项。**

### 5.2 多关键字排序

```java
// 先按第一列升序，第一列相同时按第二列降序
Arrays.sort(points, (a, b) -> {
    if (a[0] != b[0]) return Integer.compare(a[0], b[0]);
    return Integer.compare(b[1], a[1]);        // 降序：把 b 放前面
});

// Comparator 链式写法
Arrays.sort(points, Comparator.comparingInt((int[] a) -> a[0])
                              .thenComparing(a -> a[1], Comparator.reverseOrder()));
```

### 5.3 字符串的自定义排序

```java
// 拼接成最大的数（179. 最大数）：核心是比较 a+b 和 b+a
public String largestNumber(int[] nums) {
    String[] strs = new String[nums.length];
    for (int i = 0; i < nums.length; i++) strs[i] = String.valueOf(nums[i]);

    // 关键：如果 a+b > b+a，则 a 应该排在 b 前面
    Arrays.sort(strs, (a, b) -> (b + a).compareTo(a + b));

    if (strs[0].equals("0")) return "0";        // 全是 0 的特殊情况
    return String.join("", strs);
}
```

> 参考实现：[src/array/ArrayToMinNum.java](../src/array/ArrayToMinNum.java)、[src/array/CountSmaller.java](../src/array/CountSmaller.java)

**为什么这个比较规则是对的？** 它是**传递的**（可以数学证明），所以满足排序的偏序要求。面试时被追问"为什么这样定义比较函数"，可以答："因为要保证拼接结果最大，而 `a+b > b+a` 这个关系是传递的，所以可以作为排序的依据。"

**面试高频追问**："Java 的 `Arrays.sort` 用的是什么？"
答：**基本类型用双轴快速排序**（DualPivotQuicksort，`O(n log n)` 且不需要稳定性，不装箱更快）；**对象类型用 TimSort**（归并排序的优化版，稳定）。这个差异的原因是：基本类型相同值无区别，稳定性无意义；对象需要稳定性。

## 七、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| 比较器用 `a - b` | 大数溢出 | `Integer.compare(a, b)` |
| 快排不随机选 pivot | 有序输入退化为 `O(n^2)` | `Math.random()` 选 pivot |
| 归并排序 `merge` 时用 `<` 而非 `<=` | 失去稳定性 | `nums[i] <= nums[j]` 时取左边 |
| 快速选择的两路 partition 遇重复元素退化 | `O(n^2)` | 三路划分 / 随机 pivot |
| 求第 K 大时的下标搞错 | 结果错 | 第 K 大 = 升序下标 `n - k` |
| 快排递归没写出口 | 栈溢出 | `if (lo >= hi) return;` |
| 归并排序忘记写回原数组 | 结果不变 | `System.arraycopy` |
| 自定义排序规则不满足传递性 | 排序结果不确定 | 确保比较规则可传递 |
