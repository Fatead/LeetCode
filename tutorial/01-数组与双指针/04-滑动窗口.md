# 04 滑动窗口

> **一句话理解**：滑动窗口是"用两个指针维护一个区间，右指针负责扩张、左指针负责收缩，每个元素最多进出窗口一次"，从而把 `O(n^2)` 的子数组枚举降到 `O(n)`。

---

## 一、什么时候能用滑动窗口

必须同时满足两个条件：

### 条件 1：求的是**连续子数组/子串**的问题

关键词：「连续」「子串」「子数组」「区间」。**子序列**（可以不连续）不能用滑动窗口，那通常是 DP。

### 条件 2：窗口的**合法性随窗口变化是单调的**

这是最关键、也最容易判断错的条件：

| 题目要求 | 窗口扩张时 | 是否单调 | 能用窗口？ |
| --- | --- | --- | --- |
| 和 ≥ target 的最短窗口 | 和**单调不减** | ✓ | ✅ |
| 无重复字符的最长子串 | 重复可能性**单调不减** | ✓ | ✅ |
| 和恰好等于 K（元素**有负数**） | 和**忽大忽小** | ✗ | ❌ 用前缀和 |
| 和恰好等于 K（元素**全正数**） | 和单调不减 | ✓ | ✅ |
| 最多包含 K 种不同字符 | 种类数单调不减 | ✓ | ✅ |

> **判断口诀**：窗口越大，越"难以满足"题目要求（或越"容易违反"）→ 可以用窗口。

## 二、万能框架：可变长度窗口

```java
/**
 * 可变长度滑动窗口 · 通用框架
 *
 * 适用：求"满足某条件的最长/最短连续子数组"
 *
 * 核心结构：
 *   for (right 扩张) {
 *       把 nums[right] 加入窗口（更新窗口状态）
 *       while (窗口不满足条件) {
 *           把 nums[left] 移出窗口（回退窗口状态）
 *           left++;
 *       }
 *       此时窗口满足条件 → 更新答案
 *   }
 */
public int slidingWindow(int[] nums) {
    int left = 0, right = 0;
    int windowState = 0;              // 窗口的状态：和、计数、字符频次……

    while (right < nums.length) {
        // ① 扩张：把 nums[right] 纳入窗口
        windowState += nums[right];

        // ② 收缩：只要窗口不合法，就移动左边界
        while (窗口不合法) {
            windowState -= nums[left];
            left++;
        }

        // ③ 更新答案：此时窗口一定合法
        // 注意：求最长用 (right - left + 1)，求最短在 while 内部更新
        right++;
    }
    return 答案;
}
```

### 2.1 三个必须想清楚的问题

写任何滑动窗口题之前，先回答这三问：

| 问题 | 说明 | 例子（无重复最长子串） |
| --- | --- | --- |
| **① 窗口里维护什么状态？** | 决定用什么数据结构 | `Map<Character, Integer>` 记录字符最后出现的位置 |
| **② 什么情况下窗口不合法？** | 决定 `while` 的条件 | 新字符已经在窗口内出现过 |
| **③ 什么时候更新答案？** | 决定答案更新位置 | 每次收缩完（此时窗口合法）更新 `max` |

### 2.2 求「最长」和求「最短」的写法差异（重要）

```java
// ===== 求最长：while 收缩到合法，然后在外面更新答案 =====
while (right < n) {
    加入 nums[right];
    while (不合法) { 移除 nums[left]; left++; }
    ans = Math.max(ans, right - left + 1);      // 窗口已合法，直接算长度
    right++;
}

// ===== 求最短：while 收缩时每收缩一步都可能产生更优答案 =====
while (right < n) {
    加入 nums[right];
    while (合法) {                               // 注意：条件反过来了！
        ans = Math.min(ans, right - left + 1);   // 在收缩过程中更新
        移除 nums[left]; left++;
    }
    right++;
}
```

**这是最容易搞混的地方**：

| | 求最长 | 求最短 |
| --- | --- | --- |
| `while` 条件 | 窗口**不**合法时收缩 | 窗口**仍然**合法时收缩 |
| 更新答案位置 | `while` **外面** | `while` **里面** |

**为什么？**

- 求最长：窗口越大越好，所以要在"刚好合法"时记录 → 收缩到合法后记录。
- 求最短：窗口越小越好，所以要在"还没被破坏合法性"时记录 → 每收缩一步都记录一次。

## 三、题型一：可变窗口 + 哈希表（字符类问题）

字符类窗口题占据了这个模板 80% 的应用场景。核心技巧：**用一个 `need` 数组记录"目标需求"，用 `window` 数组记录"当前窗口"，两者相等就说明匹配**。

### 3.1 例题：3. 无重复字符的最长子串（最经典的窗口题）

**三问分析**：

1. 窗口状态：`Map<Character, Integer>` 记录每个字符**最后一次出现的下标**
2. 不合法条件：新字符 `c` 在窗口 `[left, right]` 内出现过
3. 更新答案：每轮扩张后更新

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();     // 字符 -> 最后出现的下标
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c)) {
            // 关键优化：left 直接跳到"重复字符的下一位"，而不是 left++
            left = Math.max(left, map.get(c) + 1);
        }
        map.put(c, right);
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```

> 参考实现：[src/slidingWindows/LengthOfLongestSubString.java](../src/slidingWindows/LengthOfLongestSubString.java)、[src/slidingWindows/LengthOfLongestSubString2.java](../src/slidingWindows/LengthOfLongestSubString2.java)、[src/slidingWindows/LongestSubString.java](../src/slidingWindows/LongestSubString.java)、[src/string/LongSubStr.java](../src/string/LongSubStr.java)、[src/dp/LongestSubString.java](../src/dp/LongestSubString.java)

**两个关键细节**：

1. **`left = Math.max(left, map.get(c) + 1)` 而不是 `left = map.get(c) + 1`**
   为什么？看 `"abba"` 的例子：
   ```
   right=3, c='a' 时，map.get('a') = 0，所以 map.get('a')+1 = 1
   但此时 left 已经因为 'b' 重复被移到了 2
   如果直接赋值 left=1，窗口就退回去了 → 错误！
   取 max 保证 left 单调不减。
   ```
   这是本题**最经典的坑**。

2. **`left` 只能单调向右移动**。滑动窗口的左边界**永远不回退**，这是 `O(n)` 复杂度的保证。

**如果用数组代替 HashMap（速度更快）**：

```java
public int lengthOfLongestSubstringArray(String s) {
    int[] last = new int[128];                  // 字符 -> 最后出现的下标 + 1（0 表示未出现）
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        left = Math.max(left, last[c]);         // last[c] 存的是"上次出现位置+1"
        max = Math.max(max, right - left + 1);
        last[c] = right + 1;
    }
    return max;
}
```

**为什么 `last` 要存 `下标+1`？** 这样"未出现"和"出现在下标 0"就能区分开（都是 0 vs 都是 1）。如果不加 1，`last` 初始化为 -1 也行，但需要额外处理。这个"用 +1 让默认值区分开来"的技巧叫**哨兵思想**，在数组题里很常见。

### 3.2 例题：438. 找到字符串中所有字母异位词（固定匹配模板）

**题意**：在 `s` 中找出所有 `p` 的字母异位词的起始下标。

**套路**：窗口大小固定为 `p.length()`，比较窗口内字符频次是否和 `p` 相同。

```java
public List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (s.length() < p.length()) return res;

    int[] need = new int[26];      // 目标字符频次
    int[] window = new int[26];    // 当前窗口字符频次
    for (char c : p.toCharArray()) need[c - 'a']++;

    int left = 0;
    for (int right = 0; right < s.length(); right++) {
        window[s.charAt(right) - 'a']++;

        // 窗口大小超过 p 的长度 → 收缩
        while (right - left + 1 > p.length()) {
            window[s.charAt(left) - 'a']--;
            left++;
        }

        // 窗口大小等于 p 的长度且频次相同 → 记录答案
        if (right - left + 1 == p.length() && Arrays.equals(window, need)) {
            res.add(left);
        }
    }
    return res;
}
```

> 参考实现：[src/slidingWindows/FindAnagrams.java](../src/slidingWindows/FindAnagrams.java)、[src/slidingWindows/CheckInclusion.java](../src/slidingWindows/CheckInclusion.java)、[src/slidingWindows/CheckInclusion2.java](../src/slidingWindows/CheckInclusion2.java)

**复杂度**：`O(n * 26)`（`Arrays.equals` 是常数 26）。可以优化到 `O(n)`：用 `diff` 变量记录"还有多少个字符的频次不匹配"。

### 3.3 例题：567. 字符串的排列（CheckInclusion）

**题意**：判断 `s2` 是否包含 `s1` 的某个排列。

**和 438 几乎完全一样**，只是返回布尔值。这是"同一模板、不同输出"的典型。

```java
public boolean checkInclusion(String s1, String s2) {
    if (s1.length() > s2.length()) return false;
    int[] need = new int[26], window = new int[26];
    for (char c : s1.toCharArray()) need[c - 'a']++;

    for (int right = 0; right < s2.length(); right++) {
        window[s2.charAt(right) - 'a']++;
        int left = right - s1.length() + 1;
        if (left < 0) continue;                       // 窗口还没达到 s1 的长度
        if (Arrays.equals(window, need)) return true;
        window[s2.charAt(left) - 'a']--;              // 窗口满了，移出最左边的
    }
    return false;
}
```

> 参考实现：[src/slidingWindows/CheckInclusion.java](../src/slidingWindows/CheckInclusion.java)

### 3.4 例题：76. 最小覆盖子串（Hard，窗口题的天花板）

**题意**：在 `s` 中找出包含 `t` 所有字符（含重复）的最短子串。

**思路**：这是"求最短"型窗口，需要三个变量：

- `need[c]`：t 中字符 c 的需求量
- `window[c]`：当前窗口中字符 c 的数量
- `valid`：**已经满足需求的不同字符种类数**（不是总字符数！）

当 `valid == need.size()` 时，窗口合法。

```java
public String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>(), window = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);

    int left = 0, valid = 0;
    int start = 0, minLen = Integer.MAX_VALUE;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        // ① 扩张：加入字符
        if (need.containsKey(c)) {
            window.merge(c, 1, Integer::sum);
            if (window.get(c).equals(need.get(c))) {
                valid++;                        // 这个字符的需求刚好满足
            }
        }

        // ② 收缩：窗口已经合法，尝试缩短
        while (valid == need.size()) {
            if (right - left + 1 < minLen) {     // 更新答案（在 while 内部！）
                start = left;
                minLen = right - left + 1;
            }
            char d = s.charAt(left);
            if (need.containsKey(d)) {
                if (window.get(d).equals(need.get(d))) {
                    valid--;                     // 移出后不再满足需求
                }
                window.merge(d, -1, Integer::sum);
            }
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

> 参考实现：[src/slidingWindows/MinWindow.java](../src/slidingWindows/MinWindow.java)、[src/string/MinWindowsStr.java](../src/string/MinWindowsStr.java)

**最容易错的三个点**：

1. **`valid` 记录的是"种类的数量"，不是字符总数**
   `need = {'a':2, 'b':1}`，`valid` 最多是 2（a 够了算 1，b 够了算 1）。

2. **判断 `valid--` 的时机**
   必须在 `window.merge(d, -1, ...)` **之前**判断 `window.get(d).equals(need.get(d))`，否则永远不相等。

3. **答案在 `while` 内部更新**
   因为是求最短，窗口每次收缩都可能产生更优解。

**面试加分**：主动说"这是求最短型窗口，所以答案更新在收缩循环内部；如果改求最长，就要把更新放到循环外面"。

### 3.5 字符窗口题的统一套路总结

```
Step 1  统计目标：need[] 或 need Map
Step 2  定义 valid = 已经满足需求的字符种类数
Step 3  right 扩张，更新 window 和 valid
Step 4  根据"求最长"还是"求最短"决定 while 条件
Step 5  判断 valid == need.size() 是否成立
Step 6  更新答案（位置取决于求最长还是最短）
```

## 四、题型二：可变窗口 + 求和/计数（数组类问题）

这类题目**不需要哈希表**，只需要维护一个累加值。

### 4.1 例题：209. 长度最小的子数组

**题意**：正整数数组，求和 ≥ target 的最短连续子数组长度。

**三问分析**：

1. 窗口状态：窗口内元素和 `sum`
2. 合法条件：`sum >= target`
3. 这是求**最短** → 在 `while (sum >= target)` 内部更新答案

```java
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {                    // 合法时收缩
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left];
            left++;
        }
    }
    return minLen == Integer.MAX_VALUE ? 0 : minLen;
}
```

> 参考实现：[src/array/MinSubArray.java](../src/array/MinSubArray.java)、[src/array/ShortestSubArray.java](../src/array/ShortestSubArray.java)

**注意**：题目说"正整数数组"，所以窗口和单调 → 可以用窗口。**如果数组含负数，这题必须用前缀和 + 单调队列**（LeetCode 862）。

### 4.2 例题：1004. 最大连续 1 的个数 III

**题意**：可以把最多 k 个 0 变成 1，求最长连续 1 的个数。

**转化思想**：等价于"找最长的子数组，其中 0 的个数 ≤ k"。

```java
public int longestOnes(int[] nums, int k) {
    int left = 0, zeroCount = 0, max = 0;
    for (int right = 0; right < nums.length; right++) {
        if (nums[right] == 0) zeroCount++;
        while (zeroCount > k) {                   // 0 太多了，收缩
            if (nums[left] == 0) zeroCount--;
            left++;
        }
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```

> 参考实现：[src/slidingWindows/LongestOnes.java](../src/slidingWindows/LongestOnes.java)

- 424. 替换后的最长重复字符 → "最多替换 k 个字符"
- 1493. 删掉一个元素以后全为 1 的最长子数组 → k = 1
- 2024. 考试的最大困扰度 → "最多改 k 个 T/F"

### 4.3 例题：713. 乘积小于 K 的子数组（窗口计数）

**题意**：统计乘积小于 k 的**连续子数组个数**。

**关键洞察**：当窗口 `[left, right]` 合法时，以 `right` 结尾的合法子数组有 `right - left + 1` 个。

```
以 right 结尾、起点在 [left, right] 的所有子数组都合法（因为元素都是正的，去掉前面的元素乘积更小）
数量 = right - left + 1
```

```java
public int numSubarrayProductLessThanK(int[] nums, int k) {
    if (k <= 1) return 0;
    int left = 0, prod = 1, count = 0;
    for (int right = 0; right < nums.length; right++) {
        prod *= nums[right];
        while (prod >= k) {
            prod /= nums[left];
            left++;
        }
        count += right - left + 1;      // 关键：一次性加上所有以 right 结尾的合法子数组
    }
    return count;
}
```

> 参考实现：[src/array/SubArraySumK.java](../src/array/SubArraySumK.java)、[src/backtracking/NumSubArrayBounded.java](../src/backtracking/NumSubArrayBounded.java)

**"以 right 结尾的合法子数组个数 = right - left + 1"这个技巧非常重要**，很多计数类窗口题都用它。

### 4.4 例题：643. 子数组最大平均数 I（定长窗口）

定长窗口的写法更简单：**滑动时"进一个、出一个"**。

```java
public double findMaxAverage(int[] nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];      // 第一个窗口
    int maxSum = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];                // 进一个、出一个
        maxSum = Math.max(maxSum, sum);
    }
    return (double) maxSum / k;
}
```

> 参考实现：[src/array/MaxAvg.java](../src/array/MaxAvg.java)、[src/array/MaxSumTwoNoOverlap.java](../src/array/MaxSumTwoNoOverlap.java)

```java
// 初始化前 k 个

...
// 滑动
for (int i = k; i < n; i++) {
    // 加入 nums[i]
    // 移除 nums[i - k]

}
```

### 4.5 例题：1052. 爱生气的书店老板（定长 + 前缀和思想）

**思路**：老板不生气时的顾客本来就满意；生气的分钟里，用长度为 `minutes` 的窗口覆盖，看最多能额外挽回多少顾客。

```java
public int maxSatisfied(int[] customers, int[] grumpy, int minutes) {
    int total = 0;                     // 不生气时段的顾客总数
    int extra = 0, maxExtra = 0;       // 窗口内能额外挽回的顾客数
    for (int i = 0; i < customers.length; i++) {
        if (grumpy[i] == 0) {
            total += customers[i];
        } else {
            extra += customers[i];     // 生气时，进入窗口就加
        }
        if (i >= minutes) {
            // 滑出窗口：如果滑出的是生气时段，要减掉
            if (grumpy[i - minutes] == 1) extra -= customers[i - minutes];
        }
        maxExtra = Math.max(maxExtra, extra);
    }
    return total + maxExtra;
}
```

> 参考实现：[src/greedy/MaxSatisfied.java](../src/greedy/MaxSatisfied.java)

**这个"只把需要统计的部分放进窗口"的技巧，是定长窗口的高级用法。**

## 五、题型三：窗口内最值 → 单调队列

如果窗口内需要**最大值/最小值**，普通窗口就不够了（因为移出元素时需要重新找最值）。这时要用**单调队列**。

### 5.1 例题：239. 滑动窗口最大值（Hard）

**题意**：定长窗口 `k`，返回每个窗口的最大值。

**暴力**：`O(nk)`。**单调队列**：`O(n)`。

**核心思想**：维护一个**下标单调递增、对应值单调递减**的双端队列。

- 队首永远是当前窗口的最大值
- 新元素入队前，把队尾所有比它小的元素弹出（它们永远不可能成为最大值了）
- 队首如果滑出窗口，弹出

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();      // 存下标，值单调递减

    for (int i = 0; i < n; i++) {
        // ① 队尾弹出所有比当前值小的 → 保证单调递减
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);

        // ② 队首滑出窗口 → 弹出
        if (deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }

        // ③ 窗口形成后记录答案
        if (i >= k - 1) {
            res[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return res;
}
```

**单调队列的四个要点**：

| 要点 | 说明 |
| --- | --- |
| 存**下标**不存值 | 因为需要判断是否滑出窗口 |
| 求最大值 → 队列**递减** | 队首最大 |
| 求最小值 → 队列**递增** | 队首最小 |
| 每个元素最多入队一次、出队一次 | 所以是 `O(n)` |

> 参考实现：[src/stack/`NextGreaterElement`](../src/stack/NextGreaterElement.java) 系列（单调栈）和 [src/queue/MyPriorityQueue.java](../src/queue/MyPriorityQueue.java)（堆的思路）
> 单调栈/队列的完整讲解见 [05 栈与队列](../05-栈与队列/README.md)

### 5.2 单调队列 vs 堆

| 方案 | 时间 | 空间 | 说明 |
| --- | --- | --- | --- |
| 单调队列 | `O(n)` | `O(k)` | 最优，但只能处理"窗口滑动"这种顺序进出 |
| 大顶堆 + 懒删除 | `O(n log n)` | `O(n)` | 更通用，能处理任意删除 |
| 有序集合（TreeMap） | `O(n log k)` | `O(k)` | Java 里用 `TreeMap` |

**面试建议**：239 题面试官期待的是**单调队列**，堆可以过但会被追问"能不能 O(n)"。

## 六、滑动窗口 vs 其他模板：怎么选

| 题目特征 | 选择 | 原因 |
| --- | --- | --- |
| 连续子数组 + 单调条件（和、计数、长度） | **滑动窗口** | 窗口单调 |
| 连续子数组 + 和为 K（有负数） | **前缀和 + 哈希** | 窗口不单调 |
| 连续子数组 + 需要排序/去重 | **排序 + 双指针** | 与连续性无关 |
| 子序列（可不连续） | **DP** | 不能用窗口 |
| 窗口内求最值 | **单调队列** | 普通窗口做不到 |
| 定长窗口 + 复杂判断 | **定长窗口 + 前缀和** | — |

## 七、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| 求最长/最短的 `while` 条件写反 | 答案错误 | 最长：不合法时收缩；最短：合法时收缩 |
| 求最短时答案更新在 `while` 外 | 漏掉最优解 | 最短型答案更新在 `while` 内 |
| `left` 会回退 | 复杂度退化 / 答案错误 | `left = Math.max(left, 新位置)` |
| `valid` 记录字符总数而非种类数 | 判断永不为真 | `valid++` 只在某字符**刚好满足**时执行 |
| 先 `window[c]--` 再判断 `valid--` | 判断永不为真 | 先判断再减 |
| 窗口状态忘记回退 | 下一轮判断错误 | 移出元素时同步更新状态 |
| 定长窗口先算答案再加元素 | 下标错位 | "先加入、后移除、再记录" |
| 单调队列存值而非下标 | 无法判断滑出 | 存下标 |
