# 01 模板总览与题型判断

> 这一节的目标只有一个：**看到题目描述，能立刻反应出该用哪个模板。**

---

## 一、判断流程（背下来）

拿到任何一道数组题，按这个顺序问自己：

```
Q1: 数组有序吗？（或者可以先排序吗？）
    ├─ 是 → 二分查找 / 双指针 / 排序后贪心
    └─ 否 → Q2

Q2: 要求"连续子数组/子串"吗？
    ├─ 是 → Q3
    └─ 否 → Q4

Q3: 子数组需要满足某种"单调"条件吗？（越长越不合法 / 求和等于 K）
    ├─ 是 → 滑动窗口（可变窗口）
    └─ 否 → 前缀和 + 哈希表

Q4: 求"是否存在/两个数的关系/最大容器"这类两两配对问题吗？
    ├─ 是 → 双指针 / 哈希表
    └─ 否 → Q5

Q5: 需要"原地修改"或"O(1) 额外空间"吗？
    ├─ 是 → 快慢指针 / 原地哈希（把值放到下标位置）
    └─ 否 → 按具体题型：排序、模拟、贪心、DP
```

## 三、四个工具的"使用前提"对照

模板不是万能药，**用错前提会写出错误答案**。这一节非常重要：

### 3.1 双指针的前提

| 类型 | 前提 | 反例（不能用的场景） |
| --- | --- | --- |
| 对撞双指针求两数和 | **数组有序** | 无序数组求两数和 → 用哈希 |
| 快慢指针原地删除 | 只关心"保留哪些"，不关心相对位置是否被打乱（或要求保持相对顺序但可以覆盖） | 需要保留所有原始位置的场景 |
| 滑动窗口 | **窗口合法性单调**（收缩只能让窗口更合法） | 「子数组和恰好等于 K」且元素有负数 → 窗口和不单调，必须用前缀和 |

### 3.2 二分的前提

**不是"有序"，而是"二段性"**：存在一个判定函数 `check(mid)`，使得区间的一侧全部满足、另一侧全部不满足。

```
二段性的两种形态：

形态 A：寻找第一个满足条件的位置
  不满足 不满足 不满足 | 满足 满足 满足
                      ↑ 答案

形态 B：寻找最后一个满足条件的位置
  满足 满足 满足 | 不满足 不满足 不满足
                ↑ 答案
```

> 经典反例：[153. 寻找旋转排序数组中的最小值](../src/array/FindMin.java) 数组整体不有序，但用 `nums[mid] < nums[right]` 依然能二分，因为存在二段性。

### 3.3 滑动窗口的前提

窗口的**合法性判定**必须随窗口变化单调：

- 「和 ≥ target」：窗口越大和越大 → 单调 ✓
- 「无重复字符」：窗口越大越可能重复 → 单调 ✓
- 「和恰好 = K」：窗口越大和不一定更大（有负数）→ 不单调 ✗

### 3.4 前缀和的前提

- 数组**静态**（不被修改）。如果需要修改，用差分数组（区间加）或线段树/树状数组。
- 前缀和 + 哈希表的关键：把「求区间和 = K」转化为「找两个前缀和的差 = K」，即「前面是否存在前缀和 = currentSum - K」。

## 四、一题多解：怎么选

同一道题往往有 2~4 种解法。面试时怎么选？看这张表：

| 场景 | 选择策略 |
| --- | --- |
| 面试官只要求"能做出来" | 选**最容易写对**的，通常是哈希表 |
| 面试官问"空间能不能更优" | 选**双指针**（`O(1)` 空间） |
| 面试官问"数据是有序的你会怎么做" | 暗示你要说**二分** |
| 面试官问"数据量很大，内存放不下" | 考虑**外部排序 / 分治 / 位图** |
| 数据规模 `n ≤ 10^5`，你的解法是 `O(n^2)` | 必须换，不要提交 |

**实战对比（两数之和）**：

```java
// 方案 A：暴力双循环，O(n^2) 时间、O(1) 空间 —— 面试先说这个
public int[] twoSumBrute(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++)
        for (int j = i + 1; j < nums.length; j++)
            if (nums[i] + nums[j] == target) return new int[]{i, j};
    return new int[]{};
}

// 方案 B：哈希表，O(n) 时间、O(n) 空间 —— 面试主推
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();   // 值 -> 下标
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) return new int[]{map.get(need), i};
        map.put(nums[i], i);                       // 注意：先查询再放入，避免自己匹配自己
    }
    return new int[]{};
}
```

**关键细节**：`map.put` 必须在 `containsKey` **之后**执行。如果先放再查，当 `target = 2 * nums[i]` 时会用同一个元素匹配自己。

> 参考实现：[src/hashTable/TwoSum.java](../src/hashTable/TwoSum.java)、[src/number/TwoSum.java](../src/number/TwoSum.java)
