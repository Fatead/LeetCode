# 05 前缀和与差分

> **一句话理解**：
> **前缀和**把"区间求和"从 `O(n)` 降到 `O(1)`；
> **差分**把"区间修改"从 `O(n)` 降到 `O(1)`。
> 两者互为逆运算——**前缀和的差分是原数组，差分的前缀和是原数组**。

---

## 一、前缀和：快速求区间和

### 1.1 核心公式

```java
// 定义 pre[i] = nums[0] + nums[1] + ... + nums[i-1]
// 即 pre[0] = 0（哨兵），pre[i] 表示"前 i 个元素的和"
int[] pre = new int[n + 1];
for (int i = 0; i < n; i++) {
    pre[i + 1] = pre[i] + nums[i];
}

// 求 nums[l..r] 的区间和（下标从 0 开始，闭区间）
int sum = pre[r + 1] - pre[l];
```

### 1.2 为什么要多开一个 `pre[0] = 0`？（哨兵思想）

这是**前缀和最重要的一个细节**。对比两种写法：

```java
// ❌ 不推荐：pre[i] 表示"前 i+1 个元素的和"
int[] pre = new int[n];
pre[0] = nums[0];
for (int i = 1; i < n; i++) pre[i] = pre[i - 1] + nums[i];

// 求 [l, r] 区间和
int sum = (l == 0) ? pre[r] : pre[r] - pre[l - 1];    // 必须特判 l == 0！

// ✅ 推荐：pre[i] 表示"前 i 个元素的和"，pre[0] = 0
int[] pre = new int[n + 1];
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];

int sum = pre[r + 1] - pre[l];                        // 无需任何特判
```

**哨兵的价值**：`pre[0] = 0` 统一了所有情况，让 `l == 0` 时公式依然成立。**这是刷题中反复出现的技巧**——多开一位、多放一个虚拟结点（链表的哑结点、树的虚拟根），可以消灭大量边界特判。

### 1.3 例题：303. 区域和检索 - 数组不可变

**题意**：多次查询 `sumRange(l, r)`。

```java
class NumArray {
    private int[] pre;

    public NumArray(int[] nums) {
        pre = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            pre[i + 1] = pre[i] + nums[i];
        }
    }

    public int sumRange(int left, int right) {
        return pre[right + 1] - pre[left];
    }
}
```

> 参考实现：[src/array/RangeSumQuery.java](../src/array/RangeSumQuery.java)、[src/array/RangeSum.java](../src/array/RangeSum.java)

**复杂度**：构造 `O(n)`，每次查询 `O(1)`，空间 `O(n)`。

### 1.4 例题：724. 寻找数组的中心下标

**题意**：找到下标 `i` 使得 `nums[0..i-1]` 的和等于 `nums[i+1..n-1]` 的和。

**思路**：左边和用累加维护，右边和 = 总和 - 左边和 - `nums[i]`。

```java
public int pivotIndex(int[] nums) {
    int total = 0;
    for (int x : nums) total += x;
    int leftSum = 0;
    for (int i = 0; i < nums.length; i++) {
        if (leftSum == total - leftSum - nums[i]) {
            return i;
        }
        leftSum += nums[i];
    }
    return -1;
}
```

> 参考实现：[src/array/PivotIndex.java](../src/array/PivotIndex.java)

**注意**：不需要真的建前缀和数组，"一边遍历一边累加"就够了。**能用变量就不用数组**，这是省空间的好习惯。

### 1.5 例题：560. 和为 K 的子数组（前缀和 + 哈希表，超高频）

**题意**：统计和为 `k` 的连续子数组个数（**元素可能为负数**）。

**为什么不能用滑动窗口？** 因为元素有负数，窗口和不是单调的，收缩左边界不一定会让和变小。

**关键转化**：

```
我们要找 pre[j] - pre[i] == k，即 pre[i] == pre[j] - k

枚举右端点 j，问：前面有多少个前缀和等于 pre[j] - k？
→ 用哈希表记录"每个前缀和出现的次数"
```

```java
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();   // 前缀和 -> 出现次数
    count.put(0, 1);                                 // 哨兵：空前缀和出现 1 次
    int pre = 0, res = 0;

    for (int x : nums) {
        pre += x;
        // 当前前缀和是 pre，需要找前面有多少个前缀和 == pre - k
        res += count.getOrDefault(pre - k, 0);
        count.merge(pre, 1, Integer::sum);           // 当前前缀和入表（注意在查询之后）
    }
    return res;
}
```

> 参考实现：[src/array/SubArraySumK.java](../src/array/SubArraySumK.java)、[src/array/SubArraySum.java](../src/array/SubArraySum.java)、[src/array/SubArraysDiv.java](../src/array/SubArraysDiv.java)、[src/array/SumEvent.java](../src/array/SumEvent.java)

**三个致命细节**：

1. **`count.put(0, 1)` 不能省**
   为什么？考虑 `nums = [3], k = 3`。遍历到 3 时 `pre = 3`，需要找 `pre - k = 0`。如果表里没有 `0`，就漏掉了"从下标 0 开始的子数组"。这个 `0→1` 就是**哨兵**。

2. **先查询、后入表**
   如果先 `count.merge(pre, ...)` 再查询 `pre - k`，当 `k == 0` 时会把"空子数组"也算进去（`pre - k == pre`，会匹配到自己）。

3. **哈希表存的是"出现次数"不是"下标"**
   因为要求**个数**，不是位置。

**一句话总结**：*和为 K 的子数组是【前缀和 + 哈希表】，关键突破点是把区间和转化为两个前缀和之差，边界是必须预置 `count[0] = 1`。*

### 1.6 同族变体：前缀和 + 取模

当题目要求"子数组和能被 K 整除"时，用**前缀和取模**：

```java
// 974. 和可被 K 整除的子数组
public int subarraysDivByK(int[] nums, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    map.put(0, 1);
    int pre = 0, res = 0;
    for (int x : nums) {
        pre += x;
        int mod = ((pre % k) + k) % k;      // Java 的 % 可能为负，必须修正到 [0, k)
        res += map.getOrDefault(mod, 0);
        map.merge(mod, 1, Integer::sum);
    }
    return res;
}
```

> 参考实现：[src/array/SubArraysDiv.java](../src/array/SubArraysDiv.java)、[src/array/PrefixesDivBy5.java](../src/array/PrefixesDivBy5.java)

**核心原理**：`(pre[j] - pre[i]) % k == 0` ⟺ `pre[j] % k == pre[i] % k`。

> ⚠️ **Java 取模负数陷阱**：`-1 % 5 == -1`（不是 4）。必须写成 `((a % k) + k) % k`。这个坑在「和可被 K 整除」类题目里非常常见。

### 1.7 二维前缀和

**公式**（背下来，画图理解）：

```
pre[i][j] = 矩阵 (0,0) 到 (i-1,j-1) 的元素和

递推：
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i-1][j-1]
                              ↑ 容斥原理：加了两次，减掉一次

查询 (r1,c1) 到 (r2,c2) 的子矩阵和：
sum = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]
```

```java
class NumMatrix {
    private int[][] pre;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        pre = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                pre[i][j] = pre[i - 1][j] + pre[i][j - 1]
                          - pre[i - 1][j - 1] + matrix[i - 1][j - 1];
            }
        }
    }

    public int sumRegion(int r1, int c1, int r2, int c2) {
        return pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
             - pre[r2 + 1][c1] + pre[r1][c1];
    }
}
```

> 参考实现：[src/array/MatrixSum.java](../src/array/MatrixSum.java)、[src/array/SumSegmentTree.java](../src/array/SumSegmentTree.java)

**记忆技巧**：画一个 2×2 的方格，标上四个角，把"大矩形减两个小矩形加回重复减掉的部分"想清楚，公式自然就出来了。

### 1.8 前缀和的兄弟：前缀积、前缀异或

前缀和的本质是**满足结合律且可逆的运算**：

| 运算 | 是否有逆运算 | 能否用前缀和技巧 |
| --- | --- | --- |
| 加法 | 减法 ✓ | ✅ |
| 异或 | 异或本身 ✓ | ✅ |
| 乘法 | 除法（需处理 0） | ⚠️ 有 0 时不能用 |
| 取模 | 无 | ❌ |

```java
// 前缀异或：求 nums[l..r] 的异或和
pre[i + 1] = pre[i] ^ nums[i];
int xor = pre[r + 1] ^ pre[l];
```

> 参考实现：[src/BitManipulation/XorOperation.java](../src/BitManipulation/XorOperation.java)

## 二、差分数组：快速做区间修改

### 2.1 核心思想

**差分是前缀和的逆运算**。

```
原数组:      a[0]  a[1]  a[2]  a[3]
差分数组:    d[0]  d[1]  d[2]  d[3]    其中 d[i] = a[i] - a[i-1], d[0] = a[0]

对差分数组求前缀和 → 还原出原数组
```

**关键性质**：对原数组的区间 `[l, r]` 全部加 `val`，等价于对差分数组做**两次单点修改**：

```java
d[l] += val;
d[r + 1] -= val;      // 如果 r + 1 < n
```

### 2.2 模板

```java
/**
 * 差分数组模板
 * 场景：多次"区间加"，最后一次性求最终数组
 */
public int[] differenceArray(int n, int[][] updates) {
    int[] diff = new int[n + 1];                  // 多开一位，方便处理 r+1
    for (int[] u : updates) {
        int l = u[0], r = u[1], val = u[2];
        diff[l] += val;
        diff[r + 1] -= val;
    }
    // 前缀和还原
    int[] res = new int[n];
    int cur = 0;
    for (int i = 0; i < n; i++) {
        cur += diff[i];
        res[i] = cur;
    }
    return res;
}
```

### 2.3 例题：1109. 航班预订统计

**题意**：`bookings[i] = [first, last, seats]` 表示第 `first` 到 `last` 航班各预订 `seats` 个座位，返回每个航班的预订总数。

```java
public int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n + 1];              // 1-based 航班号 → 用下标 1..n
    for (int[] b : bookings) {
        int first = b[0], last = b[1], seats = b[2];
        diff[first] += seats;
        diff[last + 1] -= seats;              // last+1 可能等于 n+1，所以要多开一位
    }
    int[] res = new int[n];
    int cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += diff[i];
        res[i - 1] = cur;
    }
    return res;
}
```

**为什么差分数组要多开一位？** 因为 `r + 1` 可能等于 `n`（数组长度），不多开就会越界。

### 2.4 例题：1094. 拼车

**题意**：`trips[i] = [numPassengers, from, to]`，车容量 `capacity`，判断能否完成所有行程（乘客在 `to` 下车，所以 `[from, to)` 区间占用座位）。

```java
public boolean carPooling(int[][] trips, int capacity) {
    int[] diff = new int[1001];               // 站点范围 0..1000
    for (int[] t : trips) {
        int num = t[0], from = t[1], to = t[2];
        diff[from] += num;
        diff[to] -= num;                      // to 下车 → [from, to) 左闭右开
    }
    int cur = 0;
    for (int x : diff) {
        cur += x;
        if (cur > capacity) return false;     // 任意时刻超载就不行
    }
    return true;
}
```

> 参考实现：[src/array/CarPooling.java](../src/array/CarPooling.java)

**易错点**：区间是 `[from, to)` **左闭右开**（因为到 `to` 就下车了），所以是 `diff[to] -= num` 而不是 `diff[to + 1] -= num`。**区间开闭搞错是差分题最常见的错误。**

### 2.5 例题：253. 会议室 II（差分思想求最大重叠）

**题意**：求同时进行的会议最大数量。

```java
public int minMeetingRooms(int[][] intervals) {
    int[] diff = new int[1000001];            // 或者用 TreeMap 做离散化
    for (int[] iv : intervals) {
        diff[iv[0]] += 1;
        diff[iv[1]] -= 1;                     // 结束时刻释放
    }
    int cur = 0, max = 0;
    for (int x : diff) {
        cur += x;
        max = Math.max(max, cur);
    }
    return max;
}
```

> 参考实现：[src/array/MinPictures.java](../src/array/MinPictures.java)、[src/array/MinInterval.java](../src/array/MinInterval.java)

**当坐标范围很大时**，用有序结构做**离散化**：

```java
// 用 TreeMap 代替大数组
TreeMap<Integer, Integer> diff = new TreeMap<>();
for (int[] iv : intervals) {
    diff.merge(iv[0], 1, Integer::sum);
    diff.merge(iv[1], -1, Integer::sum);
}
int cur = 0, max = 0;
for (int v : diff.values()) {
    cur += v;
    max = Math.max(max, cur);
}
```

## 三、前缀和 vs 差分：一张表说清

| 需求 | 工具 | 单次操作复杂度 |
| --- | --- | --- |
| 数组**不变**，多次**区间查询** | 前缀和 | 查询 `O(1)`，预处理 `O(n)` |
| 数组**频繁区间修改**，最后求结果 | 差分 | 修改 `O(1)`，最后还原 `O(n)` |
| **又修改又查询** | 树状数组 / 线段树 | 都是 `O(log n)` |

```
前缀和：  预处理一次 → 查询很多次
差分：    修改很多次 → 还原一次

两者是逆运算：
  pre[i] - pre[i-1] = nums[i]        （前缀和的差分是原数组）
  diff 的前缀和 = 原数组              （差分的前缀和是原数组）
```

**记忆方法**：

- 要**读**得快（区间查询）→ 前缀和
- 要**写**得快（区间修改）→ 差分

## 四、进阶：树状数组与线段树（了解即可）

当"修改"和"查询"交替出现时，前缀和和差分都不够用了，需要：

| 结构 | 支持操作 | 复杂度 | 代码量 |
| --- | --- | --- | --- |
| 树状数组（BIT） | 单点修改 + 前缀查询 | `O(log n)` | 约 20 行 |
| 线段树 | 区间修改 + 区间查询（任意结合律操作） | `O(log n)` | 约 60 行 |

**面试中出现的概率**：树状数组 ≈ 5%，线段树 ≈ 5%（国内大厂稍高）。**不必优先掌握**，但要知道它们的存在。

**什么时候你会想到它们？** 题目描述里出现"**多次修改 + 多次查询**"且 `n` 较大。例如：

- 307. 区域和检索 - 数组可修改 → 树状数组
- 315. 计算右侧小于当前元素的个数 → 树状数组 / 归并排序
- 493. 翻转对 → 归并排序 / 树状数组

> 参考实现：[src/sugmentTree/MaxSegmentTree.java](../src/sugmentTree/MaxSegmentTree.java)、[src/sugmentTree/MinSegmentTree.java](../src/sugmentTree/MinSegmentTree.java)、[src/array/SumSegmentTree.java](../src/array/SumSegmentTree.java)
> **替代方案**：这类题**优先用归并排序**（见 [06 排序与快速选择](06-排序与快速选择.md)），代码更短，写对概率更高。

## 五、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| 前缀和数组只开 `n` 位 | `l == 0` 需特判 | 开 `n+1` 位，`pre[0] = 0` |
| 区间公式写成 `pre[r] - pre[l]` | 少算一个元素 | `pre[r + 1] - pre[l]` |
| 忘记 `count.put(0, 1)` | 漏掉从 0 开始的子数组 | 哈希表必须先放哨兵 |
| 先入表后查询 | `k == 0` 时多算 | 先查询，后 `put` |
| Java 取模为负 | 分桶错误 | `((a % k) + k) % k` |
| 差分区间开闭搞错 | 结果整体偏移 | 明确是 `[l, r]` 还是 `[l, r)` |
| 差分数组不多开一位 | `diff[r+1]` 越界 | 开 `n + 1` |
| 二维前缀和容斥符号写错 | 结果错误 | `大 - 上 - 左 + 左上` |
