# 03 二分查找

> **一句话理解**：二分查找是在**有单调性的答案空间**上做"每次砍掉一半"的搜索。
> 它的适用条件不是"数组有序"，而是"存在一个判定函数，把搜索空间切成两段"——这叫**二段性**。

---

## 一、先破除两个误解

### 误解 1：二分必须数组有序

**错。** 二分的本质是**二段性**。看 LeetCode 162「寻找峰值」：数组完全无序，但依然能二分。

```
峰值的二段性：
  上坡段 nums[mid] < nums[mid+1]  → 峰在右边
  下坡段 nums[mid] > nums[mid+1]  → 峰在左边（含 mid）
```

### 误解 2：二分模板很多，记不住

**其实只需要记住一个**。所有二分题的差别只在于**「区间定义」（开闭）**和**「check 条件」**。本节会给你一套"万能框架"，让 `while` 边界、`mid` 取整、返回值三个最容易错的点一次解决。

---

## 二、万能框架（先记住这一个）

```java
/**
 * 二分查找万能框架（左闭右闭写法）
 *
 * 在 [left, right] 内寻找 满足 check(x) 的 第一个位置。
 * 前提：check 具有单调性 —— 存在分界点 k，使得
 *        下标 < k 时 check 为 false，下标 >= k 时 check 为 true
 *       （即 false false false | true true true）
 *
 * 返回：第一个使 check 为 true 的下标；若不存在，返回 right + 1
 */
private int lowerBound(int left, int right) {
    while (left <= right) {                 // ① 区间非空时继续
        int mid = left + (right - left) / 2; // ② 防溢出写法
        if (check(mid)) {
            right = mid - 1;                // ③ mid 满足，答案在 [left, mid-1] 里继续找更左的
        } else {
            left = mid + 1;                 // ④ mid 不满足，答案在 [mid+1, right]
        }
    }
    return left;                            // ⑤ 循环结束时 left == right + 1，即"第一个满足的位置"
}
```

**三个关键点，逐个解释**：

#### ① 为什么是 `left <= right`？

因为区间是**闭区间** `[left, right]`：当 `left == right` 时区间里还有一个元素没检查，必须继续。

#### ② 为什么写 `left + (right - left) / 2`？

防止 `left + right` 溢出（当 `left`、`right` 都接近 `Integer.MAX_VALUE` 时）。面试时**建议写这个版本**，既安全又显得专业。

它还有个性质：**当区间长度为偶数时偏向左边**。这很重要，否则 `left = mid` 会死循环。

#### ③④ 为什么一个 `-1` 一个 `+1`？

因为 `mid` 已经检查过了，下一轮要排除它。**只要写 `left = mid` 或 `right = mid`（不加 1），就必须改 `mid` 的取整方向，否则死循环。**

> **死循环自检口诀**：如果出现 `left = mid`，那么 `mid` 必须向上取整 `(left + right + 1) / 2`；如果出现 `right = mid`，`mid` 向下取整即可，但循环条件要配 `left < right`。

#### ⑤ 为什么返回 `left`？

循环结束时 `right = left - 1`，`left` 正好是"第一个满足条件的位置"。若答案不存在，`left` 会走到 `right + 1`（即越界位置），调用方需要判断。

## 三、三种区间写法的完整对照

很多人被"到底该用哪种"困扰。答案：**随便挑一种，但永远不要混用**。这里是三种写法解决同一道题（[704. 二分查找](https://leetcode.cn/problems/binary-search/)）的完整代码。

### 3.1 写法 A：左闭右闭 `[left, right]`

```java
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;      // right 取得到
    while (left <= right) {                     // 闭区间 → <=
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

> 参考实现：[src/array/BinarySearch.java](../src/array/BinarySearch.java)

### 3.2 写法 B：左闭右开 `[left, right)`

```java
public int search2(int[] nums, int target) {
    int left = 0, right = nums.length;          // right 取不到
    while (left < right) {                      // 半开区间 → <
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid;                       // 注意：不是 mid - 1（因为 right 取不到）
    }
    return -1;
}
```

### 3.3 写法 C：左开右开 `(left, right)`

用得少，不推荐，仅作了解：

```java
public int search3(int[] nums, int target) {
    int left = -1, right = nums.length;
    while (left + 1 < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid;
        else right = mid;
    }
    return -1;
}
```

### 3.4 三种写法对照表

| 项 | 左闭右闭 | 左闭右开 | 左开右开 |
| --- | --- | --- | --- |
| 初始 `left` | `0` | `0` | `-1` |
| 初始 `right` | `n - 1` | `n` | `n` |
| 循环条件 | `left <= right` | `left < right` | `left + 1 < right` |
| 收缩左边界 | `left = mid + 1` | `left = mid + 1` | `left = mid` |
| 收缩右边界 | `right = mid - 1` | `right = mid` | `right = mid` |
| 循环结束含义 | `left = right + 1` | `left == right` | `left + 1 == right` |

**面试建议**：**固定用「左闭右闭」**。它最符合直觉（区间两端都能取到），也最不容易出错。

## 四、核心应用一：查找边界（第一个 / 最后一个）

这是二分最高频的实际用途。标准二分只能告诉你有/没有，但很多题需要**最左或最右**的位置。

### 4.1 模板：查找左边界（第一个 ≥ target 的位置）

```java
/** 返回第一个 >= target 的下标；若都 < target，返回 nums.length */
public int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;      // 注意：right = n，处理"越界"情况
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {          // mid 满足 → 尝试找更左的
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```

### 4.2 模板：查找右边界（最后一个 ≤ target 的位置）

```java
/** 返回最后一个 <= target 的下标；若都 > target，返回 -1 */
public int upperBound(int[] nums, int target) {
    int left = -1, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left + 1) / 2;   // 向上取整！
        if (nums[mid] <= target) {                 // mid 满足 → 尝试找更右的
            left = mid;
        } else {
            right = mid - 1;
        }
    }
    return left;
}
```

> ⚠️ **注意 `mid` 向上取整**：因为出现了 `left = mid`。如果不向上取整，当 `right = left + 1` 且 `nums[mid] <= target` 时会 `left = mid` 原地不动 → **死循环**。

### 4.3 用"找左边界"统一解决 4 种问题

有了 `lowerBound`，下面 4 个问题都是它的变形：

| 问题 | 解法 |
| --- | --- |
| 第一个 ≥ target 的位置 | `lowerBound(nums, target)` |
| 第一个 > target 的位置 | `lowerBound(nums, target + 1)` |
| target 是否存在 | `lowerBound(nums, target) < n && nums[lo] == target` |
| target 出现次数 | `lowerBound(nums, target+1) - lowerBound(nums, target)` |

### 4.4 例题：34. 在排序数组中查找元素的第一个和最后一个位置

```java
public int[] searchRange(int[] nums, int target) {
    int first = lowerBound(nums, target);
    // 三种"不存在"的情况
    if (first == nums.length || nums[first] != target) {
        return new int[]{-1, -1};
    }
    int last = lowerBound(nums, target + 1) - 1;   // 第一个 > target 的位置减 1
    return new int[]{first, last};
}

private int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;
}
```

> 参考实现：[src/array/SearchRange.java](../src/array/SearchRange.java)、[src/array/SearchPos.java](../src/array/SearchPos.java)

**这个写法比"两次二分分别找左右边界"更优雅**，因为它只需要一个函数。

public char nextGreatestLetter(char[] letters, char target) {

### 4.7 例题：658. 找到 K 个最接近的元素

**思路**：答案区间一定形如 `[i, i+k-1]`（长度为 k 的连续窗口）。用二分找这个窗口的起点。

```java
public List<Integer> findClosestElements(int[] arr, int k, int x) {
    int left = 0, right = arr.length - k;
    while (left < right) {
        int mid = left + (right - left) / 2;
        // 比较"窗口左端左移一格"和"窗口右端右移一格"哪个更优
        // x - arr[mid] > arr[mid+k] - x  表示右端更近 → 窗口应该右移
        if (x - arr[mid] > arr[mid + k] - x) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    List<Integer> res = new ArrayList<>();
    for (int i = left; i < left + k; i++) res.add(arr[i]);
    return res;
}
```

> 参考实现：[src/array/ClosestElement.java](../src/array/ClosestElement.java)

**关键**：这里的 `check(mid)` 是"窗口起点为 mid 时，是否比起点为 mid+1 更优"，依然满足二段性。

## 五、核心应用二：旋转排序数组

### 5.1 例题：33. 搜索旋转排序数组

**题意**：升序数组在某个位置被旋转，如 `[4,5,6,7,0,1,2]`，在 `O(log n)` 内查找 `target`。

**核心观察**：无论怎么旋转，**`mid` 把数组分成两半，必然有一半是完全有序的**。

```
[4, 5, 6, 7, 0, 1, 2]
       mid
左边 [4,5,6,7] 有序；右边 [0,1,2] 也恰好有序（这里因为是旋转点右侧）
一般地：
  nums[left] <= nums[mid] → 左半段 [left, mid] 有序
  nums[left] >  nums[mid] → 右半段 [mid, right] 有序
```

```java
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        if (nums[left] <= nums[mid]) {
            // 左半段 [left, mid] 是有序的
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;        // target 在有序的左半段里
            } else {
                left = mid + 1;         // 否则去右半段找
            }
        } else {
            // 右半段 [mid, right] 是有序的
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}
```

> 参考实现：[src/array/SearchRotateArray.java](../src/array/SearchRotateArray.java)、[src/array/SearchRotateArray2.java](../src/array/SearchRotateArray2.java)

**易错点**：判断有序半段用 `<=`（`nums[left] <= nums[mid]`），判断 target 是否在区间内也要用正确的开闭关系。写错了会漏掉 `left == mid` 的情况。

### 5.2 例题：153. 寻找旋转排序数组中的最小值

```java
public int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < nums[right]) {
            right = mid;            // mid 在右半段（较小的一段），最小值在 mid 或左边
        } else {
            left = mid + 1;         // mid 在左半段（较大的一段），最小值一定在 mid 右边
        }
    }
    return nums[left];
}
```

> 参考实现：[src/array/FindMin.java](../src/array/FindMin.java)、[src/array/SearchMinRotateArray.java](../src/array/SearchMinRotateArray.java)

**为什么和 `nums[right]` 比较而不是 `nums[left]`？**
因为 `nums[right]` 是"较小段的右端"，用它判断 `mid` 落在哪一段更可靠。如果和 `nums[left]` 比较，遇到未旋转的情况会出错。

### 5.3 例题：154. 寻找旋转排序数组中的最小值 II（含重复元素）

```java
public int findMin(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < nums[right]) {
            right = mid;
        } else if (nums[mid] > nums[right]) {
            left = mid + 1;
        } else {
            right--;                // 相等时无法判断，保守地缩小右边界
        }
    }
    return nums[left];
}
```

> 参考实现：[src/array/MinArray.java](../src/array/MinArray.java)

**为什么相等时 `right--` 是对的？** 因为 `nums[mid] == nums[right]`，无论 `mid` 是不是最小值，`right` 位置都可以被 `mid` 位置的相同值替代，所以丢弃 `right` 不会丢答案。

**复杂度退化**：最坏 `O(n)`（数组全部元素相同时）。面试时如果被追问，要主动说出这一点。

## 六、核心应用三：峰值与山脉

### 6.1 例题：162. 寻找峰值

**题意**：数组无重复元素，`nums[i] != nums[i+1]`，找到任意一个峰值（比左右都大）的下标，要求 `O(log n)`。

**二段性**：从任意位置出发，沿着"上坡"方向走一定能到峰值。

```java
public int findPeakElement(int[] nums) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > nums[mid + 1]) {
            right = mid;            // 在下降段 → 峰值在 mid 或左边
        } else {
            left = mid + 1;         // 在上升段 → 峰值在右边
        }
    }
    return left;
}
```

## 七、核心应用四：二分答案

**这是二分最强大的用法**，也是很多人不知道的用法。

### 7.1 什么时候用二分答案？

题目出现这些字眼：

- "**最小化**最大值" / "**最大化**最小值"
- "至少需要多少天/多少船/多少次"
- 答案是一个**数值**，且**答案越大越容易满足条件**（或越小越容易）

**框架**：

```java
/**
 * 二分答案模板
 * 1. 确定答案的取值范围 [lo, hi]
 * 2. 写出 check(x)：判断"答案为 x 时是否可行"
 * 3. 确认单调性：x 越大越容易可行（或越小越容易）
 * 4. 二分
 */
public int binarySearchAnswer(int[] nums) {
    int lo = 1, hi = 某个上界;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (check(nums, mid)) {
            hi = mid;              // mid 可行 → 尝试更小的答案
        } else {
            lo = mid + 1;          // mid 不可行 → 答案必须更大
        }
    }
    return lo;
}
```

**关键**：`check(x)` 通常是一个**贪心**判断。

### 7.2 例题：875. 爱吃香蕉的珂珂

**题意**：`piles[i]` 表示第 i 堆香蕉数，每小时吃 `k` 根（一堆要在同一小时吃完，不够就只吃这堆），求 `h` 小时内吃完的最小 `k`。

**答案空间**：`k ∈ [1, max(piles)]`
**单调性**：`k` 越大，所需时间越少 → 满足"时间 ≤ h"这个条件越容易
**check(k)**：计算总耗时 `sum(ceil(pile / k))`，判断是否 ≤ h

```java
public int minEatingSpeed(int[] piles, int h) {
    int lo = 1, hi = 0;
    for (int p : piles) hi = Math.max(hi, p);      // 上界：最大堆的香蕉数

    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canFinish(piles, mid, h)) {
            hi = mid;
        } else {
            lo = mid + 1;
        }
    }
    return lo;
}

private boolean canFinish(int[] piles, int k, int h) {
    int hours = 0;
    for (int p : piles) {
        hours += (p + k - 1) / k;                  // 向上取整的写法：(a + b - 1) / b
        if (hours > h) return false;               // 提前剪枝，防止溢出
    }
    return hours <= h;
}
```

> 参考实现：[src/greedy/ShipWithDays.java](../src/greedy/ShipWithDays.java)

### 7.3 例题：1011. 在 D 天内送达包裹的能力

```java
public int shipWithinDays(int[] weights, int days) {
    int lo = 0, hi = 0;
    for (int w : weights) {
        lo = Math.max(lo, w);          // 下界：至少能装下最重的单个包裹
        hi += w;                       // 上界：一次全装完
    }
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (canShip(weights, mid, days)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}

private boolean canShip(int[] weights, int cap, int days) {
    int need = 1, cur = 0;
    for (int w : weights) {
        if (cur + w > cap) {           // 装不下就开新车
            need++;
            cur = 0;
        }
        cur += w;
    }
    return need <= days;
}
```

> 参考实现：[src/greedy/ShipWithDays.java](../src/greedy/ShipWithDays.java)

### 7.4 确定二分答案上下界的技巧

| 题目类型 | 下界 lo | 上界 hi |
| --- | --- | --- |
| 吃香蕉 | 1 | `max(piles)` |
| 运包裹 | `max(weights)` | `sum(weights)` |
| 分割数组的最大值 | `max(nums)` | `sum(nums)` |
| 平方根 | 0 | `x` |
| 第 k 小距离 | 0 | `max - min` |

**通用规律**：下界取"物理上不可能更小"的值，上界取"暴力一定能满足"的值。

### 7.5 例题：69. x 的平方根

```java
public int mySqrt(int x) {
    if (x <= 1) return x;
    int lo = 0, hi = x;
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;      // 向上取整（因为下面有 lo = mid）
        if ((long) mid * mid <= x) {
            lo = mid;                          // mid 可行 → 找更大的
        } else {
            hi = mid - 1;
        }
    }
    return lo;
}
```

> 参考实现：[src/number/SqrtX.java](../src/number/SqrtX.java)、[src/number/SqrtDouble.java](../src/number/SqrtDouble.java)

**注意 `(long) mid * mid`**：`mid` 最大到 `x`（可能 2^31-1），平方会溢出 int。**这是二分题最常见的溢出坑。**

## 八、二分的死循环与越界自查表

写完二分，先问自己这 4 个问题：

| 自查项 | 检查方法 |
| --- | --- |
| **会死循环吗？** | 如果写了 `left = mid`，`mid` 必须向上取整 `+1`；如果写了 `right = mid`，循环条件必须是 `left < right` |
| **会越界吗？** | 出现 `nums[mid+1]` 或 `nums[mid+k]` 时，`mid` 的取值是否保证不越界？`right` 初值该是 `n-1` 还是 `n`？ |
| **会溢出吗？** | `mid * mid`、`left + right`、`mid + k` 是否需要 `long` 或改成 `left + (right-left)/2`？ |
| **返回什么？** | `left` / `right` / `left-1` / 越界判断，是否和你的区间定义一致？ |

### 死循环的经典例子

```java
// ❌ 死循环写法
int left = 0, right = n - 1;
while (left < right) {
    int mid = left + (right - left) / 2;    // 向下取整
    if (check(mid)) left = mid;             // 当 right = left+1 且 check(left) 为真 → left 不变！
    else right = mid - 1;
}

// ✅ 修正：mid 向上取整
int mid = left + (right - left + 1) / 2;
```

**记忆口诀**：**`left = mid` 配向上取整，`right = mid` 配向下取整。**

## 十、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| `mid = (left + right) / 2` | 大数溢出 | `left + (right - left) / 2` |
| `left = mid` 且 `mid` 向下取整 | 死循环 | 改 `mid = left + (right - left + 1) / 2` |
| 混用开闭区间 | 漏元素或越界 | 选定一种，全篇一致 |
| 找边界时 `right` 初始化为 `n-1` | 漏掉"所有元素都 < target"的答案位置 `n` | 要返回插入位置时 `right = n` |
| `mid * mid` 溢出 | 结果错误（负数 < x） | `(long) mid * mid` |
| 二分答案上下界取错 | 答案错误 | 下界"物理不可能更小"，上界"暴力必满足" |
| 数组含重复元素时用普通二分找边界 | 结果不稳定 | 遇到 `nums[mid] == target` 时不要立即返回，继续收缩 |
