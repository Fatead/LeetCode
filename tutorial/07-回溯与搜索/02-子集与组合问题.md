# 02 子集与组合问题

> **一句话理解**：子集与组合都属于**"不关心顺序"的枚举**——用 `start` 参数保证"只往后选"，
> `[1,2]` 和 `[2,1]` 只会被生成一次。区别只在**什么时候收集结果**：子集是"每个节点都收"，组合是"满足条件才收"。

---

## 一、判定标准：这题该用 start 还是 used

| 观察题目 | 结论 |
| --- | --- |
| 要求"所有子集/所有组合"，答案里元素的**顺序无关** | 用 `start`；`[1,2]` 与 `[2,1]` 是同一答案 |
| 要求"全排列"，答案里元素的**顺序有关** | 用 `used`，见 [03 排列问题](03-排列问题.md) |
| 元素**可以重复使用** | 递归时传 `i`（不是 `i + 1`） |
| 元素**只能用一次** | 递归时传 `i + 1` |
| 数组**有重复元素**且答案不能重复 | 排序 + `if (i > start && nums[i] == nums[i-1]) continue;` |
| **每个节点**都是答案 | 进入函数就 `res.add(...)`，不写 `return` |
| **叶子 / 满足条件时**才是答案 | 在终止分支里 `res.add(...)`，然后 `return` |

**什么时候不能用 `start` 型模板**：

| 场景 | 为什么不行 | 用什么 |
| --- | --- | --- |
| 排列类问题 | `start` 强制下标递增，生不出 `[2,1]` | `used` 数组 |
| 求"最小值/最大值" | 穷举会超时 | DP / 贪心 |
| 只问"方案个数"且规模大 | 指数爆炸 | DP（见 4.1 的组合总和 IV） |

## 二、Java 通用模板

### 2.1 模板 A：子集型（每个节点都是答案）

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> subsets(int[] nums) {
        backtrack(nums, 0);
        return res;
    }

    private void backtrack(int[] nums, int start) {
        res.add(new ArrayList<>(path));   // ★ 进入节点就收集，所以不用写终止 return
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);            // 做选择
            backtrack(nums, i + 1);       // 只能往后选 → 不重不漏
            path.removeLast();            // 撤销选择
        }
    }
}
```

**逐条解释易错点**：

| 细节 | 为什么这样写 |
| --- | --- |
| 收集语句在 `for` **之前** | 子集包含空前缀和所有中间状态，每个节点都是一个子集 |
| 没有 `return` 终止语句 | 收集不依赖"路径完整"；`for` 自然结束即等价于终止 |
| 传 `i + 1` 而不是 `start + 1` | 下一层从"当前元素的下一个"开始 |
| `res.add(new ArrayList<>(path))` | 必须拷贝快照，否则所有答案共享同一个 `path` 引用 |

**正确性**：任何子集 `{i1 < i2 < ... < ik}` 都会沿"第 1 层取 i1、第 2 层取 i2……"被走到；任何路径的下标都递增，所以 `{2,1}` 不会被重复生成。这就是"不重不漏"。

### 2.2 模板 B：组合型（满足条件才收集）

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1);
        return res;
    }

    private void backtrack(int n, int k, int start) {
        if (path.size() == k) {                    // ★ 终止条件：路径长度够了
            res.add(new ArrayList<>(path));
            return;
        }
        // 还需要 k - path.size() 个数；从 i 到 n 还剩 n - i + 1 个数
        for (int i = start; i <= n - (k - path.size()) + 1; i++) {
            path.add(i);
            backtrack(n, k, i + 1);                // 不可重复取数 → i + 1
            path.removeLast();
        }
    }
}
```

### 2.3 两套模板的差异对照

| 维度 | 模板 A 子集型 | 模板 B 组合型 |
| --- | --- | --- |
| 收集位置 | `for` 之前（每个节点） | 终止分支里（满足条件时） |
| 终止条件 | 无（靠 `for` 自然结束） | `path.size() == k` / `sum == target` |
| 是否常带"累计和"参数 | 一般不需要 | 常需要（`sum` 或 `target - nums[i]`） |
| 典型题 | 78 / 90 / 491 | 77 / 39 / 40 / 216 |
| 答案个数 | `2^n` | `C(n,k)` 或受 target 限制 |

> **一句话记住**：**子集是"边走边收"，组合是"到站才收"。**

## 三、典型例题

### 3.1 78. 子集

**题意**：返回数组所有可能的子集（幂集），元素互不相同。

**决策树**（`nums = [1,2,3]`，每个节点都是一个答案）：

```
                        []                       ← ✅ 空集
          ┌──────────────┼──────────────┐
        [1]             [2]            [3]       ← ✅ 三个单元素
    ┌────┴────┐         │
 [1,2]      [1,3]    [2,3]                      ← ✅ 三个双元素
    │
 [1,2,3]                                        ← ✅
```

共 `2^3 = 8` 个节点 = 8 个子集。**暴力写法**是"用二进制枚举 `0 ~ 2^n-1`"（也是 `O(n · 2^n)`，但只能表达"选/不选"，推广不到后面的变形题）。

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> subsets(int[] nums) {
        backtrack(nums, 0);
        return res;
    }

    private void backtrack(int[] nums, int start) {
        res.add(new ArrayList<>(path));          // 每个节点都是一个子集
        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);                   // 选 nums[i]
            backtrack(nums, i + 1);              // 之后的元素只能从 i+1 开始选
            path.removeLast();                   // 撤销
        }
    }
}
```

> 参考实现：[src/backtracking/SubSet.java](../src/backtracking/SubSet.java)、[src/DFS/Subsets.java](../src/DFS/Subsets.java)

**仓库版本说明**：[SubSet.java](../src/backtracking/SubSet.java) 用"从列表里删元素再递归"，[Subsets.java](../src/DFS/Subsets.java) 用"选/不选"的二叉树式递归，两者都靠全局 `HashSet` 去重。**推荐版本是上面的 `start` 模板**：不需要哈希表，天然不重复。注意空数组要返回 `[[]]` 而不是 `[]`——上面的模板天然满足。

**复杂度**：时间 `O(n · 2^n)`（`2^n` 个节点，每个节点收集时拷贝 `path` 要 `O(n)`）；空间 `O(n)`。

*78 题是【子集模板】，关键突破点是"进入节点就收集 + 传 `i+1` 保证下标递增"，边界是空数组要返回 `[[]]`。*

### 3.2 90. 子集 II（含重复元素）

**题意**：数组可能含重复元素，返回所有不重复的子集。

**核心**：先排序，再**树层去重**。

```
nums = [1,2,2]（已排序）

                        []
          ┌──────────────┼──────────────┐
        [1]            [2]            [2]✂      ← 第 1 层的第二个 [2] 被剪掉
    ┌────┴────┐        │
 [1,2]      [1,2]✂   [2,2]
    │
 [1,2,2]

✂ 的位置：i > start 且 nums[i] == nums[i-1]
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);                        // ★ 排序：让相同的值相邻
        backtrack(nums, 0);
        return res;
    }

    private void backtrack(int[] nums, int start) {
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            // ★ 树层去重：本层如果已经用同样的值开过分支，跳过（注意是 i > start）
            if (i > start && nums[i] == nums[i - 1]) continue;
            path.add(nums[i]);
            backtrack(nums, i + 1);
            path.removeLast();
        }
    }
}
```

> 参考实现：[src/backtracking/SubSet2.java](../src/backtracking/SubSet2.java)

**仓库版本说明**：[SubSet2.java](../src/backtracking/SubSet2.java) 已经用了"排序 + 相邻判断"的思想（`if (i == 0 || !list.get(i).equals(list.get(i - 1)))`），但它额外挂了 `HashSet` 兜底，且判断写的是 `i == 0`——**思路对了，只是多了一层保险**。推荐把 `HashSet` 去掉。

**复杂度**：排序 `O(n log n)`，回溯最坏 `O(n · 2^n)`；空间 `O(n)`。

*90 题是【子集模板 + 树层去重】，关键突破点是 `i > start && nums[i] == nums[i-1]`，边界是 `i > start` 不能写成 `i > 0`（否则丢掉 `[2,2]`）。*

### 3.3 77. 组合

**题意**：返回 `1 ~ n` 中所有 `k` 个数的组合。

**决策树**（`n = 4, k = 2`）：

```
                      []
        ┌──────┬──────┼──────┐
      [1]    [2]    [3]    [4]✂      ← i=4 时剩余 1 个 < 还差 2 个 → 数学剪枝
   ┌───┼───┐  │      │
 [1,2][1,3][1,4][2,3][2,4]  [3,4]
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1);
        return res;
    }

    private void backtrack(int n, int k, int start) {
        if (path.size() == k) {                          // 到站：收结果
            res.add(new ArrayList<>(path));
            return;
        }
        // ★ 数学剪枝：还需 k - path.size() 个数，从 i 到 n 只有 n-i+1 个，不够就停
        for (int i = start; i <= n - (k - path.size()) + 1; i++) {
            path.add(i);
            backtrack(n, k, i + 1);
            path.removeLast();
        }
    }
}
```

> 参考实现：[src/backtracking/Combine.java](../src/backtracking/Combine.java)、[src/backtracking/CombineNum.java](../src/backtracking/CombineNum.java)

**仓库版本说明**：[Combine.java](../src/backtracking/Combine.java) 是最标准的写法（`LinkedList` + `removeLast()` + 拷贝结果），只差这个数学剪枝；[CombineNum.java](../src/backtracking/CombineNum.java) 有两个问题——**`resultList.add(result)` 直接存引用**，且 `k == 0` 分支会把不完整结果也加进去。**推荐版本就是上面的代码。**

**复杂度**：时间 `O(k · C(n,k))`，空间 `O(k)`。

*77 题是【组合模板】，关键突破点是 `path.size() == k` 才收集 + 剩余不足时收窄上界，边界是上界 `n - (k - path.size()) + 1`（写成 `n` 只是慢，不会错）。*

### 3.4 39. 组合总和（元素可重复使用）

**题意**：`candidates` 无重复元素，每个数**可以无限次使用**，找出所有和为 `target` 的组合。

**与 77 的唯一区别**：递归时传 `i` 而不是 `i + 1`。

```
candidates = [2,3,6,7], target = 7

sum=0
├─ 2 → 2
│   ├─ 2 → 4          ← 还能再选 2（传的是 i，不是 i+1）
│   │   ├─ 2 → 6
│   │   │   └─ 再选任何数都 > 7   ✂ break（排序后可直接结束本层）
│   │   └─ 3 → 7  ✅ [2,2,3]
│   └─ 3 → 5 → 5+2=7 ✅ 但路径下标是 {1,2,0}？不会——传 i 保证下标非递减
└─ 7 → 7  ✅ [7]
```

**为什么不会重复**：每层都从 `start = i` 往后选，路径内部下标**非递减**，`[2,2,3]` 只会以 `2→2→3` 出现一次，不会出现 `2→3→2`。

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);                       // ★ 排序，为 break 剪枝做准备
        backtrack(candidates, target, 0, 0);
        return res;
    }

    private void backtrack(int[] candidates, int target, int start, int sum) {
        if (sum == target) {                           // 找到一组解
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            if (sum + candidates[i] > target) break;   // ★ 排序后可以 break（后面更大）
            path.add(candidates[i]);
            backtrack(candidates, target, i, sum + candidates[i]);   // ★ 传 i：可重复取
            path.removeLast();
        }
    }
}
```

> 参考实现：[src/backtracking/ComSum.java](../src/backtracking/ComSum.java)、[src/backtracking/CombinationSum.java](../src/backtracking/CombinationSum.java)

**仓库版本说明**：[ComSum.java](../src/backtracking/ComSum.java) 的 `calculate` 就是标准的"传 `i`"写法（推荐），但它把 `candidates[left] > target` 写在 `return` 之前，`left == candidates.length` 时会**数组越界**，而且没有 `break` 剪枝；[CombinationSum.java](../src/backtracking/CombinationSum.java) 用了 `HashSet` 去重 + 每层拷贝 list，能过但更慢。

**复杂度**：时间上界 `O(S)`，`S` = 解的个数 × 平均解长度；空间 `O(target / min(candidates))`（递归深度上界）。

*39 题是【组合模板 + 可重复取数】，关键突破点是递归传 `i` 而不是 `i + 1`，边界是 `sum + candidates[i] > target` 时用 `break`（必须先排序）。*

### 3.5 40. 组合总和 II（只能取一次 + 含重复元素）

**题意**：`candidates` 可能含重复元素，每个数只能用一次，找出所有和为 `target` 的组合，答案不能重复。

**两个约束叠在一起，对应两行代码**：

| 约束 | 代码 |
| --- | --- |
| 每个数只能用一次（树枝） | 递归传 `i + 1` |
| 答案不能重复（树层） | `if (i > start && candidates[i] == candidates[i-1]) continue;` |

```
candidates = [1,1,2,5,6,7,10]（排序后），target = 8

                    []
       ┌────────────┼────────────┐
     [1]          [1]✂          [2] ...        ← 第 1 层的第二个 1 是树层重复
   ┌──┼──┐
 [1,1][1,2][1,5][1,6][1,7]                     ← [1,7] ✅  [1,1,6] ✅
       │
    [1,2,5] ✅
```

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);                                  // ★ 排序
        backtrack(candidates, target, 0, 0);
        return res;
    }

    private void backtrack(int[] candidates, int target, int start, int sum) {
        if (sum == target) {
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            if (sum + candidates[i] > target) break;              // 循环内剪枝：break
            if (i > start && candidates[i] == candidates[i - 1]) continue;  // ★ 树层去重
            path.add(candidates[i]);
            backtrack(candidates, target, i + 1, sum + candidates[i]);      // ★ 传 i+1
            path.removeLast();
        }
    }
}
```

> 参考实现：[src/backtracking/CombinationSum2.java](../src/backtracking/CombinationSum2.java)、[src/backtracking/ComSum2.java](../src/backtracking/ComSum2.java)

**仓库版本说明**：[CombinationSum2.java](../src/backtracking/CombinationSum2.java) 已是**教科书式的正确写法**（`if (i > position && nums[i] == nums[i-1]) continue;` 就是树层去重），只是多挂了一个 `HashSet`——**去掉它就是最优解**。[ComSum2.java](../src/backtracking/ComSum2.java) 用 `integerList.toString()` 塞 `HashSet` 去重，且缺 `break` 剪枝，属于**治标不治本**的写法。

**复杂度**：排序 `O(n log n)`，回溯 `O(2^n)` 上界（实际被剪枝大幅缩小）；空间 `O(n)`。

*40 题是【组合模板 + 树层去重】，关键突破点是"传 `i+1` 管树枝去重 + `i > start` 管树层去重"必须同时做，边界是 `i > start`。*

### 3.6 216. 组合总和 III

**题意**：找出 `k` 个**互不相同**的数（1~9），和为 `n` 的所有组合。

| 约束 | 代码 |
| --- | --- |
| 只从 1~9 里选 | `for (int i = start; i <= 9; i++)` |
| 恰好 `k` 个数 | `if (path.size() == k)` |
| 和恰好为 `n` | 传 `sum`，判断 `sum == n` |
| 每个数只用一次 | 传 `i + 1` |

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> combinationSum3(int k, int n) {
        backtrack(k, n, 1, 0);
        return res;
    }

    private void backtrack(int k, int n, int start, int sum) {
        if (path.size() == k) {                     // 长度够了：只有和也对才收
            if (sum == n) res.add(new ArrayList<>(path));
            return;                                 // ★ 无论对不对都要 return
        }
        for (int i = start; i <= 9; i++) {
            if (sum + i > n) break;                 // ★ 剪枝：和超了（i 递增 → break）
            path.add(i);
            backtrack(k, n, i + 1, sum + i);
            path.removeLast();
        }
    }
}
```

> 参考实现：[src/backtracking/CombineNum3.java](../src/backtracking/CombineNum3.java)

**仓库版本说明**：[CombineNum3.java](../src/backtracking/CombineNum3.java) 思路正确（`if (k == 0 && n == 0)` 收集，判断顺序也对），但每层都 `new ArrayList<>(list)`，常数偏大。**推荐版本用 `path.size() == k` 判断**，比同时追踪 `k` 和 `n` 更不容易错。

**复杂度**：时间 `O(k · C(9,k))`，空间 `O(k)`。

*216 题是【组合模板 + 多约束】，关键突破点是"长度先判、和再判，无论成败都要 return"，边界是 `n < k` 或 `n > 45` 时直接返回空结果。*

## 四、组合家族的其余成员（速览）

### 4.1 377. 组合总和 IV —— 与 DP 的正面交锋（★重要）

**题意**：`candidates` 无重复元素，每个数可用无限次，求**和为 `target` 的排列个数**（顺序不同算不同！）。仓库里**没有实现**。

这题是理解"回溯 vs DP"的最佳教材：

| 维度 | 回溯 | DP |
| --- | --- | --- |
| 思路 | 枚举所有序列，`sum == target` 时计数 | `dp[i] = Σ dp[i - nums[j]]` |
| 时间 | `target` 稍大就超时 | `O(target · n)` |
| 空间 | `O(深度)` | `O(target)` |

```java
// ✅ DP 解法（这题的正解）
class Solution {
    public int combinationSum4(int[] nums, int target) {
        int[] dp = new int[target + 1];
        dp[0] = 1;                                  // 和为 0 有一种方案：什么都不选
        for (int i = 1; i <= target; i++) {          // ★ 外层枚举"和"
            for (int num : nums) {                   // 内层枚举"最后一个数"
                if (i >= num) dp[i] += dp[i - num];
            }
        }
        return dp[target];
    }
}
```

> **为什么外层必须是"和"而不是"物品"？** 因为要数的是**排列**。
> 外层枚举物品 → 只能数出**组合**（对应 [518. 零钱兑换 II](https://leetcode.cn/problems/coin-change-ii/)）；
> 外层枚举容量 → 能数出**排列**。这一行顺序的差别就是"组合 vs 排列"的分水岭。

**这题给出的判据**：**题目问"个数"而且 `target` 很大时，一定是 DP 而不是回溯。**

### 4.2 131. 分割回文串 —— "切割型"回溯

**题意**：把 `s` 分割成若干子串，使每个子串都是回文串，返回所有方案。

**建模转换（关键一步）**：**"切割"就是"在字符串上选下标"**——`start` 是当前切割位置，每层选"下一个切割点 `i+1`"。

```
s = "aab"

              切在 0
    ┌───────────┼───────────┐
  "a"         "aa"        "aab"✂
 切在1        切在2        (不是回文)
 ┌──┴──┐        │
"a"   "ab"✂    "b"
切在2  (非回文)
  │
 "b"
 ✅ [a,a,b]   ✅ [aa,b]
```

```java
class Solution {
    List<List<String>> res = new ArrayList<>();
    LinkedList<String> path = new LinkedList<>();

    public List<List<String>> partition(String s) {
        backtrack(s, 0);
        return res;
    }

    private void backtrack(String s, int start) {
        if (start == s.length()) {                       // ★ 切到末尾 = 一个完整方案
            res.add(new ArrayList<>(path));
            return;
        }
        for (int i = start; i < s.length(); i++) {
            String sub = s.substring(start, i + 1);       // 本段 = [start, i]
            if (!isPalindrome(sub)) continue;             // ★ 剪枝：本段非回文就换更长的
            path.add(sub);
            backtrack(s, i + 1);
            path.removeLast();
        }
    }

    private boolean isPalindrome(String s) {
        int l = 0, r = s.length() - 1;
        while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
        return true;
    }
}
```

> 参考实现：[src/backtracking/PartitionStr.java](../src/backtracking/PartitionStr.java)

**仓库版本说明**：仓库版逻辑正确，但对 `s.length() == 1` 做了单独提前分支，属于**可以简化掉的特例**（"切到末尾才收集"已天然覆盖）。**优化方向**（面试常考）：用区间 DP 预处理 `isPal[i][j]`，把每段判断从 `O(n)` 降到 `O(1)`。

**复杂度**：时间 `O(n · 2^n)`，空间 `O(n)`。

*131 题是【切割型模板】，关键突破点是 `start == s.length()` 时收集、下一层传 `i+1`，边界是空串要返回 `[[]]`（`start == 0 == length` 时正好收集空路径）。*

## 六、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| 子集题 `res.add` 写在 `for` 之后 | 漏掉空集和所有中间节点 | 收集语句放在 `for` **之前** |
| 组合题忘了 `return` | 长度到了还继续加元素 | `if (path.size() == k) { res.add(...); return; }` |
| 可重复取数写了 `i + 1` | 漏掉 `[2,2,3]` 这类答案 | 传 `i` |
| 不可重复取数写了 `i` | 同一元素被反复用 | 传 `i + 1` |
| 去重写成 `i > 0` | 漏掉 `[1,1]`、`[2,2]` | 必须是 `i > start` |
| 去重前忘了排序 | 相同元素不相邻，去重失效 | `Arrays.sort(nums)` 放在回溯之前 |
| 491 题先排序 | 破坏"子序列"相对顺序，答案错 | 491 不能排序，用每层 `HashSet` |
| 超限判断用了 `continue` | 能过但慢（不丢答案） | 排序后放心用 `break` |
| 93 题前导零用 `continue` | 多搜很多无用分支 | `break`（更长的段一定也以 0 开头） |
| 698 题忘了空桶剪枝 | TLE | 空桶对称，`if (buckets[i] == 0) break;` |
| 377 题用回溯写 | `target` 稍大就超时 | 换 DP，外层枚举容量才是"排列" |
| 17 题空串没特判 | 返回 `[""]` 而不是 `[]` | `if (digits.isEmpty()) return res;` |
