# 01 树的遍历与递归思维

> **一句话理解**：写树的递归，就是**在三个固定位置插入你的代码**——进入节点时（前序）、左子树做完时（中序）、左右子树都做完时（后序）。选错位置，题目就做不出来。
>
> **前序位置拿不到子树结果，后序位置拿得到**——这一句话决定了后面 90% 树题的模板选择。

---

## 一、什么时候能用递归遍历 / 什么时候不能用

| 判定项 | 能用递归遍历 | 不能用（要换思路） |
| --- | --- | --- |
| 结构 | 树 / 多叉树 / 分治结构，天然递归 | 图、有环结构（要 `visited` 去重） |
| 每个节点的处理 | 只依赖**祖先传下来的参数**或**左右子树的返回值** | 需要跨分支互相通信（得加全局变量） |
| 树的深度 | `n ≤ 10^4`，Java 默认栈基本安全 | 退化成链且 `n ≥ 10^5`，必须改迭代 |
| 是否要"按层"处理 | 不需要 | 需要（层序 → BFS + `Queue`） |

**三句话判断该用哪个位置**：

```
需要"从根往下传"信息（深度、路径、上下界、剩余和）  → 前序位置
需要"从子树往上带"结果（高度、和、是否合法）        → 后序位置
需要"从小到大"访问（BST 相关）                     → 中序位置
```

## 二、三个模板与两个位置

### 2.1 三部曲与三种遍历模板

```java
void traverse(TreeNode root) {
    if (root == null) return;   // 第 1 步：终止条件，永远写第一行
    // ... 第 2 步：本层要做什么（放哪个位置由题目决定）...
    traverse(root.left);        // 第 3 步：递归左右孩子
    traverse(root.right);
}
```

```java
void preorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    res.add(root.val);              // ① 前序位置
    preorder(root.left, res);
    preorder(root.right, res);
}

void inorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    inorder(root.left, res);
    res.add(root.val);              // ② 中序位置
    inorder(root.right, res);
}

void postorder(TreeNode root, List<Integer> res) {
    if (root == null) return;
    postorder(root.left, res);
    postorder(root.right, res);
    res.add(root.val);              // ③ 后序位置
}
```

**三行代码换个位置，就是三种遍历。** 记住这句，比背"前序根左右"有用得多。

> 参考实现：[src/tree/PreOrder.java](../src/tree/PreOrder.java)、[src/tree/InOrder.java](../src/tree/InOrder.java)、[src/tree/PostOrder.java](../src/tree/PostOrder.java)

### 2.2 前序位置与后序位置的本质区别（本节最重要）

```java
void traverse(TreeNode root) {
    if (root == null) return;
    // ★ 前序位置：刚踏进这个节点，左右子树长什么样完全不知道
    //             手里只有"参数"（祖先带下来的）
    traverse(root.left);
    // 中序位置：左子树处理完了，右子树还没碰
    traverse(root.right);
    // ★ 后序位置：左右子树都走完了，它们的返回值就在手里
}
```

看调用栈的时间线（缩进 = 递归深度）：

```
traverse(1) 进入  ← 前序位置(1)
  traverse(2) 进入  ← 前序位置(2)
    traverse(4) 进入  ← 前序位置(4)
    traverse(4) 离开  → 后序位置(4)：4 的子树结果已确定
    traverse(5) 进入  ← 前序位置(5)      traverse(5) 离开 → 后序位置(5)
  traverse(2) 离开  → 后序位置(2)：4、5 的结果都在手里
  traverse(3) 进入  ← 前序位置(3)        traverse(3) 离开 → 后序位置(3)
traverse(1) 离开  → 后序位置(1)：2、3 的结果都在手里
```

| | 前序位置 | 后序位置 |
| --- | --- | --- |
| 时机 | **进入**节点 | **离开**节点 |
| 手里有什么 | 只有参数（从根带下来的） | 参数 **+ 左右子树的返回值** |
| 典型题目 | 求深度、收集路径、传上下界、传剩余和 | 求子树高度、子树和、判断平衡、求直径 |
| 写不出来时的症状 | 想用 `left`/`right` 的返回值 → 逻辑错 | 想用"当前深度" → 根本没有这个参数 |

**用一道题的两种写法把区别钉死**：求最大深度。

```java
// 写法 A：前序位置做事 —— 把"当前深度"当参数传下去（前序 + 全局答案）
int answer = 0;
void dfs(TreeNode root, int depth) {
    if (root == null) { answer = Math.max(answer, depth); return; }
    dfs(root.left,  depth + 1);      // depth 是参数，不是返回值
    dfs(root.right, depth + 1);
}

// 写法 B：后序位置做事 —— 把"子树高度"当返回值带上来
int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int l = maxDepth(root.left);     // 先拿到左子树高度
    int r = maxDepth(root.right);    // 再拿到右子树高度
    return Math.max(l, r) + 1;       // 用子树结果推出自己
}
```

> A 的仓库版本：[src/tree/MaxDepthTree.java](../src/tree/MaxDepthTree.java)；B 的仓库版本：[src/tree/MaxDepth.java](../src/tree/MaxDepth.java) 的 `maxDepth2`

两种写法都对，但场景不同：**后序版的结果能返回给父亲参与别计算；前序 + 全局变量版在"每个节点都要更新答案"时更自然。** 这就是下一节 [02 二叉树的属性与递归](02-二叉树的属性与递归.md) 的两大范式。

> **正确性直觉（循环不变量）**：把 `traverse(node)` 看成一个契约——"结束时恰好访问完以 `node` 为根的子树中每个节点一次"。终止条件处理空子树（0 个节点）；三种写法都只做"访问自己 + 递归两棵子树"，并集恰好是整棵子树。**三种写法访问的节点集合完全相同，只是"自己"被访问的时刻不同**，所以都不会漏解。

## 三、迭代写法：用栈模拟递归

递归用的是**系统栈**，迭代就是把系统栈搬到**显式栈**上。树退化成链且 `n` 很大时会 `StackOverflowError`，必须会写迭代。

### 3.1 前序遍历（迭代）

```java
public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.add(node.val);                              // 出栈即访问 = 前序位置
        if (node.right != null) stack.push(node.right); // 先压右
        if (node.left  != null) stack.push(node.left);  // 后压左 → 左先出栈
    }
    return res;
}
```

**为什么先压右再压左？** 栈是后进先出，要让左孩子先被处理，就得让左孩子后进栈。

> 参考实现：[src/stack/PreOrder.java](../src/stack/PreOrder.java)

### 3.2 中序遍历（迭代）

```java
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    while (root != null || !stack.isEmpty()) {   // 两个条件缺一不可
        while (root != null) {                   // 一路向左，把祖先压栈
            stack.push(root);
            root = root.left;
        }
        root = stack.pop();                      // 左边到底了 → 轮到"中"
        res.add(root.val);                       // 中序位置
        root = root.right;                       // 转向右子树
    }
    return res;
}
```

**为什么外层条件是"或"？** `root != null` 处理"还没走到最左"，`!stack.isEmpty()` 处理"左边走完要弹栈"。漏掉任一个都会提前终止或死循环。

> 参考实现：[src/tree/InOrder.java](../src/tree/InOrder.java) 的 `inorderTraversal2`、[src/stack/Inorder.java](../src/stack/Inorder.java)

### 3.3 后序遍历的巧妙写法

后序最难写，因为**根要最后访问，但根是最先入栈的**。最省事的技巧是**逆序法**：后序 = "根右左"的逆序。

```java
public List<Integer> postorderTraversal(TreeNode root) {
    LinkedList<Integer> res = new LinkedList<>();
    if (root == null) return res;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        res.addFirst(node.val);                           // 头插 = 逆序收集
        if (node.left  != null) stack.push(node.left);     // 注意：先压左（与前序相反）
        if (node.right != null) stack.push(node.right);
    }
    return res;
}
```

```
访问顺序：根 → 右 → 左   （先压左后压右，所以右先出栈）
头插（或最后 reverse）：左 → 右 → 根  ✓ 正是后序
```

另一个通用写法是**单栈 + `pre` 指针**：`while (root != null || !stack.isEmpty())` 一路向左压栈，然后只看栈顶不弹出——若 `root.right == null || root.right == pre` 就说明右子树处理完了，输出根并把 `pre` 更新为它；否则转去 `root.right`。`pre` 表示"上一次输出的节点"，用来判断右孩子是不是刚从栈里出来。

> 参考实现：[src/tree/PostOrder.java](../src/tree/PostOrder.java) 的 `postorderTraversal2`（双栈版）、[src/stack/PostOrder.java](../src/stack/PostOrder.java) 的 `postorderTraversal2`（`add(0, x)` 版）
>
> ⚠️ **仓库里的 bug**：[src/stack/PostOrder.java](../src/stack/PostOrder.java) 的单栈版把循环条件写成 `while (root != null || stack.isEmpty())`，**漏了一个 `!`**。栈已空且 `root == null` 时仍会进循环，对空栈 `pop()` → `EmptyStackException`。

### 3.4 三种遍历写法对照表

| 遍历 | 迭代核心 | 空间 | 仓库文件 |
| --- | --- | --- | --- |
| 前序 | 栈 + **先压右后压左** | `O(h)` | [PreOrder.java](../src/stack/PreOrder.java) |
| 中序 | 栈 + **一路向左**，弹出后转右 | `O(h)` | [Inorder.java](../src/stack/Inorder.java) |
| 后序 | **逆序法**（根右左 → 反转）或单栈 + `pre` | `O(h)` | [PostOrder.java](../src/stack/PostOrder.java) |
| 层序 | `Queue` + **`size` 分层**（不是栈） | `O(w)` | [LevelOrder.java](../src/tree/LevelOrder.java) |

`h` 为树高（平衡树 `O(log n)`，链式树 `O(n)`）；`w` 为最大层宽（完全二叉树底层约 `n/2`）。

## 四、层序遍历模板（BFS + Queue）

### 4.1 模板：`size` 循环按层分组

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;                 // 空树必须先返回
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();                  // ★ 关键：先固定本层节点数
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {          // 只处理这 size 个，新入队的留给下一层
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left  != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

**为什么必须先取 `size`？** `for` 循环里会往队列塞孩子，队列长度一直在变。写成 `for (int i = 0; i < queue.size(); i++)` 时 `queue.size()` 每轮重算，本层与下一层就混在一起了——**这是层序题最高频的 bug**。

### 4.2 另一种分层写法与层序变形速查

[src/tree/LevelOrder.java](../src/tree/LevelOrder.java) 用两个计数器代替 `size` 快照：`currCount` 记本层还剩几个没处理，`nextCount` 记下一层已入队几个；每处理一个就 `currCount--`，减到 0 时把 `level` **拷贝**进答案、清空 `level`，再令 `currCount = nextCount; nextCount = 0;`。

| 写法 | 优点 | 缺点 |
| --- | --- | --- |
| `size` 快照（推荐） | 少两个变量，不易写错 | 需要理解"队列里当前只装本层和下一层" |
| `currCount`/`nextCount` | 显式表达"本层 / 下层" | 变量多，三行赋值顺序写反就出错 |

> ⚠️ 仓库就写反过一次：[src/tree/LevelAvg.java](../src/tree/LevelAvg.java) 先执行 `nextNum = 0` 再执行 `levelNum = nextNum`，导致 `levelNum` 恒为 0，**第二层开始层平均值全输出 0**。推荐用 4.1 的模板重写。

## 五、Morris 遍历：`O(1)` 空间的遍历思想（了解）

Morris 用**线索二叉树**的思路，把节点左子树中最右节点的空右指针临时指回自己（中序前驱 → 后继），走完再拆掉，因此不需要栈。

```java
/** Morris 中序遍历：时间 O(n)，额外空间 O(1) */
public List<Integer> inorderTraversalMorris(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    TreeNode cur = root;
    while (cur != null) {
        if (cur.left == null) {                 // 没有左子树 → 直接访问自己
            res.add(cur.val);
            cur = cur.right;
        } else {
            TreeNode pre = cur.left;            // 找左子树最右节点
            while (pre.right != null && pre.right != cur) pre = pre.right;
            if (pre.right == null) {            // 第一次到达：建线索，钻进左子树
                pre.right = cur;
                cur = cur.left;
            } else {                            // 第二次到达：拆线索，访问 cur
                pre.right = null;
                res.add(cur.val);
                cur = cur.right;
            }
        }
    }
    return res;
}
```

| 项 | 递归 / 栈迭代 | Morris |
| --- | --- | --- |
| 时间 | `O(n)` | `O(n)`（每条线索建一次拆一次，总代价仍 `O(n)`） |
| 空间 | `O(h)` | `O(1)` |
| 代价 | 代码短 | 代码长易错，且遍历中会临时改树 |

**面试策略**：Morris 不用背，被问"能不能不用额外空间"时说出思路即可。本仓库没有 Morris 实现。

### 144. 二叉树的前序遍历

**题意**：按"根 → 左 → 右"返回所有节点值。

**思路**：递归就是三行换位置。迭代版本用栈，**先压右孩子再压左孩子**，保证左孩子先出栈——它把"递归调用顺序"这个隐式信息变成了显式的入栈顺序。

```java
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);                              // 前序位置
            if (node.right != null) stack.push(node.right);  // 先压右
            if (node.left  != null) stack.push(node.left);   // 后压左
        }
        return res;
    }
}
```

> 参考实现：[src/tree/PreOrder.java](../src/tree/PreOrder.java)、[src/stack/PreOrder.java](../src/stack/PreOrder.java)

**复杂度**：时间 `O(n)`（每节点恰好进出栈一次）；空间 `O(h)`，最坏 `O(n)`。

*二叉树的前序遍历是【递归三部曲 + 栈模拟】，关键突破点是【迭代时先压右后压左才能保证左先出栈】，边界是【`root == null` 直接返回空列表，空树不能建栈】。*

### 94. 二叉树的中序遍历

**题意**：按"左 → 根 → 右"返回所有节点值。

**思路**：**中序是 BST 相关题目的钥匙**——对 BST 做中序得到升序序列（见 [03 二叉搜索树](03-二叉搜索树.md)）。迭代的关键是"一路向左压栈，弹出来就访问，然后转向右子树"。

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        while (root != null || !stack.isEmpty()) {
            while (root != null) {          // 一路向左
                stack.push(root);
                root = root.left;
            }
            root = stack.pop();             // 中序位置
            res.add(root.val);
            root = root.right;              // 转向右子树
        }
        return res;
    }
}
```

> 参考实现：[src/tree/InOrder.java](../src/tree/InOrder.java)、[src/stack/Inorder.java](../src/stack/Inorder.java)

**复杂度**：时间 `O(n)`；空间 `O(h)`。

*二叉树的中序遍历是【BST 题目的通用前置】，关键突破点是【一路向左压栈、弹出即访问、再转右子树】，边界是【外层循环条件必须是 `root != null || !stack.isEmpty()` 两个条件的或】。*

### 145. 二叉树的后序遍历

**题意**：按"左 → 右 → 根"返回所有节点值。

**思路**：后序 = **"根右左"的逆序**。把前序的"先压右后压左"改成"先压左后压右"得到"根右左"，再反转即得后序——这一步消除了"必须记住右子树什么时候处理完"这个难点。

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        LinkedList<Integer> res = new LinkedList<>();
        if (root == null) return res;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.addFirst(node.val);                           // 头插 = 逆序收集
            if (node.left  != null) stack.push(node.left);     // 与前序相反
            if (node.right != null) stack.push(node.right);
        }
        return res;
    }
}
```

> 参考实现：[src/tree/PostOrder.java](../src/tree/PostOrder.java)（双栈版）、[src/stack/PostOrder.java](../src/stack/PostOrder.java)（⚠️ 单栈版会抛 `EmptyStackException`）

**复杂度**：时间 `O(n)`；空间 `O(h)`。

*二叉树的后序遍历是【后序位置的载体】，关键突破点是【用"根右左 + 反转"绕过"根最后访问"的难题】，边界是【先压左后压右，别和前序的压栈顺序搞混】。*

### 102. 二叉树的层序遍历

**题意**：按层返回节点值，每层一个 `List`。

**思路**：DFS 收集每层需要额外记录深度，BFS 天然按层推进——**换数据结构就消除了"记录深度"这个冗余**。

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();                   // ★ 本层节点数快照
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

> 参考实现：[src/tree/LevelOrder.java](../src/tree/LevelOrder.java)、[src/tree/LevelOrderPrint.java](../src/tree/LevelOrderPrint.java)

**复杂度**：时间 `O(n)`（每节点入队出队各一次）；空间 `O(w)`，`w` 为最大层宽。

*二叉树的层序遍历是【BFS + size 分层】，关键突破点是【进 while 后立刻 `int size = queue.size()` 固定本层规模】，边界是【空树提前返回；`size` 必须在 for 循环外取一次】。*

### 103. 二叉树的锯齿形层序遍历

**题意**：第 1 层从左到右、第 2 层从右到左、第 3 层从左到右……交替。

**思路**：暴力做法是每层收集完再 `Collections.reverse`（仓库版本就这么写）。更优做法是**用 `LinkedList` 的 `addFirst`/`addLast`**，插入时就放到正确位置，省掉整层翻转的 `O(w)` 遍历。

```java
class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        boolean leftToRight = true;
        while (!queue.isEmpty()) {
            int size = queue.size();
            LinkedList<Integer> level = new LinkedList<>();   // 支持两端插入
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (leftToRight) level.addLast(node.val);
                else             level.addFirst(node.val);    // 逆序层：头插
                if (node.left  != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            leftToRight = !leftToRight;                       // 每层结束后翻转方向
            res.add(level);
        }
        return res;
    }
}
```

> 参考实现：[src/tree/ZagLevelOrder.java](../src/tree/ZagLevelOrder.java)、[src/stack/ZigZagLevelOrder.java](../src/stack/ZigZagLevelOrder.java)

**复杂度**：时间 `O(n)`；空间 `O(w)`。`addFirst` 版与 `reverse` 版同阶，但常数更小。

*锯齿形层序遍历是【层序 + 方向控制】，关键突破点是【用 `LinkedList` 双端插入替代整层 `reverse`】，边界是【方向标志在每层结束后翻转一次，不能在 for 内部翻转】。*

### 429. N 叉树的层序遍历

**题意**：N 叉树按层返回节点值。

**思路**：把"两个固定孩子"换成"遍历 `children` 列表"，其余与 102 完全一致。

```java
class Solution {
    public List<List<Integer>> levelOrder(Node root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> level = new ArrayList<>(size);
            for (int i = 0; i < size; i++) {
                Node node = queue.poll();
                level.add(node.val);
                for (Node child : node.children) queue.offer(child);   // 唯一的差别
            }
            res.add(level);
        }
        return res;
    }
}
```

> 参考实现：[src/tree/LevelOrderNTree.java](../src/tree/LevelOrderNTree.java)

**复杂度**：时间 `O(n)`；空间 `O(w)`。

*N 叉树的层序遍历是【层序模板的直译】，关键突破点是【把 `left`/`right` 换成 `for (Node child : node.children)`】，边界是【`children` 可能为空列表，不能假设非空】。*

## 七、易错点清单

| 易错点 | 后果 | 正确做法 |
| --- | --- | --- |
| 层序用 `i < queue.size()` 当循环条件 | 本层与下一层混在一起 | 循环前 `int size = queue.size()` |
| 层序忘了 `if (root == null) return` | 队列里塞入 `null`，`poll().val` 空指针 | 进队列前判空 |
| `res.add(level)` 没新建副本 | 所有层指向同一个 List，最后全空 | `res.add(new ArrayList<>(level))` |
| 后序迭代漏写 `!stack.isEmpty()` | 空栈 `pop()` 抛 `EmptyStackException` | `while (root != null \|\| !stack.isEmpty())` |
| 前序迭代先压左后压右 | 变成"根右左" | 先压右、后压左 |
| 后序"逆序法"沿用前序压栈顺序 | 得到前序逆序，不是后序 | 逆序法要**先压左后压右** |
| `Stack` 与 `Deque` 混用 | `Stack` 效率低，方法名混乱 | 统一 `ArrayDeque`：`push/pop/peek` |
| 在链式树上递归 | `StackOverflowError` | 改迭代 |
| 把"求子树高度"写到前序位置 | 拿不到子树返回值，只能重算，`O(n^2)` | 移到后序位置 |
| BST 相关题用前序/后序 | 得不到有序序列 | 用中序 |
