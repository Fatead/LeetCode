# 02 拓扑排序与最短路

> **一句话理解**：拓扑排序 = "**先修课在前**"的排序，解决有向图的依赖关系与判环；Dijkstra = "**每次扩展最近的点**"，解决带正权图的单源最短路。

---

## 一、拓扑排序：给有向图排个合法顺序

**什么是拓扑排序？** 对有向无环图（DAG）的节点排序，使得**每条边 `u→v` 都满足 `u` 排在 `v` 前面**。典型场景：课程有先修关系，求一个合法的学习顺序。

**两个核心用途**：
1. 求一个合法的执行/学习顺序
2. **判断有向图是否有环**（有环就无法完成拓扑排序）

有两种实现：**Kahn 算法（BFS 入度法）** 和 **DFS 后序法**。

## 二、课程表（207 题）：判断能否完成

**题目**：`numCourses` 门课，`prerequisites[i]=[a,b]` 表示学 `a` 前必须先学 `b`，问能否学完所有课（即图是否无环）。

### 2.1 DFS 判环（三色标记法）

用三种状态标记每个节点：`0` 未访问、`1` 正在访问（在当前 DFS 路径上）、`2` 已完成。**如果 DFS 过程中遇到状态为 `1` 的节点，说明有环**。

```java
List<List<Integer>> graph;
int[] visited;       // 0 未访问, 1 访问中, 2 已完成
boolean valid = true;

public boolean canFinish(int numCourses, int[][] prerequisites) {
    graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    for (int[] p : prerequisites) graph.get(p[0]).add(p[1]);
    visited = new int[numCourses];
    for (int i = 0; i < numCourses && valid; i++)
        if (visited[i] == 0) dfs(i);
    return valid;
}
private void dfs(int u) {
    visited[u] = 1;                      // 标记为"访问中"
    for (int v : graph.get(u)) {
        if (visited[v] == 0) {           // 没访问过，继续深入
            dfs(v);
            if (!valid) return;
        } else if (visited[v] == 1) {    // ★ 遇到"访问中"的节点 = 发现环
            valid = false;
            return;
        }
    }
    visited[u] = 2;                      // 本节点及其后代都处理完
}
```

> 参考实现：[src/graph/CourseGraph.java](../../src/graph/CourseGraph.java)（仓库就是三色标记 DFS 判环）

**三色标记的关键**：为什么需要"访问中（1）"这个中间态？只有"正在当前递归路径上"的节点被再次遇到，才构成环；如果遇到的是已完成（2）的节点，只是不同路径汇合，不是环。

### 2.2 Kahn 算法（BFS 入度法）

**思想**：不断把"入度为 0"（没有前置依赖）的节点取出，并删掉它的出边。能取完所有节点就无环。

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    int[] indegree = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);      // b → a（学完 b 才能学 a）
        indegree[p[0]]++;               // a 的入度 +1
    }
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);   // 入度 0 的先入队
    int finished = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        finished++;
        for (int v : graph.get(u))
            if (--indegree[v] == 0) queue.offer(v);  // 删边后入度变 0 的入队
    }
    return finished == numCourses;      // 全部出队 = 无环
}
```

*课程表是【拓扑排序判环】，关键突破点是【DFS 三色标记遇"访问中"即有环；或 Kahn 不断移除入度 0 的点看能否移完】，边界是【建图方向别搞反】。*

## 三、课程表 II（210 题）：输出拓扑序

**题目**：返回一个合法的学习顺序（无解返回空数组）。在 Kahn 算法基础上，**记录出队顺序**即为拓扑序。

```java
public int[] findOrder(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
    int[] indegree = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);
        indegree[p[0]]++;
    }
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);
    int[] order = new int[numCourses];
    int idx = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        order[idx++] = u;               // 记录出队顺序
        for (int v : graph.get(u))
            if (--indegree[v] == 0) queue.offer(v);
    }
    return idx == numCourses ? order : new int[0];   // 没排完说明有环
}
```

> 参考实现：[src/graph/CourseGraph2.java](../../src/graph/CourseGraph2.java)

**Kahn 的天然优势**：出队顺序就是拓扑序，不像 DFS 要把后序结果再反转。所以**求拓扑序推荐 Kahn，纯判环两者都行。**

## 四、Dijkstra：带权图单源最短路

**适用**：边权**非负**的图，求从起点到各点的最短距离。**思想**：维护一个"已确定最短距离"的集合，每次从未确定的点里选距离起点最近的，用它去松弛（更新）邻居。用**优先队列**自动取最近点。

```java
int[] dijkstra(List<int[]>[] graph, int n, int start) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;
    // 小根堆按距离排序，元素是 [节点, 到起点的距离]
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{start, 0});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], d = cur[1];
        if (d > dist[u]) continue;          // 过期的旧记录，跳过
        for (int[] edge : graph[u]) {       // edge = [邻居, 边权]
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {    // 松弛
                dist[v] = dist[u] + w;
                pq.offer(new int[]{v, dist[v]});
            }
        }
    }
    return dist;
}
```

**典型题**：网络延迟时间（743）、到达目的地的最短路（1976）、K 站中转内最便宜航班（787，Dijkstra 变体或 Bellman-Ford）。

> Dijkstra 的核心是"**贪心 + 优先队列**"——每次都确定当前最近的那个点的最短距离不会再被改变（因为后续路径只会更长）。这个贪心成立的前提是**边权非负**；有负权要用 Bellman-Ford / SPFA。

## 五、判断二分图（785 题）：染色法

**二分图**：节点能分成两组，使每条边的两端分属不同组。**用两种颜色交替染色**，相邻节点染不同色，若发现相邻节点同色则不是二分图。

```java
public boolean isBipartite(int[][] graph) {
    int n = graph.length;
    int[] color = new int[n];       // 0 未染, 1 和 2 两种颜色
    for (int i = 0; i < n; i++)
        if (color[i] == 0 && !dfs(graph, color, i, 1)) return false;
    return true;
}
private boolean dfs(int[][] graph, int[] color, int u, int c) {
    color[u] = c;
    for (int v : graph[u]) {
        if (color[v] == c) return false;              // 相邻同色 → 非二分图
        if (color[v] == 0 && !dfs(graph, color, v, 3 - c)) return false;  // 3-c 在 1/2 间切换
    }
    return true;
}
```

> 参考实现：[src/graph/BiPartition.java](../../src/graph/BiPartition.java)

**`3 - c` 的小技巧**：在颜色 `1` 和 `2` 之间来回切换（`3-1=2`，`3-2=1`），比写 `if-else` 简洁。
